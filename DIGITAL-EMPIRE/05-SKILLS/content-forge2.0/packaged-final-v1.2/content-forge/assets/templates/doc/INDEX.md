# Templates: `doc` target

Template scheletro per documenti markdown ampliati prodotti dal `doc-builder-agent`.

## File

- `document.template.md` — scaffolding del documento principale (TOC + sezioni canoniche)
- `chapter.template.md` — scaffolding di un capitolo (intro + atomi + cross-ref + outro)
- `glossary.template.md` — scaffolding del glossario
- `faq.template.md` — scaffolding della FAQ generata da steel-manning
