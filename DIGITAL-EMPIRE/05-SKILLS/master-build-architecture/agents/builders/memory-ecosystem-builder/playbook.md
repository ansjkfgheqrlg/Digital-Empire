# Memory-Ecosystem-Builder Playbook

1. Receive vision + context from Conductor.
2. Create dir structure in target/memory/ (checkpoints, decisions, sessions, plans, architectures).
3. Generate MEMORY-INDEX.md using template + populate with vision, sources, rules, initial indexes.
4. Create first CP-000, DEC-000, SES-000 with full details.
5. Generate or copy Python automation (memory_manager.py).
6. Add integration notes for Ruflo and other agents.
7. Log everything to the new memory/ structure.
8. Return control to Conductor with "Memory ecosystem ready. INDEX updated."

**For this build itself:** We are dogfooding the exact process.
