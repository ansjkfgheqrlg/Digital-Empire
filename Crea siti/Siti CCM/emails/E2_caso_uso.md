# Email 2: Caso d'uso concreto (Invio dopo 1 giorno)

**Oggetto:** Da un vocale di 2 minuti a una Skill pronta per Claude Code 🎙️ ➡️ 💻

Ciao,

Ieri ti ho inviato il link per scaricare il manuale. Oggi voglio mostrarti un **caso d'uso reale e pratico** che puoi implementare oggi stesso nei tuoi flussi di lavoro.

Immagina questa scena: sei in macchina, ti viene in mente un'idea per un workflow o una specifica per una nuova funzionalità. Prendi il telefono, registri un vocale WhatsApp di 2 minuti in cui descrivi il tuo flusso di pensiero.

Come trasformi quel vocale confuso in una **Skill strutturata e operativa** per Claude Code in meno di 5 minuti?

Ecco il flusso operativo spiegato nel Capitolo 8 e Capitolo 28 del manuale:

1. **Trascrizione**: Esporta il vocale in testo usando uno strumento di trascrizione AI.
2. **Ingestione**: Dai in pasto la trascrizione grezza a Claude Code usando il comando:
   `claude "Crea una skill partendo da questa trascrizione..."`
3. **Analisi e Struttura**: Grazie alle regole descritte nel **Framework I.C.R.O.** (Capitolo 9), Claude analizza il testo grezzo e lo struttura in un file `SKILL.md` con frontmatter YAML conforme agli standard di Digital Empire.
4. **Scrittura automatica**: Claude crea il file direttamente nella cartella `.claude/skills/` del tuo progetto.
5. **Autoverifica**: Esegue una passata di QA per accertarsi che i tag siano corretti.

Da quel momento, per richiamare quel workflow complesso, ti basterà dire a Claude Code:  
`claude esegui [nome-skill]`

Niente prompt da 1.000 parole da copiare e incollare ogni volta. Una sola riga di comando per automatizzare un intero reparto.
