# CHECKLIST OPERATIVA APSOC — Derivata da Sistema Andrei Pascu
### Usala per OGNI copy, landing, ad, email, script video. Se manca una spunta, non pubblicare.

> APSOC = **Attention – Problem/Pain – Story/Solution – Offer – Close**
> Framework originale di Andrei Pascu. Questa è la versione operativa cross-video.

---

## ISTRUZIONI
- Per ogni asset, valuta SÌ / NO. Niente "NI".
- Obiettivo: 100% SÌ. Minimo accettabile: 8/10 per sezione? No, 8/10 TOTALE sul punteggio finale? Meglio: devi avere 90%+ overall.
- Compilarla in 4 minuti max. Se ci metti di più, il copy è troppo complesso.

---

### A — ATTENTION (0-3 sec) [Obiettivo: fermare lo scroll]
- [ ] **A1. Hook provocatorio / Controintuitivo:** La prima frase sfida una credenza o spara un verdetto secco? (Es: "Il tuo copy fa schifo")
- [ ] **A2. Call out avatar iper-specifico:** Chi stai chiamando è chiarissimo in 7 parole? (Evita "se sei un imprenditore")
- [ ] **A3. Pattern Interrupt visivo/testuale:** C'è qualcosa che rompe il pattern feed? (Parola in caps, screenshot, frase tronca)
- [ ] **A4. Promessa implicita di valore pratico:** Si capisce che nei prossimi 60 sec imparerò qualcosa di applicabile, non teoria?
- [ ] **A5. Zero introduzioni inutili:** Niente "Ciao ragazzi, oggi..."?

**Score A: __ /5**

### P — PROBLEM / PAIN AGITATION (Obiettivo: "cazzo sta parlando di me")
- [ ] **P1. Dolore espresso in verbatim del target:** Usi parole reali che il target usa nei DM/recensioni, non gergo marketing?
- [ ] **P2. Costo dell'inazione quantificato:** Hai esplicitato cosa perde ogni giorno/settimana se non risolve? (soldi, tempo, status)
- [ ] **P3. 3 sintomi riconoscibili:** Hai elencato 3 segnali concreti che lo fanno annuire? (Es: "Scrivi 2 ore, zero reply, clienti che ti chiedono sconto")
- [ ] **P4. Nemico comune identificato:** Hai dato un nemico esterno? (Guru fuffa, metodo vecchio, AI usata male, concorrenza che copia)
- [ ] **P5. Agitazione senza pietismo:** Hai "girato il coltello" senza fare la vittima? (Emozione > dramma)

**Score P: __ /5**

### S — STORY / SOLUTION + Meccanismo (Obiettivo: trasferimento di certezza)
- [ ] **S1. Principio unico in 1 frase:** Il meccanismo è riassumibile in una frase tatuabile? (Es: "Copy = scienza, non arte")
- [ ] **S2. Story = Proof, non intrattenimento:** La storia finisce con morale = principio + proof? (Origin story, caso studio, teardown)
- [ ] **S3. Demo / Prima-Dopo live:** Mostri trasformazione concreta? (Screenshot, riscrittura, risultato)
- [ ] **S4. Semplicità estrema:** Un 13enne capisce il meccanismo? Frasi <20 parole? Zero paroloni?
- [ ] **S5. Anti-errore:** Hai esplicitato l'errore fatale da NON fare? (Es: "Se prendi headline da ChatGPT così com'è...")

**Score S: __ /5**

### O — OFFER / Stack Valore (Obiettivo: rendere stupido dire no)
- [ ] **O1. Offerta = Risultato, non prodotto:** Parli di risultato/trasformazione, non di "ore di video, moduli"?
- [ ] **O2. Stack valore chiaro:** Elencato cosa ottiene (meccanismo 1, 2, bonus) e cosa evita (perdite, errori)?
- [ ] **O3. Meccanismo Unico Nominato:** Hai dato un nome al tuo metodo? (APSOC, Sistema Cecchino, outHeadline)
- [ ] **O4. Offerta > Copy:** L'offerta di per sé è già forte anche senza copy figo? (Se no, torna a Fase 0)
- [ ] **O5. Differenziazione da competitor:** È chiaro perché NON sei come gli altri? (Filosofia, storico aggiornamenti, ricerca)

**Score O: __ /5**

### C — CLOSE / Contenimento Obiezioni + CTA (Obiettivo: azione immediata)
- [ ] **C1. Obiezione #1 disinnescata:** Hai anticipato e distrutto la scusa più comune? ("Non funziona per me perché sono alle prime armi")
- [ ] **C2. Riduzione rischio tangibile:** Garanzia, storico aggiornamenti gratis, supporto, proof di 270k/1100+ studenti?
- [ ] **C3. Scarsità/urgenza etica (non finta):** Costo dell'inazione o finestra temporale reale, non "solo 3 posti falsi"?
- [ ] **C4. CTA SINGOLA:** Una sola azione chiesta, ultra specifica? (Non 3 CTA diverse)
- [ ] **C5. Task di 10 minuti:** Se non vende direttamente, lasci un compito micro-applicabile subito?

**Score C: __ /5**
