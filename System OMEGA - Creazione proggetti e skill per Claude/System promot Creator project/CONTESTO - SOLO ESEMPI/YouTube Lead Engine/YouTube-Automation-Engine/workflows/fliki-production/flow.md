# Workflow: Produzione con Fliki

## Obiettivo
Convertire lo script validato in un video 16:9 completo di voiceover, musica, transizioni e sottotitoli.

## Steps (Operatività in Fliki)
1. **Setup Progetto:** Formato 16:9, incolla script.
2. **Assegnazione Voiceover:** Scegliere la voce neurale e lingua corretta. 
3. **Cura Visiva:** Fliki abbina le clip. L'agente/operatore deve validare che ogni clip corrisponda concettualmente al testo a schermo.
4. **Bilanciamento Audio:** Musica a -20dB/-30dB rispetto al Voiceover. Nessuna sovrapposizione fastidiosa.
5. **Quality Gate (Anteprima):** Riproduzione intera *pre-export* obbligatoria.
6. **Esportazione:** Rendering in 1080p MP4.

## Error Handling
- *Desincronizzazione Audio/Video:* Regolare la lunghezza dei blocchi di testo nello scene editor di Fliki.
