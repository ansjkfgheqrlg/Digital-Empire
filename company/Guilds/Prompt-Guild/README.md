# 💬 Prompt Guild — Guild

> Expertise: prompt engineering, system prompt design, prompt review, chain-of-thought
> Serve principalmente: tutti gli ecosistemi — ogni agente L5 ha un system prompt che può essere revisionato
> Guild Master: `prompt-guild-master`

## Standard di qualità (invariante)

ogni system prompt deve avere: identità, responsabilità, I/O, acceptance criteria, esempi

## Come si richiede supporto alla Guild

```json
{
  "from": "<ecosistema_richiedente>",
  "to": "Prompt Guild",
  "tipo": "guild_request",
  "brief": "...",
  "formato_atteso": "...",
  "deadline": "..."
}
```

## Stato

Struttura creata (F1). Agenti L5 da assegnare in F3 (migrazione asset + registro Identity-HR).
