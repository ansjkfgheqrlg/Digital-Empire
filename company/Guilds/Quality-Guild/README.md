# ✅ Quality Guild — Guild

> Expertise: QA gate, testing, contradiction-analyzer, review strutturale, acceptance criteria
> Serve principalmente: tutti — ogni delivery passa dal Quality Gate prima di uscire dall'ecosistema
> Guild Master: `quality-guild-master`

## Standard di qualità (invariante)

acceptance criteria misurabili su ogni handoff contract; 0 delivery senza QA

## Come si richiede supporto alla Guild

```json
{
  "from": "<ecosistema_richiedente>",
  "to": "Quality Guild",
  "tipo": "guild_request",
  "brief": "...",
  "formato_atteso": "...",
  "deadline": "..."
}
```

## Stato

Struttura creata (F1). Agenti L5 da assegnare in F3 (migrazione asset + registro Identity-HR).
