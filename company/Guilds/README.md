# ⊕ GUILDS — Collegi trasversali

> Le Guild sono gruppi di agenti con expertise specifica che serve **tutti** gli ecosistemi.
> Non hanno gerarchia verticale — sono colleghi orizzontali disponibili su richiesta via BUS.
> Ogni Guild ha un Guild Master che ne mantiene gli standard.

## Le 5 Guild

| Guild | Expertise | Serve principalmente | Path |
|---|---|---|---|
| **Prompt Guild** | prompt engineering, prompt review, system prompt design | tutti | `Prompt-Guild/` |
| **Copy/APSOC Guild** | framework APSOC, brand voice, headline, CPB | MARKETING, AGENCY, INFO-BIZ | `Copy-APSOC-Guild/` |
| **Quality Guild** | QA, testing, contradiction-analyzer, gate review | tutti | `Quality-Guild/` |
| **Cost Guild** | cost-attribution, budget guard, routing tier, ROI calc | OPERATIONS, CFO | `Cost-Guild/` |
| **Design Guild** | visual identity, empire-style, template, Canva | CONTENT-FACTORY, PLATFORM | `Design-Guild/` |

## Come si usa una Guild

```
Ecosistema X ha bisogno di expertise Copy → 
  manda HC sul BUS a Copy/APSOC Guild →
  Guild Master assegna l'agente giusto →
  agente esegue → consegna risultato a X
```

Le Guild non hanno workflow propri: eseguono su richiesta degli ecosistemi.
