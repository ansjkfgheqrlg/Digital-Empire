# 🎨 Design Guild — Guild

> Expertise: visual identity, empire-style design system, template Canva, cover KDP
> Serve principalmente: CONTENT-FACTORY (visual assets), PLATFORM (UI siti), MULTI-BIZ (cover KDP, thumbnail YT)
> Guild Master: `design-guild-master`

## Standard di qualità (invariante)

ogni visual usa empire-style come base; brand kit del cliente dichiarato per multi-tenant

## Come si richiede supporto alla Guild

```json
{
  "from": "<ecosistema_richiedente>",
  "to": "Design Guild",
  "tipo": "guild_request",
  "brief": "...",
  "formato_atteso": "...",
  "deadline": "..."
}
```

## Stato

Struttura creata (F1). Agenti L5 da assegnare in F3 (migrazione asset + registro Identity-HR).
