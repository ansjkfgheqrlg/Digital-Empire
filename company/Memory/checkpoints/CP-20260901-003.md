## Criterio di ufficializzazione

Una skill è UFFICIALE quando:

1. esiste `.claude/skills/<slug>/SKILL.md`
2. il frontmatter YAML è parsabile (niente BOM, niente `": "` non quotato in scalari plain)
3. `name` == nome della cartella
4. `description` dice **cosa fa** e **quando si attiva** (≥ 60 caratteri)
5. è registrata in `company/skills-map.yaml` → `ufficializzazione_skill.skill`

Stessa logica applicata agli agenti (file ufficiale + registro + gate).

- Il difetto più costoso non era la skill mancante, era la skill **presente ma muta**: YAML rotto e
