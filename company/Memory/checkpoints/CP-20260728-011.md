## 1. BUILD
- Nuovo `Apex7Orchestrator.write_dashboard(phase_results)`: scrive la dashboard leggendo
  `self.working_memory` della run corrente (canale scelto, video replicato, idea script, SEO
  score) e una tabella con l'esito REALE per fase — 🟢 PASS / 🔴 FAIL / ⚪ N/D ("non eseguita",
  per le fasi mai raggiunte in questa run, es. per un `--phase` limitato o un fallimento a monte).
  Stato fabbrica: 🟢 OPERATIVA solo se 6/6 fasi reali PASS, 🔴 BLOCCATA ALLA FASE N se una fase
  fallisce, 🟡 PARZIALE se la run si ferma prima per `--phase` senza errori.

  (prima del `sys.exit(1)`) — non avrebbe senso scrivere lo stato reale solo quando va tutto
  bene. `phase_results` (esito per fase) persistito in `working_memory["phase_results"]` così
  sopravvive a un `--resume` su più invocazioni, non solo l'ultima chiamata.
- **Fix collaterale onesto**: il messaggio di errore diceva già "Stato salvato" sul fallimento
  ma **non chiamava mai `self.save_state()`** — bug preesistente, ora corretto (il messaggio
