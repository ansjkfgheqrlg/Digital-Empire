# CP-20260905-016 — Brand Guidelines CCM sul motore condiviso + sync sanato

- **Data:** 2026-09-05 · **Codice di ripresa:** `EMP-ECGA` (continuazione, ripresa post-EMP-PDFSTD)
- **Perché esiste:** alla ripresa EMP-ECGA il repo aveva lavoro vero non committato (la migrazione
  delle Brand Guidelines al motore PDF condiviso) e un falso conflitto di sync che bloccava
  l'auto-commit da ore.

---

## Cosa è stato fatto

1. **Trovato e chiuso il lavoro orfano di EMP-PDFSTD:** `build_brand_guidelines.py` era già stato
   riscritto sopra `PIANO-MAESTRO/scripts/pdf_engine_empire.py` (−177 righe: via grana, CSS e
   copertina duplicati) e `content.py` adattato alla copertina standard del dossier 28 — ma mai
   committato. Verificato davvero: compile OK, import OK, rigenerati HTML (18 pagine, 111 KB) e
   PDF (0,67 MB) dal codice attuale, tutto sincrono.
2. **Diagnosi del falso conflitto di sync:** `SYNC-CONFLICT.txt` nasceva dal submodule
   `ruflo-source` — 45 file "modificati" che erano SOLO perdita del bit eseguibile su Windows
   (mode 100755→100644) + churn CRLF, zero contenuto; più `crates` (gitlink annidato non
   inizializzato) segnato come cancellato. L'auto-sync tentava il commit, non trovava nulla di
   committabile e scriveva il file di conflitto ad ogni giro.
3. **Fix permanente, non pezza:** nel repo padre `git config diff.ignoreSubmodules dirty`;
   dentro il submodule `git config core.fileMode false`. Config locali (non viaggiano col repo:
   su una macchina nuova vanno ridati — due righe).
4. `SYNC-CONFLICT.txt` rimosso come da sua stessa istruzione (il commit EMP-ECGA era già
   committato E pushato: HEAD = origin/main verificato prima di cancellare).

## Trappola per chi riprende

Il gitlink `ruflo-source` NON ha `.gitmodules`: è un repo incorporato nudo. I comandi
`git submodule ...` non lo vedono; la via per zittirlo è la config `diff.ignoreSubmodules`.

   sistema visivo guild Design).
2. Nessun cantiere aperto su brand/PDF: la migrazione è completa e committata.
