# CP-20260701-003 — PreventivoForge: scraping LIVE mobile.de RISOLTO + prova reale GLA (Max)

**Data:** 2026-07-01 · **Autore:** Max · **Tipo:** cliente / fix critico + test reale

## Problema
Il primo test "reale" (BMW di Gael) usava una **fixture JSON-LD sintetica**: il parser non era mai
stato provato sul DOM vero. Provando l'annuncio LIVE (Mercedes GLA), scoperto che:
1. mobile.de è dietro **Akamai Bot Manager** (challenge comportamentale `sec-if-cpt`): Playwright
   (anche Chrome/Edge reale pilotato) → "Zugriff verweigert".
2. mobile.de **NON espone i dati auto in JSON-LD** (solo Organization/Breadcrumb): il parser
   basato su JSON-LD non estraeva nulla di reale.

## Soluzione (implementata + testata LIVE)
- **Bypass Akamai in AUTOMATICO:** lo scraper ora lancia **Google Chrome reale** (non Playwright) con
  `--remote-debugging-port` e si collega via **CDP** (`connect_over_cdp`). Fingerprint = browser vero
  → Akamai passa su IP residenziale. Profilo per-run in temp + poll DevTools + kill-tree (fix lock).
  Fallback `--manual` invariato.
- **Parser sui dati VERI:** estrae `window.__INITIAL_STATE__ → search.vip.ads.<id>.data.ad`
  (`_extract_initial_state`/`_from_initial_state`): make/model/title, `price.grossAmount` (esposto),
  attributes per `tag` (mileage/power/fuel/transmission/firstRegistration/color/…), `features`
  (equipment_de), `htmlDescription` (pulita), `galleryImages` (rule=mo-1600). JSON-LD/DOM = fallback.
- **Schema:** `scrape_method` enum +`chrome-cdp`; `raw_specs` coerce liste/dict→stringa.
- **run.py:** wiring gate B/C/D (helper `_gate`) + fix `UnicodeEncodeError` (stdout UTF-8).
- **Glossario (Half B) esteso** ~40 termini reali + `looks_german` corretto (morfemi solo `endswith`:
  eliminati falsi positivi IT tipo "telecamera"/"assistente"; aggiunti antrieb/system/kontrolle/filter/spiegel/laden).
