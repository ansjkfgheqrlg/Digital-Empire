# CP-20260728-001 — Fase 1 (pilota) fusione Ruflo + APEX-7-CORE: motore multi-tenant + fix bug bloccante

- **Data:** 2026-07-28
- **Ecosistema/Reparto:** 11-APEX-7-CORE (motore) + YOUTUBE-AUTOMATION-FACTORY (consumer)
- **Task:** Max ha chiesto se APEX-7 sia già sistema nervoso empire-wide (no) e ha ordinato
  di aprire il piano di espansione. Ricerca ha trovato 4 implementazioni APEX-7 divergenti +
  backbone Ruflo mai costruito → decisione ADR-010: fondere le due linee usando il motore già
  scritto in `11-APEX-7-CORE`. Questo CP copre la prima fetta tecnica della Fase 1 (pilota
  YouTube + Stream-S7-Bot): multi-tenancy nel motore condiviso + fix di un bug bloccante trovato
  durante l'indagine.
- **Esito:** ⚠️ parziale — motore condiviso ora multi-tenant e testato; retrofit di YouTube
  (`apex7_orchestrator.py`) e ritiro della reimplementazione Stream-S7-Bot **non ancora fatti**.
- **Output:**
  - `company/Ecosistemi/11-APEX-7-CORE/memory/memory_system.py` — `APEX7Memory(domain=...)`,
    namespacing dati per dominio, `domain="default"` retrocompatibile.
  - `company/Ecosistemi/11-APEX-7-CORE/orchestrator/ruflo_core.py` — `RuFLOOrchestrator(domain=...)`.
  - `company/Ecosistemi/11-APEX-7-CORE/test_multi_tenant.py` — 4/4 verde (isolamento dati per
    dominio verificato).
  - `YOUTUBE-AUTOMATION-FACTORY/02-AUTOMAZIONI-E-SCRIPTS/memory.py` — fix path assoluto
    hardcoded di un'altra macchina (`c:\Users\olhad\...`), ora relativo allo script.
    `test_youtube_apex7.py` 11/11 ancora verde dopo il fix.
- **Decisioni prese:** [ADR-010](../decisions/ADR-010-fusione-ruflo-apex7.md) — fusione
  Ruflo+APEX-7-CORE, pilota su 2 ecosistemi, poi roadmap sui restanti 11 (richiesta esplicita
  di Max, non opzionale).
- **Lezioni/errori:** il bug del path hardcoded (`c:\Users\olhad\...`) era silenzioso — mai
  esploso perché nessun caller passa `base_dir` esplicito e probabilmente nessuno ha ancora
  girato lo script fuori dalla macchina originale. Vale come promemoria: ogni path di default
  va derivato dallo script (`__file__`), mai scritto a mano per una macchina specifica.
- **Costi:** 2 agenti Explore in background (ricerca architettura, ~190k token totali) + build
  diretto di questo CP.
- **Prossimo passo:** retrofit `apex7_orchestrator.py` (sostituire critic fisso e agenti
  hardcoded con chiamate al motore condiviso) + ritiro reimplementazione indipendente in
  `12-STREAM-S7-BOT` + aggiornare `company/REGISTRO-IMPRESA.md` e
  `PIANO-MAESTRO/07-BACKBONE-RUFLO-SKILLS.md`. Blocco ⚠️ COORDINAMENTO da mettere in
  STATO-EMPIRE.md prima di toccare i file che Gael possiede in YOUTUBE-AUTOMATION-FACTORY.
