## Trappole per chi riprende

1. **La console è cp1252:** ogni script Python che stampa emoji va lanciato con `PYTHONIOENCODING=utf-8`.
2. **`sed` con `|` come delimitatore rompe** sulle righe di tabella markdown. Usare Python.
3. **Il daemon di sync committa da solo** mentre si lavora: prima di ricommittare, verificare HEAD.
   Due commit di sync (19:30 e 19:35) hanno già preso parte di questo lavoro.
4. **ADR-022 non è più libero.** Il nostro è il 023.
5. **Mai tagliare un file con `t[indice_a:indice_b]` calcolato con `index`/`rindex`.** Errore
   commesso e riparato oggi: una sostituzione così ha cancellato 1.500 righe di
   `06-CRITICA-E-GIRI.md` in un colpo. Il file era già committato, quindi
   `git checkout HEAD -- <file>` ha ripristinato tutto: **è la ragione per cui si committa spesso.**
   Le correzioni su file lunghi si fanno con sostituzioni di stringhe esatte, verificando prima
   che l'occorrenza sia una sola (`assert t.count(vecchio) == 1`) e controllando il delta di righe
   dopo la scrittura.
