## Cosa e' stato fatto

Portato APEX-7 da "mappa" (markdown descrittivo) a **territorio** (codice
operativo testato). Sistema nervoso multi-agente per lo Stream S7 e riusabile.

Componenti costruiti/riscritti (tutti in `company/Ecosistemi/12-STREAM-S7-BOT/`):

1. **event_bus.py** — L2: 19 eventi catalogati, 4 code priorita' P0→P3, retry
   policy per priorita', Dead Letter Queue, EXACTLY_ONCE con deduplica, replay.
2. **memory_interface.py** — 5 query type (contextual_recall, decision_lookup,
   strategy_fetch, write con lock, forget-archivia), indice invertito,
   checkpoint/restore su disco, ranking strategie per success_rate misurato.
3. **quality_gates.py** — tutti e 6 i gate (L1→L7), 33 criteri con rubrica
   misurabile, soglie differenziate, timeout, sequenza + resolve_gate_id.
4. **gate_verifiers.py** (NUOVO) — verificatori eseguibili: leggono il codice
   vero, il bus vero, la memoria vera. Un criterio senza rubrica = FAIL.
5. **gate_agent.py** — macchina a stati reale (transizioni illegali bloccate),
   valutazione con rubriche, escalation con diagnosi root-cause.
6. **meta_agent.py** — registro agenti, health, pattern detection (min 3
   campioni), spawn con tetto MAX_AGENTS=12, auto-evoluzione sorvegliata da
   gate, human_override.
7. **orchestrator.py** — mappa gate→task, loop remediation con tetto 3,
   metriche baseline/current.
8. **worker_agent.py** — claim per competenza (2 worker non duplicano), fallimenti
   dichiarati sul bus.
9. **ruflo_adapter.py** + **apex7_workflow.ruflo.yaml** (NUOVI) — config unica,
   esecutore intercambiabile (RuFLO se presente, Event Bus interno altrimenti),
   validate() coerenza yaml↔codice.
10. **prompts/** (NUOVI) — 7 prompt interni: planner, writer, analyst, critic,
    refiner, gate, meta.
11. **APEX-7.md** (NUOVO) — documentazione completa 8 sezioni.
12. **test_apex7.py** (NUOVO) — end-to-end, 8 sezioni con assert reali.
