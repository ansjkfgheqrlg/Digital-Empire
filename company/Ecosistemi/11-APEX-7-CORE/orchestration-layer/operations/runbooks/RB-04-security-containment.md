# RB-04 Security or tenant-isolation incident

1. Declare SEV-1 and assign Incident Commander.
2. Revoke capability grants; freeze new writes and R2/R3.
3. Preserve database, audit, object and policy evidence.
4. Rotate affected credentials and isolate components.
5. Determine tenants/data/time window and notify accountable owners.
6. Reopen only after root cause, retest and security approval.
