# CHIEF FORGE - TOOLS

I seguenti strumenti sono a disposizione del Chief Forge:
1. `record_checkpoint(title, details, principles)`: Registra uno stato nella memoria viva.
2. `record_decision(title, context, decision, consequences)`: Registra un ADR.
3. `create_handoff(sender, receiver, stage, payload)`: Inizia un trasferimento di compito ad un altro agente.
4. `invoke_forge_pipeline(source_name, source_text)`: Attiva il Reparto Forgiatura.
