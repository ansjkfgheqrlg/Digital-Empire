# L2.4 — ANALYTICS & OTTIMIZZAZIONE
## Ecosistema: 04-MARKETING

## Missione
Misurare l'effetto di ogni copy e campagna, diagnosticare i risultati per sezione APSOC, e chiudere il cerchio: i dati diventano pattern (reasoningbank) e i pattern diventano revisioni di copy mirate. E' il reparto che rende il sistema auto-migliorante nel tempo (pattern #5 del Piano Maestro). Senza L2.4, Marketing produce copy a ciclo aperto — non a ciclo chiuso. L'obiettivo finale è che i pattern ICP accumulati rendano ogni run di copy migliore della precedente.

## Team (agenti)

|---|---|---|---|
| AN1 | Tracking Engineer | L5 | Tracking plan, UTM codes, configurazione eventi e pixel |

## Workflow L3
- **WF-TRACKING-SETUP** — Tracking plan completo: AN1 definisce eventi + UTM + configurazione piattaforme → coordinamento con 06-PLATFORM per implementazione tecnica.
- **WF-OPTIMIZATION-LOOP** — Il cerchio che si chiude: raccolta dati (AN1/AN2) → diagnosi APSOC (AN2) → distillazione pattern (AN4) → revisione chirurgica copy (copy-master) → test (AN3) → consolidamento winner (AN4) → torna a raccolta.
- **WF-AB-TEST** — Disegno ed esecuzione esperimenti: AN3 progetta → varianti prodotte da L2.1/AD2 → raccolta dati AN1 → verdetto AN2 → pattern AN4.

## Funzioni L4
- **T-ATTRIBUTION** — Attribuzione per canale/campagna/copy (attiva AN2)
- **T-REPORT** — Report periodici per committente (skill `market-report` / `market-report-pdf`)
- **T-INSIGHT-DISTILLER** — Distillazione risultati in pattern per ICP → namespace memoria + wiki (attiva AN4)

## Regola anti-deriva (dal dossier §4d)
Nessuna revisione di copy basata su opinioni. Solo su:
1. Dati del loop (performance reale con diagnosi APSOC)
2. Score A8 (gate qualità interno)
I pattern si consolidano solo con evidenza ripetuta. Sotto soglia statistica minima: verdetto "inconclusivo", non forzato.

## Handoff contract
**Input:** dati performance (piattaforme ads/email/analytics) + copy_id delle varianti testate + contratto originale con KPI target
**Output:** diagnosi per sezione APSOC + pattern aggiornati in namespace + report committente (T-REPORT) + raccomandazioni mirate per next iteration
**Gate:** verdetti di test basati su soglie statistiche predefinite da AN3 — non soggettivi
