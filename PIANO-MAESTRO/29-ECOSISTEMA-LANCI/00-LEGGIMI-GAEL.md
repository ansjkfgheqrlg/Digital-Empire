## 5.3 Le parole che ricorrono

| Parola | Cosa vuol dire qui |
|---|---|
| **Avvolgere** | usare una capacità che esiste già altrove tramite un contratto, invece di riscriverla. Il proprietario resta chi ce l'ha |
| **Gate** | un controllo che **può bloccare davvero**. Se non può bloccare, non è un gate |
| **Verbale** | il file che un gate scrive **sempre**, anche quando lascia passare. Senza verbale, il gate non è stato eseguito |
| **Handoff** | il passaggio di consegne fra due reparti, con criterio di accettazione |
| **Schema riutilizzabile** | una cosa imparata in un lancio, scritta perché il lancio dopo la usi |
| **Scaglione** | un blocco di costruzione che finisce con qualcosa che gira |
| **Irreversibile verso l'esterno** | ciò che non si annulla: un'email spedita, un pagamento, una pagina pubblicata. **Lo fa sempre una persona** |
| **Misurato / assunto / non so** | i tre stati di ogni dato. Un dato assunto **non può essere prova** per un gate |

## 5.4 Gli stati di un lancio

| Stato | Vuol dire |
|---|---|
| `IDEA` | proposta, non ancora filtrata |
| `VALUTATO` | ha passato il filtro |
| `ISTRUITO` | ricerca e prodotto pronti; manca prezzo e data |
| `DATATO` | **ha prezzo e data**: il conto alla rovescia parte |
| `IN_PRODUZIONE` | testi, pagine e contenuti in corso |
| `PRONTO` | la lista di sincronizzazione è tutta vera |
| `APERTO` | si vende |
| `CHIUSO` | la vendita è finita, il debrief no |
| `APPRESO` | debrief scritto, schemi distillati — **l'unico finale buono** |
| `SOSPESO` | fermo, **con data di revisione obbligatoria** |
| `ABORTITO` | chiuso per decisione umana, con cosa si salva |
| `ARCHIVIATO` | idea respinta, conservata con la ragione |

1. **Nessuno scaglione si chiude con della carta.** Ognuno finisce con qualcosa che si esegue e
