# 📋 SCOPO
# ──────────────────────────────────────────────────────

Questo file traduce il metodo a 5 fasi (KB_04) in una routine
temporale concreta e ripetibile. Definisce QUANDO fare COSA
durante la settimana e durante il mese.

Senza una routine strutturata, lo studio diventa un evento
casuale che accade "quando ho tempo" — cioè quasi mai.
Con questa routine, lo studio è un processo sistematico
che produce risultati prevedibili.

## 1.2 — LUNEDÌ: Sessione di Studio Attivo

### Protocollo Dettagliato
QUANDO: Lunedì, preferibilmente al mattino o nel primo slot
di lavoro disponibile. NON alla fine della giornata
quando l'energia mentale è bassa.

DURATA: 45-60 minuti (timer impostato — non sforare)

PRE-SESSIONE (5 minuti):
│
├── 1. SCEGLI IL MATERIALE
│ │
│ │ Consulta questa gerarchia (da KB_04 Sezione 2.4):
│ │
│ │ PRIORITÀ 1: Hai un problema urgente in un progetto?
│ │ → SÌ → Cerca materiale che risolve QUEL problema
│ │ → NO → Continua sotto
│ │
│ │ PRIORITÀ 2: Hai materiale non studiato nella biblioteca?
│ │ → SÌ → Studia quello PRIMA di cercare novità
│ │ → NO → Continua sotto
│ │
│ │ PRIORITÀ 3: Quale area della biblioteca è più vuota?
│ │ → Studia materiale per quell'area
│ │
│ │ PRIORITÀ 4: C'è materiale formativo che hai acquistato
│ │ e non hai ancora aperto?
│ │ → SÌ → Studialo (regola anti-accumulazione)
│ │ → NO → Cerca nuove fonti per le aree con gap
│ │
├── 2. VERIFICA ANTI-ACCUMULAZIONE
│ │
│ │ Hai più di 5 schede in status "Estratto" non "Applicato"?
│ │ → SÌ → STOP. Non studiare oggi. Usa questa ora per
│ │ APPLICARE una delle schede in attesa.
│ │ → NO → Procedi con lo studio
│ │
└── 3. DEFINISCI L'OBIETTIVO
"Cosa spero di imparare oggi?"
"In quale progetto potrei applicare ciò che imparo?"
Scrivi la risposta in 1 riga — tienila a mente durante lo studio.

SESSIONE (35-50 minuti):
│
├── Leggi/guarda il materiale con FOCUS ATTIVO
│ (protocollo completo in KB_04 Sezione 2.2)
│
├── Cerca attivamente:
│ 🟢 Concetti nuovi
│ 🔵 Framework riutilizzabili (PRIORITÀ MASSIMA)
│ 🟡 Esempi illuminanti
│ 🔴 Contraddizioni con ciò che sai
│ 🟣 Applicazioni immediate
│
└── Segna mentalmente o su carta i candidati framework

POST-SESSIONE (5 minuti):
│
├── Rispondi alle 3 domande:
│ 1. "Qual è la SINGOLA cosa più importante che ho imparato?"
│ 2. "Quanti framework potenziali ho identificato?" (numero)
│ 3. "In quale progetto applicherò per primo?" (nome)
│
└── Annota i concetti chiave per l'estrazione di mercoledì
(non serve dettaglio — basta una lista con parole chiave
che ti ricordino i concetti)

text


### Cosa Fare se Lunedì Non è Possibile
SE lunedì non è disponibile (carico lavoro, emergenza, etc.):

OPZIONE A: Sposta a martedì (buffer day)
→ La routine prosegue normalmente con 1 giorno di ritardo
→ Mercoledì diventa giovedì, venerdì resta venerdì

OPZIONE B: Sessione ridotta (20-30 minuti)
→ Se non hai 45-60 minuti, fai una sessione ridotta
→ 20 minuti di studio attivo producono comunque 1+ concetti
→ Meglio una sessione corta che nessuna sessione

OPZIONE C: Salta la settimana
→ Succede. Non è un dramma.
→ MA: non saltare 2 settimane consecutive
→ SE salti 2+ settimane: la review mensile lo segnalerà
→ Azione correttiva: nella prossima settimana, fai 2 sessioni
(lunedì + mercoledì entrambe di studio, venerdì estrazione + check)

## 1.3 — MERCOLEDÌ: Sessione di Estrazione

### Protocollo Dettagliato
QUANDO: Mercoledì, qualsiasi momento della giornata.
L'estrazione è meno cognitivamente pesante dello studio —
può essere fatta anche a fine giornata.

DURATA: 20-30 minuti

PROCESSO:
│
├── 1. RIPRENDI GLI APPUNTI DI LUNEDÌ
│ → Guarda la lista di concetti candidati
│ → Per ciascuno, chiediti: "È ancora valido dopo 48 ore
│ di elaborazione inconscia?"
│ → A volte un concetto che sembrava brillante lunedì
│ si rivela ovvio mercoledì. È normale — scartalo.
│
├── 2. APRI MARKETING UNIVERSITY (progetto Claude)
│ → Invia il materiale o i tuoi appunti
│ → Oppure descrivi i concetti identificati
│ → Chiedi: "Estrai framework da questo materiale"
│ (attiva Workflow W1)
│
├── 3. L'AI GENERA LE SCHEDE FRAMEWORK
│ → Segue il protocollo di KB_02
│ → Produce schede con 9 campi
│ → Classifica nelle aree corrette
│ → Collega ai progetti
│ → Definisce azioni entro 7 giorni
│
├── 4. REVISIONA LE SCHEDE
│ → Le azioni suggerite sono realistiche per questa settimana?
│ → Il collegamento al progetto è corretto?
│ → Manca qualcosa? Aggiungi.
│ → Conferma o modifica.
│
└── 5. IMPEGNATI SULL'AZIONE
→ Scegli 1-2 azioni da eseguire entro venerdì/domenica
→ "Questa settimana applicherò [azione X] nel progetto [Y]"
→ Questo impegno rende la review di venerdì significativa

text


### Cosa Fare se Non Hai Studiato Lunedì
SE arrivi a mercoledì senza aver studiato lunedì:

OPZIONE A: Fai la sessione di studio ORA (mercoledì)
→ Studio + estrazione nello stesso giorno
→ Durata: 60-75 minuti totali
→ Venerdì: check come normale

OPZIONE B: Hai schede della settimana precedente non applicate?
→ Usa mercoledì per APPLICARE quelle schede
→ Non estrarre nuovo — applica il vecchio

OPZIONE C: Nessun materiale da studiare, nessuna scheda in attesa
→ Usa il tempo per una sessione QUICK REFERENCE:
consulta la biblioteca (KB_01/KB_08) e familiarizza
con i framework che hai già
→ Oppure: sessione di "pulizia" — verifica status schede esistenti

text


## 1.4 — VENERDÌ: Check Settimanale

### Protocollo Dettagliato
QUANDO: Venerdì, fine giornata lavorativa (ultimi 15 minuti).
È la chiusura della settimana di apprendimento.

DURATA: 10-15 minuti

PROCESSO:
│
├── 1. APRI MARKETING UNIVERSITY
│ → Dì: "Review settimanale" (attiva Workflow W4)
│
├── 2. L'AI VERIFICA:
│ │
│ ├── Schede create questa settimana: [elenco]
│ ├── Azioni scadute (>7 giorni senza applicazione): [elenco]
│ ├── Azioni completate: [elenco]
│ └── Backlog totale (schede Estratto non Applicate): [numero]
│
├── 3. PER OGNI AZIONE NON COMPLETATA:
│ │
│ ├── "Perché non l'hai completata?"
│ │ → Rispondi onestamente
│ │ → L'AI diagnostica il blocco (KB_04 Sezione 4.4)
│ │ → Insieme definite: rischedula / riduci / metti in pausa
│ │
│ └── SE hai completato l'azione ma non documentato:
│ → Compila il Report di Applicazione ORA
│ → Aggiorna status → ✅ Applicato
│
├── 4. PIANO SETTIMANA PROSSIMA:
│ │
│ ├── "Cosa studi lunedì prossimo?"
│ │ → SE hai materiale in coda → quello
│ │ → SE non hai materiale → l'AI suggerisce (W3)
│ │
│ ├── "Quali azioni applichi la settimana prossima?"
│ │ → Schede in attesa + nuove schede
│ │
│ └── "C'è qualcosa da validare?" (schede >30 giorni da applicazione)
│ → SE SÌ → schedula validazione per settimana prossima
│
└── 5. CHIUDI CON UN NUMERO:
"Questa settimana: [N] framework studiati, [N] estratti,
[N] applicati. Backlog: [N]."
→ Questo numero dà il polso della settimana

QUANDO: Primo lunedì del mese

## 3.1 — Settimane Anomale
SETTIMANA CON CARICO LAVORO ESTREMO:
├── Elimina la sessione di studio (Lunedì)
├── Mantieni SOLO il check di venerdì (10 minuti)
│ → Anche solo per verificare il backlog
├── Non aggiungere pressione — accetta la settimana leggera
└── Recupera la settimana successiva con sessione extra

SETTIMANA DI VACANZA:
├── Opzione A: pausa completa (nessuna attività MU)
│ → Segnala nella review mensile come "settimana di pausa"
├── Opzione B: studio leggero (lettura libro, podcast)
│ → Non serve estrazione formale
│ → Segna gli spunti per la settimana successiva
└── NON sentirti in colpa per la pausa
→ Il sistema è progettato per la sostenibilità,
non per il burnout

SETTIMANA CON EMERGENZA PROGETTO:
├── SE il problema del progetto può essere risolto
│ da un framework nella biblioteca:
│ → Sessione W2 (Ricerca Rapida) invece di W1 (Studio Nuovo)
│ → Trova e applica framework esistente
│ → Questo È studio applicato — conta
├── SE il problema richiede conoscenza che NON hai:
│ → La sessione di studio di lunedì diventa
│ studio MIRATO per risolvere quel problema
│ → Segui la PRIORITÀ 1 di KB_04 Sezione 2.4
└── In entrambi i casi: il check di venerdì resta

text


## 3.2 — Mesi Anomali
MESE CON SOLO 1-2 SESSIONI DI STUDIO (su 4 previste):
├── Non è un fallimento — è una fase con altre priorità
├── Nella review mensile: documenta PERCHÉ
│ → Troppo lavoro clienti? → Valuta se servono più processi/delega
│ → Mancanza di disciplina? → Implementa trigger più forti
│ → Materiale non motivante? → Cambia materiale, collega a problema reale
├── Piano correttivo per mese prossimo:
│ → Obiettivo realistico (non "recupero tutto" ma "faccio almeno 3 sessioni")
└── La regola chiave: la CONSISTENZA batte l'intensità
→ 3 sessioni/mese per 12 mesi = 36 sessioni = 50+ framework
→ 8 sessioni un mese poi 0 per 3 mesi = stessi 8 framework

MESE CON MOLTE SESSIONI MA POCHE APPLICAZIONI:
├── Questo è il segnale di allarme PRINCIPALE
├── Stai accumulando senza applicare (trappola #1)
├── Piano correttivo:
│ → Mese prossimo: ZERO sessioni di studio
│ → Solo applicazione delle schede in attesa
│ → Riprendi lo studio quando il backlog è ≤3
└── Chiedi a te stesso: "Sto studiando per evitare di FARE?"
→ Se sì: è procrastinazione travestita da produttività

text


## 3.3 — Adattamento della Routine nel Tempo
DOPO 1 MESE:
→ Valuta se il giorno e l'orario scelti funzionano
→ Se lunedì non funziona mai: sposta a un altro giorno
→ L'importante è la CADENZA (1x studio, 1x estrazione, 1x check)
non il giorno specifico
