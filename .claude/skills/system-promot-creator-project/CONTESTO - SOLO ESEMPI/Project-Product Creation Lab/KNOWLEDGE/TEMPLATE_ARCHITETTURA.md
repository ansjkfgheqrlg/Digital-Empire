## 📋 SCOPO

Questo file contiene i template completi per la Fase 1 della pipeline: il Learning Path (stato PRIMA → stato DOPO), l'Outline Modulare dettagliato e l'Outline Lezione. Questi template garantiscono che ogni prodotto abbia una struttura logica, una trasformazione chiara per lo studente, e che ogni modulo e ogni lezione abbia uno scopo ben definito.

Principio fondante: "Un prodotto info non è una collezione di contenuti. È un VIAGGIO che porta lo studente da un punto A a un punto B. Il Learning Path è la mappa di questo viaggio. L'Outline è la sequenza delle tappe."

## ⚠️ NOTE E AVVERTENZE

1. **Il Learning Path è la mappa del viaggio.** Se non hai un Learning Path chiaro, il prodotto è una collezione di contenuti senza direzione. Ogni modulo deve portare lo studente da un punto all'altro.

2. **Ogni modulo ha UNA trasformazione.** Se non riesci a dire "Prima non sapeva X, dopo sa X", il modulo non ha ragione di esistere. Riprogetta.

3. **Ogni lezione ha UN obiettivo specifico.** Non creare lezioni "teoriche pure". Ogni lezione deve dare qualcosa che lo studente PORTA VIA: un concetto, un framework, un template, un esercizio completato.

4. **I template devono essere compilabili con esempi.** Un template vuoto è intimidatorio. Un template con esempio compilato è utile. La checklist di autovalutazione permette allo studente di verificare da solo se ha fatto bene.

5. **L'outline deve seguire l'ordine del Learning Path.** Non mescolare l'ordine dei moduli. Il modulo 2 deve richiedere il modulo 1, il modulo 3 il modulo 2, ecc. Se c'è un salto logico, lo studente si perde.

6. **Il numero massimo di moduli è 7.** Se servono più di 7 moduli, probabilmente stai creando 2 corsi, non 1. Riesci a identificare un punto di divisione naturale? Se sì, dividi in 2 corsi. Se no, riprogetta i moduli per renderli più compatti.
