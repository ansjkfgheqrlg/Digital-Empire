# 🎬 YouTube Script Factory PRO

Sistema di Scrittura Script Video che Portano Lead all'agenzia CRO Digital Empire.

## PRINCIPIO FONDAMENTALE

```
══════════════════════════════════════════════
UNO SCRIPT YOUTUBE NON È UN ARTICOLO
LETTO AD ALTA VOCE.
══════════════════════════════════════════════
È una CONVERSAZIONE con una persona sola,
seduta dall'altra parte dello schermo,
che ha il dito pronto a scrollare via
in qualsiasi momento.
```

### Implicazioni pratiche:
- **OGNI SECONDO conta.** Se un passaggio non aggiunge valore → TAGLIA.
- **PARLA come parli a un amico.** Mai gergo tecnico non spiegato.
- **UNA IDEA per video.** Mai 2. Mai 3. UNA.
- **Il video è un FUNNEL:** Hook → Intro → Contenuto → CTA. Ogni sezione "vende" la successiva.
- **Lo spettatore È il target dell'agenzia.** Non stai facendo video per "views". Stai facendo video per far dire a un imprenditore: "Questa persona capisce il mio problema. Voglio lavorare con lei."

### DESCRIZZIONE SECONDARIA:
  Usa OGNI VOLTA che devi: scrivere uno script YouTube, generare idee video, creare hook,
  ottimizzare titoli/thumbnail, fare quality check di uno script, pianificare contenuti settimanali,
  analizzare performance video, migliorare uno script esistente, fare audit di uno script,
  gestire il backlog contenuti, generare description/pinned comment, creare CTA per video.
  Attiva quando l'utente dice "scrivi script", "video YouTube", "hook video", "piano contenuti",
  "backlog video", "quality check script", "titoli video", "thumbnail", "retention",
  "script factory", "YouTube Lead Engine", o qualsiasi riferimento a produzione video per il canale.
  NON usare per copy di landing page (CRO Copy Architect) o ricerca target (Client Research Engine).

## VOCE DIGITAL EMPIRE — REGOLE NON NEGOZIABILI

**✅ COSA SÌ:**
- "Analizziamo", "vediamo", "ti mostro"
- Dati e numeri concreti
- Esempi pratici e reali
- Onestà: "questo non funziona sempre"
- Linguaggio dell'imprenditore: "Le tue ads portano click ma zero vendite"
- Frasi brevi (max 15-20 parole per frase)
- Domande retoriche per coinvolgere
- Analogie e metafore quotidiane
- "Tu" diretto — parli a UNA persona

**❌ COSA NO:**
- "Segreto magico", "hack incredibile"
- Hype e promesse vuote
- Tono da guru o da venditore
- Gergo tecnico non spiegato
- "Ciao ragazzi, benvenuti nel mio canale"
- Frasi lunghe e complesse
- Tono accademico o da manuale
- Finto entusiasmo

## TIPI DI VIDEO — STRUTTURA CONTENUTO CORE

### ANCHOR (70% dei video) — "IL TUTORIAL"
- Risponde a una RICERCA SPECIFICA (SEO)
- Struttura: 3-5 punti → Affermazione → Spiegazione → Esempio → Azione → Transizione
- Durata per punto: 1.5-3 minuti
- Richiede: keyword target

### SHIFT (20% dei video) — "IL REFRAME"
- Cambia una CREDENZA SBAGLIATA del target
- Struttura: 4 atti → Credenza Comune → Perché Sbagliata → Il Reframe → Cosa Fare
- Durata: 10-15 minuti
- Richiede: credenza da smontare

### CONVERSION (10% dei video) — "IL CASO STUDIO"
- DIMOSTRA competenza con prove concrete
- Struttura: 4 atti → Contesto → Diagnosi → Implementazione → Risultati
- Durata: 8-14 minuti
- Richiede: caso reale con numeri

### AUDIT LIVE (variante Conversion)
- Analisi dal vivo di un sito/funnel
- Tono: pensiero ad alta voce, spontaneo, genuino
- Durata: 12-20 minuti



## SISTEMA CTA A 3 LIVELLI

| Livello | Dove | Tono | Scopo |
|---|---|---|---|
| PREVIEW (1/3) | Nel setup (~30s) | Leggera, nel flusso | Far sapere che c'è una risorsa |
| REMINDER (2/3) | A metà video | Collegata al contenuto | Ricordare, collegare al valore |
| FINALE (3/3) | Dopo il ricap | Diretta, completa | L'azione vera |

3 versioni CTA finale: Lead Magnet | Call Diretta | Doppia



## OTTIMIZZAZIONE

- **Titolo**: 6 formule testate, <60 caratteri, 5 varianti per video
- **Thumbnail**: max 4-5 parole, faccia espressiva, contrasto, 3 concept per video
- **Description**: template con link CTA nelle prime 2 righe + timestamps
- **Pinned Comment**: link CTA + timestamps + domanda engagement

## 1. HOOK

```
══════════════════════════════════════════════
IL HOOK: I PRIMI 15 SECONDI
LA PARTE PIÙ IMPORTANTE DEL VIDEO
══════════════════════════════════════════════
```

### Dati:
- Il 20% degli spettatori abbandona nei primi 5 secondi
- Il 33% abbandona nei primi 30 secondi
- Il tuo hook ha 5-15 secondi per CATTURARE

### L'errore più comune:
"Ciao ragazzi, benvenuti nel mio canale, oggi parleremo di..."
→ MORTO. Lo spettatore è già via.

### Il principio:
Il hook deve creare un **GAP DI CURIOSITÀ**: lo spettatore sa che MANCA qualcosa e DEVE continuare a guardare per scoprirlo. OPPURE deve far **RICONOSCERE un problema**: lo spettatore pensa "aspetta, questo è il MIO problema!"

### Checklist Hook (deve avere ALMENO 3 di questi):
- [ ] Identifica un PROBLEMA che il target riconosce
- [ ] Contiene un NUMERO specifico
- [ ] Crea un GAP DI CURIOSITÀ (voglio sapere di più)
- [ ] Genera un'EMOZIONE (frustrazione, sorpresa, curiosità, speranza)
- [ ] Promette un BENEFICIO chiaro
- [ ] È pronunciabile in MENO DI 15 SECONDI
- [ ] NON dice "ciao ragazzi, benvenuti..."

**REGOLA:** scrivi SEMPRE 3 hook per ogni video. Scegli il migliore. Registra gli altri 2 come alternative.

→ Per le 20 formule hook dettagliate: vedi `hook-formulas.md`

## 2. SETUP

```
══════════════════════════════════════════════
IL SETUP: IMPOSTA LE ASPETTATIVE (15-45 sec)
══════════════════════════════════════════════
```

### Scopo:
Dopo l'hook, lo spettatore pensa "ok, sono interessato". Il setup gli dice ESATTAMENTE cosa otterrà se resta fino alla fine. È una PROMESSA specifica.

### Template Setup:
```
"In questo video ti mostro [COSA],
così potrai [BENEFICIO PER LUI].
Nello specifico:
[punto 1], [punto 2], e [punto 3].
E alla fine ti dò [BONUS/RISORSA]."
```

### Esempio compilato:
```
"In questo video ti mostro le 3 sezioni
della tua landing page che stanno uccidendo
le conversioni — e come fixarle oggi.

Nello specifico vedremo:
primo, perché il tuo above-the-fold
sta facendo scappare il 60% dei visitatori;
secondo, l'errore che quasi tutti fanno
con le CTA;
e terzo, dove mettere la social proof
perché funzioni davvero.

E alla fine ti lascio una checklist gratuita
per auditare la tua landing page da solo."
```

### Perché il setup funziona:
- **ROADMAP:** Lo spettatore sa cosa aspettarsi → riduce l'ansia da "non so se vale il mio tempo"
- **LOOP APERTI:** Ogni punto citato è un "loop" che il cervello vuole chiudere → resta per chiuderli
- **VALORE PERCEPITO:** 3 punti specifici + bonus finale = "tanto valore in poco tempo"
- **CONTRATTO IMPLICITO:** "Se resti fino alla fine, ti prometto che otterrai X"

### CTA Preview (dentro il setup):
```
"A proposito — la checklist che ti dicevo
la trovi già in descrizione.
Ma prima vediamo insieme questi 3 punti."
```
→ Menzione SOFT del lead magnet
→ Non interrompe il flusso
→ Chi è già convinto può andare subito
→ Chi vuole il contenuto continua a guardare

### Errori da evitare:
- ❌ Setup troppo lungo (>45 secondi)
- ❌ Setup vago ("parleremo di marketing...")
- ❌ Promesse esagerate che non mantieni nel video
- ❌ Elencare 10 punti (3-4 massimo)
- ❌ Ripetere l'hook (il setup è DIVERSO dall'hook)

## 3. CREDIBILITÀ

```
══════════════════════════════════════════════
CREDIBILITÀ: PERCHÉ ASCOLTARE TE (30-60 sec)
══════════════════════════════════════════════
PRINCIPIO: MOSTRA, NON DIRE.
❌ "Sono un esperto di CRO con 5 anni di esperienza..."
✅ "Ho ottimizzato il funnel di [N] aziende
    e la media di uplift è del [X]%."
```

### 5 Formule Credibilità:

**FORMULA 1 — RISULTATO:**
```
"Negli ultimi [tempo] ho lavorato con [N] aziende
sulla conversione dei loro funnel.
Il pattern che vedo più spesso è [quello
di cui parla il video]."
```

**FORMULA 2 — ESPERIENZA:**
```
"Questo è esattamente il tipo di problema
che risolvo ogni giorno nella mia agenzia.
E dopo averlo visto in [N] business diversi,
posso dirti che la causa è quasi sempre la stessa."
```

**FORMULA 3 — ERRORE PERSONALE:**
```
"So di cosa parlo perché ho fatto
esattamente questo errore all'inizio.
Ed è costato a un mio cliente [conseguenza].
Da allora ho sviluppato un sistema per evitarlo."
```

**FORMULA 4 — DATO:**
```
"Ho analizzato [N] landing page nel settore [X].
Il [Y]% aveva questo esatto problema."
```

**FORMULA 5 — MINIMALISTA (per subscriber esistenti):**
```
"Se mi segui già, sai che mi occupo di CRO —
ottimizzare le conversioni per aziende
che hanno già traffico."
```
→ Per subscriber esistenti, basta 1 riga.

### Dove posizionare la credibilità:
- **POSIZIONE A — DOPO IL SETUP (classica):** Hook → Setup → Credibilità → Contenuto
- **POSIZIONE B — DENTRO L'HOOK (integrata):** "Ho appena ottimizzato un funnel e il CR è triplicato. Vi mostro come."
- **POSIZIONE C — DISTRIBUITA:** Pezzi di credibilità sparsi nel contenuto ("Come ho visto con il cliente X...", "Nel nostro ultimo sprint...")

**REGOLA:** mai più di 60 secondi di credibilità pura. La credibilità migliore è IMPLICITA: si vede da COME parli, dalla profondità dell'analisi, dalla qualità dei consigli.

## 4. CONTENUTO CORE

```
══════════════════════════════════════════════
IL CONTENUTO: DOVE DAI VALORE REALE (70-80%)
La struttura cambia RADICALMENTE in base al tipo.
══════════════════════════════════════════════
```

### TIPO A: ANCHOR (70% dei video)

**SCOPO:** Rispondere a una RICERCA SPECIFICA. Lo spettatore cerca "[problema]" su YouTube, trova il tuo video, ottiene la risposta.

**STRUTTURA: "IL TUTORIAL" — 3-5 punti/step**

Template per ogni punto:
```
PUNTO [N]: [TITOLO CHIARO]
├── AFFERMAZIONE: cosa dici (1-2 frasi)
│   "Il primo errore è [X]. Succede quando [contesto]."
│
├── SPIEGAZIONE: perché è importante (2-3 frasi)
│   "Il motivo è che [spiegazione].
│    Questo significa che [conseguenza per lui]."
│
├── ESEMPIO: caso concreto (3-5 frasi)
│   "Ti faccio un esempio. [Situazione reale].
│    [Cosa è successo]. [Risultato]."
│   OPPURE: "[Condividi schermo e mostra]"
│
├── AZIONE: cosa deve fare lui (1-2 frasi)
│   "Quello che puoi fare è [azione specifica].
│    In pratica: [come farlo, step by step]."
│
└── TRANSIZIONE: collegamento al punto successivo
    "Ora, questo ci porta al secondo punto,
     che è ancora più importante..."
    OPPURE: "E questo è collegato a..."
    OPPURE: "Ma c'è un errore ancora più grande..."
```

**Esempio compilato:**
```
"PUNTO 1: LA HEADLINE NON PARLA AL CLIENTE

[FACCIA]
Il primo errore — e il più comune —
è avere una headline che parla dell'azienda
invece che del cliente.

[SCREENCAST — mostra esempio landing page]
Faccio un esempio. Guardate questa headline:
'La nostra soluzione innovativa per il business.'
Innovativa per chi? Soluzione a cosa? Quale business?

Ora guardate questa:
'Smetti di perdere il 60% dei visitatori.
Converti il tuo traffico in clienti.'
Vedete la differenza? La seconda parla
del PROBLEMA del lettore, non dell'azienda.

[FACCIA]
Quello che potete fare è prendere
la vostra headline attuale e chiedervi:
'Se tolgo il nome della mia azienda,
questa frase potrebbe essere di chiunque?'
Se la risposta è sì — riscrivetela.

{RETENTION HOOK}
E questo ci porta al secondo errore,
che è forse ancora più costoso..."
```

**Durata per punto:** 1.5-3 minuti
**Durata totale contenuto:** 5-9 minuti (per 3 punti)

**Nota visual:**
- MOSTRA, non solo DIRE
- Condividi schermo quando analizzi landing/dati/tool
- Usa evidenziazioni (cerchi, frecce)
- Alterna tra FACCIA e SCHERMO (mantiene attenzione)
- Before/after side-by-side = potentissimo

### TIPO B: SHIFT (20% dei video)

**SCOPO:** Cambiare una CREDENZA SBAGLIATA del target. Rieducarlo su un concetto che "tutti" gli dicono in un modo, ma che tu vedi diversamente.

**STRUTTURA: "IL REFRAME" — arco narrativo in 4 atti**

**ATTO 1 — LA CREDENZA COMUNE (2-3 minuti)**
```
├── "La maggior parte degli imprenditori crede che..."
├── Presenta la credenza con RISPETTO
│   (non insultare chi la pensa così)
├── Mostra PERCHÉ sembra logica:
│   "Ed è comprensibile — se le ads non convertono,
│    la prima reazione è cambiarle. Ha senso."
├── Normalizza:
│   "Non è colpa tua pensarla così.
│    Quasi tutti ti dicono la stessa cosa."
└── CREA DUBBIO alla fine:
    "Ma c'è un problema con questo ragionamento."
```

**ATTO 2 — PERCHÉ È SBAGLIATA (3-5 minuti)**
```
├── DATI: "Guardate questi numeri..."
│   Mostra evidenze concrete
├── LOGICA: "Se ci pensi, la logica non regge perché..."
│   Smonta il ragionamento passo per passo
├── ESEMPIO: "Vi faccio vedere un caso reale..."
│   Caso concreto dove seguire la credenza
│   ha prodotto risultati negativi
├── CONFRONTO: "Chi fa [X] ottiene [A].
│   Chi fa [Y] ottiene [B]."
└── MOMENTO "AHA":
    "Il punto è che il problema non è [credenza].
     Il problema è [vera causa]."
```

**ATTO 3 — IL REFRAME (3-4 minuti)**
```
├── "Ecco come dovresti pensarla:"
├── Presenta il TUO framework/approccio
├── Spiega PERCHÉ funziona (dati, logica, risultati)
├── Se hai un framework con nome
│   (es: APP-SOC, Conversion Sprint) → presentalo qui
│   → Diventa il TUO "sistema unico"
│   → Lo spettatore associa TE a questo framework
├── Mostra come cambia TUTTO quando guardi
│   il problema dalla prospettiva giusta
└── ESEMPIO: caso dove il reframe ha prodotto risultati
```

**ATTO 4 — COSA FARE ADESSO (2-3 minuti)**
```
├── 2-3 azioni concrete immediate
├── "Il primo passo è [azione semplice].
│    Puoi farlo oggi."
├── "Il secondo passo è [azione più avanzata]."
├── "E se vuoi fare il terzo passo —
│    che è il più impattante —
│    ti serve [risorsa/aiuto]."
│   → Qui si collega alla CTA
└── Transizione alla CTA
```

**TONO SHIFT:**
- MAI arrogante ("io ho ragione, voi sbagliate")
- SEMPRE rispettoso ("la credenza è comprensibile")
- Posizionati come chi ha SCOPERTO qualcosa
- Usa "noi" inclusivo: "tutti cadiamo in questa trappola, io compreso"
- L'obiettivo è ILLUMINARE, non umiliare

**DURATA TOTALE:** 10-15 minuti

### TIPO C: CONVERSION (10% dei video)

**SCOPO:** DIMOSTRARE competenza con prove concrete. Chi guarda è già "caldo" — vuole la PROVA che sai fare quello che dici.

**STRUTTURA: "IL CASO STUDIO" — 4 atti**

**ATTO 1 — IL CONTESTO (1-2 minuti)**
```
├── "Un'azienda nel settore [X] ci ha contattato
│    con questo problema: [problema specifico]."
├── Metriche iniziali:
│   "CR [X]%. CPA €[Y]. Budget €[Z]/mese."
├── Situazione emotiva:
│   "Erano frustrati perché [emozione]."
├── Tentativi precedenti:
│   "[Cosa avevano provato] — senza risultato."
└── NOTA: anonimizza se necessario,
    ma mantieni i NUMERI (numeri = credibilità)
```

**ATTO 2 — LA DIAGNOSI (2-4 minuti)**
```
├── "La prima cosa che abbiamo fatto
│    è analizzare il funnel."
├── [SCREENCAST — mostra analisi]:
│   • Screenshot landing (anonimizzata)
│   • Heatmap / analytics
│   • Punti di drop-off specifici
├── Per ogni problema trovato:
│   "Problema [N]: [cosa] — questo causava [conseguenza]."
├── Prioritizzazione:
│   "Dei 7 problemi trovati, questi 3 erano i più impattanti."
└── VALORE: lo spettatore impara a fare
    la stessa analisi sul SUO business
```

**ATTO 3 — L'IMPLEMENTAZIONE (3-5 minuti)**
```
├── Per ogni intervento:
│   "Intervento [N]: [cosa abbiamo fatto]"
│   "Perché: [il ragionamento dietro]"
│   "In pratica: [cosa è cambiato]"
│
```

## 7. RETENTION HOOKS

```
══════════════════════════════════════════════
RETENTION HOOKS: COME TENERE LO SPETTATORE
L'algoritmo YouTube premia il WATCH TIME.
Più watch time = più views.
══════════════════════════════════════════════
```

### 10 Pattern di Retention

**PATTERN 1 — "OPEN LOOP" (il più potente)**
Apri un argomento che chiuderai più tardi.
```
"Tra poco ti mostro l'errore numero 3,
che è il più grave — ma prima devi capire questo."
```
→ Non può andarsene senza scoprire l'errore #3

**PATTERN 2 — "IL CONTRASTO"**
Cambia improvvisamente l'energia.
Stavi parlando con tono calmo → alza la voce:
```
"E qui è dove la maggior parte SBAGLIA."
```
→ Il cambio di energia riattiva l'attenzione

**PATTERN 3 — "PROVA VISIVA"**
Non dire "guardate questo dato". MOSTRA il dato.
Il cambio da faccia a schermo (e viceversa) è un pattern interrupt naturale.

**PATTERN 4 — "LA DOMANDA RETORICA"**
```
"Ma aspetta — perché succede questo?
Ci hai mai pensato?"
```
→ Il cervello si attiva per cercare la risposta

**PATTERN 5 — "IL TEASER"**
```
"Quello che sto per mostrarti
ha cambiato completamente il modo
in cui guardo le landing page."
```
→ Crea aspettativa per ciò che viene dopo

**PATTERN 6 — "L'ANEDDOTO VELOCE"**
Interrompi il contenuto didattico con una micro-storia.
```
"A proposito di questo, la settimana scorsa
mi è successa una cosa..."
```
→ Lo storytelling cattura istintivamente

**PATTERN 7 — "IL DISCLAIMER ONESTO"**
```
"Ok, questo punto potrebbe sembrarti banale.
Ma resta con me perché è il più importante."
```
→ Previeni l'abbandono nei punti che sembrano ovvi

**PATTERN 8 — "LA PREVIEW INTERNA"**
```
"Il prossimo punto è quello dove la maggior parte
dei miei clienti ha l'AHA moment."
```
→ Anticipa il valore della sezione successiva

**PATTERN 9 — "L'INTERAZIONE"**
```
"Fammi sapere nei commenti
se anche tu hai questo problema."
```
→ Pensa alla risposta → sta ancora guardando

**PATTERN 10 — "IL BONUS INASPETTATO"**
A metà video:
```
"Ok, visto che sei arrivato fin qui,
ti dò un bonus che non era previsto..."
```
→ Premia chi resta → incentiva a continuare

### Posizionamento consigliato:
- Almeno 1 open loop nel primo minuto
- 1 pattern interrupt ogni 2-3 minuti
- 1 teaser prima di ogni nuovo punto/sezione
- 1 bonus inaspettato a metà video
- 1 aneddoto nella seconda metà (quando l'attenzione cala naturalmente)

## CHECKLIST COMPLETA PRE-REGISTRAZIONE

### SEZIONE 1: HOOK (0-15 secondi) — 5 check

- [ ] **Cattura in meno di 5 secondi?**
  Il primo concetto/frase è abbastanza forte da impedire lo scroll?

- [ ] **Crea gap di curiosità o riconoscimento problema?**
  Lo spettatore pensa "devo sapere di più" o "questo è il mio problema"?

- [ ] **Contiene un numero specifico?**
  Es: "il 60% dei visitatori", "in 14 giorni", "3 errori"

- [ ] **NON dice "ciao ragazzi benvenuti"?**
  Zero intro generiche. Si parte direttamente col contenuto.

- [ ] **Ho scritto 3 varianti e scelto la migliore?**
  Almeno 3 hook diversi provati, il migliore selezionato.

---

### SEZIONE 2: SETUP (15-45 secondi) — 4 check

- [ ] **Lo spettatore sa ESATTAMENTE cosa otterrà?**
  Roadmap chiara: "vedrai X, Y, Z"

- [ ] **Elenca 3-4 punti specifici (non di più)?**
  Max 4 punti. Ogni punto è un loop aperto.

- [ ] **Include menzione preview della CTA?**
  Menzione 1/3: "Ho preparato [lead magnet], link in descrizione."

- [ ] **Dura meno di 30 secondi?**
  Il setup deve essere conciso. Non un secondo discorso.

---

### SEZIONE 3: CREDIBILITÀ — 3 check

- [ ] **C'è un motivo per cui ascoltare ME?**
  Perché TU sei qualificato su questo topic?

- [ ] **Mostro, non dico? (risultato, non curriculum)**
  ❌ "Ho 5 anni di esperienza" → ✅ "Ho ottimizzato 20+ funnel"

- [ ] **È sotto i 60 secondi?**
  La credibilità migliore è implicita, non un monologo.

---

### SEZIONE 4: CONTENUTO CORE — 8 check

- [ ] **C'è UNA SOLA idea centrale?**
  Un video = un concetto. Non 5 strategie + 3 tool + 2 case study.

- [ ] **È organizzato in punti/step chiari?**
  Lo spettatore sa sempre "dove siamo" nel video.

- [ ] **Ogni punto ha: affermazione + spiegazione + esempio + azione?**
  La struttura completa per ogni punto (Anchor) o atto (Shift/Conversion).

- [ ] **Ci sono screencast/visual dove possibile?**
  MOSTRA > DICI. Alterna FACCIA e SCHERMO.

- [ ] **Retention hooks ogni 2-3 minuti?**
  Almeno 1 open loop + 1 pattern interrupt ogni 2-3 min.

- [ ] **Open loops posizionati strategicamente?**
  "Tra poco ti mostro [cosa grave] — ma prima..."

- [ ] **Transizioni fluide tra punti?**
  Ogni punto "vende" il successivo. Nessun salto brusco.

- [ ] **Il linguaggio è quello del TARGET?**
  Parole dell'imprenditore, non gergo tecnico da manuale.

- [ ] **Riassume i punti in <60 secondi?**

### SEZIONE 6: CTA — 4 check

  Non "clicca il link" → "Scarica [nome] per applicare tutto da solo."

- [ ] **Include de-risking ("gratis", "senza impegno")?**
  Rimuovi il rischio percepito dall'azione.

- [ ] **C'è UNA sola azione principale?**
  Non 5 CTA diverse. UNA azione chiara. (La versione "doppia" conta come 1 se ben strutturata.)

- [ ] **C'è varietà di energia (non monotono)?**
  Alternanza di tono: calmo → energico → riflessivo → diretto.

- [ ] **Il video potrebbe essere più corto senza perdere valore?**
  Se sì → taglia. Ogni sezione deve guadagnarsi il suo posto.

- [ ] **Se togli una sezione, manca qualcosa?**

- [ ] **Lo spettatore TARGET direbbe "questo è per me" in 15 secondi?**

```python
def _calcola_timestamps(durata_sec: int, tipo: str, n_punti: int) -> dict:
    """Calcola timestamps automatici per ogni componente."""
    ts = {}
    ts["hook"] = "0:00"
    ts["setup"] = "0:15"
    ts["credibilita"] = "0:45"
    ts["contenuto_start"] = "1:15"

    # Contenuto finisce a ~80% del video
    contenuto_end_sec = int(durata_sec * 0.82)
    ts["ricap"] = _sec_to_ts(contenuto_end_sec)
    ts["cta"] = _sec_to_ts(contenuto_end_sec + 45)

    # Sottopunti del contenuto
    if n_punti > 0:
        contenuto_durata = contenuto_end_sec - 75  # dopo hook+setup+cred
        per_punto = contenuto_durata // n_punti
        ts["punti"] = []
        for i in range(n_punti):
            ts["punti"].append(_sec_to_ts(75 + (i * per_punto)))

    return ts


def _sec_to_ts(seconds: int) -> str:
    """Converte secondi in timestamp MM:SS."""
    m = seconds // 60
    s = seconds % 60
    return f"{m}:{s:02d}"

def _posiziona_retention_hooks(durata_min: int, tipo: str) -> list:
    """Posiziona i retention hooks lungo il video."""
    hooks = []

    # Open loop nel primo minuto
    hooks.append({
        "timestamp": "0:30-1:00",
        "pattern": "open_loop",
        "testo": "\"Tra poco ti mostro [punto più importante] — ma prima devi capire questo.\"",
        "nota": "Inserisci durante il setup o inizio contenuto"
    })

    # Ogni 2-3 minuti
    minuti = list(range(3, durata_min, 2))
    patterns_rotation = ["teaser", "prova_visiva", "domanda_retorica",
                         "contrasto", "preview_interna", "aneddoto"]

    for i, m in enumerate(minuti):
        pattern_key = patterns_rotation[i % len(patterns_rotation)]
        pattern = RETENTION_PATTERNS[pattern_key]
        hooks.append({
            "timestamp": f"{m}:00",
            "pattern": pattern_key,
            "testo": pattern["template"],
            "nota": pattern["posizione"]
        })

    # Bonus a metà video
    meta = durata_min // 2
    hooks.append({
        "timestamp": f"{meta}:00",
        "pattern": "bonus",
        "testo": RETENTION_PATTERNS["bonus"]["template"],
        "nota": "Premia chi è arrivato fin qui"
    })

    # CTA reminder a metà (menzione 2/3)
    hooks.append({
        "timestamp": f"{meta + 1}:00",
        "pattern": "cta_reminder",
        "testo": "\"Quello che ti sto mostrando è esattamente uno dei punti della [lead magnet] in descrizione.\"",
        "nota": "Menzione 2/3 della CTA — collegata al contenuto"
    })

    return sorted(hooks, key=lambda x: x["timestamp"])
```

```python
def valuta_script(
    titolo: str,
    risposte: dict,
    note: str = ""
) -> dict:
    """
    Valuta uno script con la checklist completa.

    Args:
        titolo: Titolo del video/script
        risposte: Dict {item_id: True/False} per ogni check
                  Es: {"H1": True, "H2": False, "H3": True, ...}
        note: Note aggiuntive opzionali

    Returns:
        Report completo con score, verdetto, punti deboli, priorità fix
    """

    report = {
        "titolo": titolo,
        "data": datetime.now().strftime("%d/%m/%Y %H:%M"),
        "sezioni": {},
        "score_totale": 0,
        "max_totale": 0,
        "punti_deboli": [],
        "top_fix": [],
        "note": note
    }

    totale_check = 0
    totale_ok = 0

    for sez_key, sezione in CHECKLIST.items():
        n_items = len(sezione["items"])
        n_ok = 0

        items_dettaglio = []
        for item in sezione["items"]:
            risposta = risposte.get(item["id"], False)
            if risposta:
                n_ok += 1
            items_dettaglio.append({
                "id": item["id"],
                "check": item["check"],
                "risultato": "✅" if risposta else "❌",
                "red_flag": item["red_flag"] if not risposta else None
            })

        pct = round((n_ok / n_items) * 100) if n_items > 0 else 0

        report["sezioni"][sez_key] = {
            "nome": sezione["nome"],
            "peso": sezione["peso"],
            "score": n_ok,
            "max": n_items,
            "percentuale": pct,
            "items": items_dettaglio
        }

        totale_check += n_items
        totale_ok += n_ok

        # Identifica punti deboli (sezioni sotto 75%)
        if pct < 75:
            failed_items = [i for i in items_dettaglio if i["risultato"] == "❌"]
            report["punti_deboli"].append({
                "sezione": sezione["nome"],
                "percentuale": pct,
                "peso": sezione["peso"],
                "items_falliti": failed_items
            })

    report["score_totale"] = totale_ok
    report["max_totale"] = totale_check
    report["percentuale_totale"] = round((totale_ok / totale_check) * 100) if totale_check > 0 else 0

    # Verdetto
    if totale_ok >= 40:
        report["verdetto"] = "✅ ECCELLENTE — Registra immediatamente"
        report["verdetto_emoji"] = "✅"
    elif totale_ok >= 35:
        report["verdetto"] = "🟡 BUONO — Migliora 2-3 punti deboli"
        report["verdetto_emoji"] = "🟡"
    elif totale_ok >= 28:
        report["verdetto"] = "🟠 MEDIOCRE — Revisione seria necessaria"
        report["verdetto_emoji"] = "🟠"
    else:
        report["verdetto"] = "🔴 DEBOLE — Riscrivi lo script"
        report["verdetto_emoji"] = "🔴"

    # Top fix — ordina punti deboli per peso sezione (priorità a sezioni critiche)
    report["punti_deboli"].sort(key=lambda x: x["peso"], reverse=True)
    fix_counter = 0
    for pd in report["punti_deboli"]:
        for item in pd["items_falliti"]:
            if fix_counter < 5:
                # Cerca errore collegato nei TOP_ERRORI
                errore_collegato = next(
                    (e for e in TOP_ERRORI if e["check_collegato"] == item["id"]), None
                )
                report["top_fix"].append({
                    "priorita": fix_counter + 1,
                    "id": item["id"],
                    "check": item["check"],
                    "sezione": pd["sezione"],
                    "red_flag": item["red_flag"],
                    "fix_suggerito": errore_collegato["fix"] if errore_collegato else "Rivedi questo punto",
                    "impatto": errore_collegato["impatto"] if errore_collegato else "Da valutare"
                })
                fix_counter += 1

    return report


def stampa_report(report: dict) -> str:
    """Formatta il report in testo leggibile."""

    lines = []

    lines.append("═" * 60)
    lines.append(f"  📋 QUALITY CHECK — \"{report['titolo']}\"")
    lines.append("═" * 60)
    lines.append(f"  Data: {report['data']}")
    lines.append("")
    lines.append(f"  SCORE: {report['score_totale']} / {report['max_totale']} ({report['percentuale_totale']}%)")
    lines.append(f"  VERDETTO: {report['verdetto']}")
    lines.append("")
    lines.append("─" * 60)
    lines.append("  PER SEZIONE:")
    lines.append("")

    for sez_key, sez in report["sezioni"].items():
        # Barra progresso
        filled = int((sez["percentuale"] / 100) * 10)
        bar = "█" * filled + "░" * (10 - filled)

        # Indicatore
        if sez["percentuale"] >= 75:
            indicator = "✅"
        elif sez["percentuale"] >= 50:
            indicator = "🟡"
        else:
            indicator = "🔴"

        stars = "⭐" * sez["peso"]
        lines.append(f"  {indicator} {sez['nome']:<20} [{sez['score']}/{sez['max']}] [{bar}] {sez['percentuale']}%  {stars}")

    # Punti deboli
    if report["punti_deboli"]:
        lines.append("")
        lines.append("─" * 60)
        lines.append("  PUNTI DEBOLI (sezioni sotto 75%):")
        lines.append("")

        for pd in report["punti_deboli"]:
            lines.append(f"  ❌ {pd['sezione']} ({pd['percentuale']}%)")
            for item in pd["items_falliti"]:
                lines.append(f"     → {item['id']}: {item['check']}")
                if item["red_flag"]:
                    lines.append(f"       🚩 {item['red_flag']}")
            lines.append("")

    # Top fix
    if report["top_fix"]:
        lines.append("─" * 60)
        lines.append("  PRIORITÀ DI FIX (dal più urgente):")
        lines.append("")

        for fix in report["top_fix"]:
            lines.append(f"  {fix['priorita']}. [{fix['id']}] {fix['check']}")
            lines.append(f"     Sezione: {fix['sezione']}")
            lines.append(f"     Fix: {fix['fix_suggerito']}")
            lines.append(f"     Impatto: {fix['impatto']}")
            lines.append("")

    # Dettaglio completo
    lines.append("─" * 60)
    lines.append("  DETTAGLIO COMPLETO:")
    lines.append("")

    for sez_key, sez in report["sezioni"].items():
        lines.append(f"  {sez['nome']}:")
        for item in sez["items"]:
            lines.append(f"    {item['risultato']} [{item['id']}] {item['check']}")
        lines.append("")

    if report["note"]:
        lines.append(f"  📝 Note: {report['note']}")

    lines.append("═" * 60)

    return "\n".join(lines)
```

```python
                "percentuale": round((score / max_score) * 100)
            }
            self.save()
        return video

    def elimina_video(self, video_id: str) -> bool:
        """Rimuove un video dal backlog."""
        video = self._find(video_id)
        if video:
            self.videos.remove(video)
            self.save()
            return True
        return False

    def _find(self, video_id: str) -> Optional[dict]:
        """Trova un video per ID."""
        return next((v for v in self.videos if v["id"] == video_id), None)

    def analisi_mix(self) -> str:
        """Analizza il mix attuale vs target per tipo e pilastro."""

        lines = []
        lines.append("═" * 70)
        lines.append("  📊 ANALISI MIX CONTENUTI")
        lines.append("═" * 70)

        totale = len(self.videos)
        if totale == 0:
            lines.append("  (backlog vuoto)")
            return "\n".join(lines)

        # ─── MIX PER TIPO ───
        lines.append("\n  MIX PER TIPO VIDEO:")
        lines.append("  " + "─" * 50)

        tipo_counts = Counter(v["tipo"] for v in self.videos)
        for tipo_key, tipo_info in TIPI_VIDEO.items():
            count = tipo_counts.get(tipo_key, 0)
            pct_attuale = round((count / totale) * 100)
            pct_target = tipo_info["target_mix"]
            diff = pct_attuale - pct_target
            status = "✅" if abs(diff) <= 10 else ("⬆️" if diff > 0 else "⬇️")

            bar_att = "█" * (pct_attuale // 5) + "░" * (20 - pct_attuale // 5)
            lines.append(
                f"  {tipo_info['emoji']} {tipo_info['nome']:<25} "
                f"{count:>3} ({pct_attuale:>3}%) target:{pct_target}% {status}"
            )

        # ─── MIX PER PILASTRO ───
        lines.append("\n  MIX PER PILASTRO:")
        lines.append("  " + "─" * 50)

        pil_counts = Counter(v["pilastro"] for v in self.videos)
        for pil_key, pil_info in PILASTRI.items():
            count = pil_counts.get(pil_key, 0)
            pct_attuale = round((count / totale) * 100)
            pct_target = pil_info["target_mix"]
            diff = pct_attuale - pct_target
            status = "✅" if abs(diff) <= 10 else ("⬆️" if diff > 0 else "⬇️")

                f"  {pil_info['emoji']} P{pil_key} {pil_info['nome']:<25} "

        lines.append("\n  PIPELINE:")
        lines.append("  " + "─" * 50)

        stato_counts = Counter(v["stato"] for v in self.videos)
        stato_emoji = {
            "idea": "💡", "backlog": "📝", "scriptato": "📄",
            "registrato": "🎥", "pubblicato": "🚀", "analizzato": "📊"
        }

        lines.append("\n  RACCOMANDAZIONI:")

    def _genera_raccomandazioni(self, tipo_counts, pil_counts, totale) -> list:
        """Genera raccomandazioni basate sul mix attuale."""
        recs = []

        # Check tipo video
        for tipo_key, tipo_info in TIPI_VIDEO.items():
            count = tipo_counts.get(tipo_key, 0)
            pct = round((count / max(totale, 1)) * 100)
            target = tipo_info["target_mix"]
            if pct < target - 15:
                recs.append(f"Servono più video {tipo_info['nome']} (attuale: {pct}%, target: {target}%)")

        # Check pilastri
        for pil_key, pil_info in PILASTRI.items():
            count = pil_counts.get(pil_key, 0)
            pct = round((count / max(totale, 1)) * 100)
            target = pil_info["target_mix"]
            if pct < target - 15:
                recs.append(f"Pilastro P{pil_key} ({pil_info['nome']}) sotto-rappresentato: {pct}% vs {target}%")

        # Check priorità alta non scriptati
        alta_non_scriptati = [v for v in self.videos
                              if v["priorita"] == "alta" and v["stato"] in ("idea", "backlog")]
        if alta_non_scriptati:
            recs.append(f"{len(alta_non_scriptati)} video ad alta priorità ancora da scriptare!")

        if not recs:
            recs.append("Mix bilanciato! ✅ Continua così.")

        return recs

        """Report performance dei video pubblicati/analizzati."""

        published = [v for v in self.videos if v.get("performance")]

            lines.append(f"  {i}. [{v['id']}] {v['titolo'][:40]} — Views: {v['performance']['views']:,}")

            tipo_videos = [v for v in published if v["tipo"] == tipo_key]

                t_ctr = sum(v["performance"]["ctr"] for v in tipo_videos) / len(tipo_videos)
                t_ret = sum(v["performance"]["avg_retention_pct"] for v in tipo_videos) / len(tipo_videos)
                t_views = sum(v["performance"]["views"] for v in tipo_videos) / len(tipo_videos)
                lines.append(
                    f"  {TIPI_VIDEO[tipo_key]['emoji']} {TIPI_VIDEO[tipo_key]['nome']:<25} "
                    f"CTR:{t_ctr:.1f}% | Ret:{t_ret:.0f}% | Avg Views:{t_views:.0f}"
                )

        # Performance per pilastro
        lines.append(f"\n  PERFORMANCE PER PILASTRO:")
        lines.append("  " + "─" * 50)
        for pil_key in PILASTRI:
            pil_videos = [v for v in published if v["pilastro"] == pil_key]
            if pil_videos:
                p_ctr = sum(v["performance"]["ctr"] for v in pil_videos) / len(pil_videos)
                p_views = sum(v["performance"]["views"] for v in pil_videos) / len(pil_videos)
                lines.append(
                    f"  {PILASTRI[pil_key]['emoji']} P{pil_key} {PILASTRI[pil_key]['nome']:<25} "
                    f"CTR:{p_ctr:.1f}% | Avg Views:{p_views:.0f}"
                )

        with_quality = [v for v in published if v.get("quality_score")]

            lines.append(f"\n  CORRELAZIONE QUALITY SCORE → PERFORMANCE:")
            lines.append("  " + "─" * 50)
            high_q = [v for v in with_quality if v["quality_score"]["percentuale"] >= 80]

                lines.append(f"  Quality <80%: CTR medio {lq_ctr:.1f}% ({len(low_q)} video)")

        lines.append(f"\n{'═' * 70}")
        return "\n".join(lines)

    def _seleziona_bilanciato(self, candidati: list, n: int) -> list:
        """Seleziona video bilanciando il mix tipo/pilastro."""
        selezionati = []
        tipi_usati = []

        for v in candidati:
            if len(selezionati) >= n:
                break
            # Evita troppi dello stesso tipo nella stessa settimana
            if v["tipo"] in tipi_usati and len(selezionati) < n - 1:
                continue
            selezionati.append(v)
            tipi_usati.append(v["tipo"])

        # Se non abbiamo abbastanza, aggiungi i rimanenti per priorità
        if len(selezionati) < n:
            for v in candidati:
                if v not in selezionati and len(selezionati) < n:
                    selezionati.append(v)

        return selezionati

    def suggerisci_prossimo_video(self) -> str:
        """Suggerisce il prossimo video da produrre basandosi su gap nel mix."""

        lines = []

        lines.append("  💡 SUGGERIMENTO PROSSIMO VIDEO")
        lines.append("═" * 70)

        totale = max(len(self.videos), 1)

        # Trova tipo più carente
        tipo_counts = Counter(v["tipo"] for v in self.videos)
        tipo_gap = {}
        for t_key, t_info in TIPI_VIDEO.items():
            attuale = round((tipo_counts.get(t_key, 0) / totale) * 100)
            tipo_gap[t_key] = t_info["target_mix"] - attuale

        tipo_suggerito = max(tipo_gap, key=tipo_gap.get)

        # Trova pilastro più carente
        pil_counts = Counter(v["pilastro"] for v in self.videos)
        pil_gap = {}
        for p_key, p_info in PILASTRI.items():
            attuale = round((pil_counts.get(p_key, 0) / totale) * 100)
            pil_gap[p_key] = p_info["target_mix"] - attuale

        pil_suggerito = max(pil_gap, key=pil_gap.get)

        lines.append(f"\n  Tipo suggerito: {TIPI_VIDEO[tipo_suggerito]['emoji']} "
                     f"{TIPI_VIDEO[tipo_suggerito]['nome']} "
                     f"(gap: {tipo_gap[tipo_suggerito]:+d}%)")
        lines.append(f"  Pilastro suggerito: {PILASTRI[pil_suggerito]['emoji']} "
                     f"P{pil_suggerito} {PILASTRI[pil_suggerito]['nome']} "
                     f"(gap: {pil_gap[pil_suggerito]:+d}%)")

        # Prerequisiti per tipo
        lines.append(f"\n  PREREQUISITI:")
        if tipo_suggerito == "anchor":
            lines.append(f"  □ Keyword target (ricerca Google, YouTube)")
        elif tipo_suggerito == "shift":
            lines.append(f"  □ Credenza sbagliata da smontare (dai commenti, call, ricerca)")
        elif tipo_suggerito == "conversion":
            lines.append(f"  □ Caso studio con numeri (progetto completato)")

        lines.append(f"  □ Lead magnet da collegare")
        lines.append(f"  □ Takeaway memorabile")

        # Video esistenti in questo gap
        gap_videos = [v for v in self.videos
                      if v["tipo"] == tipo_suggerito and v["pilastro"] == pil_suggerito
                      and v["stato"] in ("idea", "backlog")]
        if gap_videos:
            lines.append(f"\n  VIDEO GIÀ IN BACKLOG per questo gap:")
            for v in gap_videos[:3]:
                lines.append(f"  → [{v['id']}] {v['titolo']}")

        lines.append(f"\n{'═' * 70}")
        return "\n".join(lines)

def _valuta_metrica(valore: float, benchmark: dict) -> str:
    """Valuta una metrica contro i benchmark."""
    if valore >= benchmark["eccellente"]:
        return "🌟 Eccellente"
    elif valore >= benchmark["buono"]:
        return "✅ Buono"
    elif valore >= benchmark["medio"]:
        return "🟡 Medio"
    else:
        return "🔴 Basso"
```
