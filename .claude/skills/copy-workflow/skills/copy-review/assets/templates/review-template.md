# Review Template — Template Operativo

> Usa questo template per completare una Full Review in modo strutturato. Ogni sezione ha istruzioni su come compilarla. Completa dall'alto verso il basso — l'analisi APSOC alimenta il punteggio.

---

## INTESTAZIONE

```
Copy Review — [IDENTIFICAZIONE]
Data: _______________________________________________
Reviewer: _______________________________________________
Tipo copy: [ ] Ad  [ ] Sales Page  [ ] Email  [ ] Landing Page  [ ] VSL  [ ] Social Post  [ ] Altro: ___
Prodotto/Servizio: _______________________________________________
Target presunto: _______________________________________________
Parole totali: ___ parole
Tipo acquisto: [ ] Impulso (<€50)  [ ] Considerato (€50-500)  [ ] High-ticket (>€500)
```

---

## STEP 1 — ANALISI STRUTTURALE

> Prima di leggere in dettaglio, identifica la struttura. Questo rivela i problemi fatali in 2 minuti.

```
Struttura identificata:
[ ] Ha headline separata dal body
[ ] Ha sezione P (problema) identificabile
[ ] Ha sezione S (soluzione) identificabile
[ ] Ha sezione O (obiezioni) identificabile
[ ] Ha CTA chiara

Ordine sezioni trovato (es. A → P → S → O → C):
_______________________________________________

PROBLEMI STRUTTURALI IMMEDIATI:
[ ] Soluzione compare prima del problema (dove: riga ___)  → -15 punti automatici
[ ] Nessuna headline / apertura debole
[ ] CTA assente o nascosta
[ ] Copy senza struttura visiva (muri di testo)
```
