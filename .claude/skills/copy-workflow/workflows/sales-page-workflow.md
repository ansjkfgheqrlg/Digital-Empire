# Sales Page Workflow
> Produzione di una sales page completa (1000-5000 parole)

**Durata**: 90-120 minuti (pipeline completo)
**Agenti usati**: Tutti (A1-A8)
**Score QA target**: ≥ 85

---

## Anatomia della Sales Page

Una sales page efficace ha questa struttura:

```
┌─────────────────────────────────┐
│    HEADLINE + SOTTOTITOLO       │ ← A3 (attenzione)
├─────────────────────────────────┤
│    APERTURA / HOOK              │ ← A3
├─────────────────────────────────┤
│    PROBLEMA + PAIN POINT        │ ← A4
│    (storytelling o scenario)    │
├─────────────────────────────────┤
│    CONSEGUENZA DEL NON AGIRE    │ ← A4
├─────────────────────────────────┤
│    CTA SOFT #1                  │ ← A7 (primo CTA)
├─────────────────────────────────┤
│    PRESENTAZIONE SOLUZIONE      │ ← A5
│    + USP + CHI SONO             │
├─────────────────────────────────┤
│    VANTAGGI (lista benefits)    │ ← A5
├─────────────────────────────────┤
│    CHIAREZZA POST-ACQUISTO      │ ← A5
├─────────────────────────────────┤
│    TESTIMONIANZE / SOCIAL PROOF │ ← A6 (prova #1)
├─────────────────────────────────┤
│    OBIEZIONE #1 (CPB)           │ ← A6
├─────────────────────────────────┤
│    OBIEZIONE #2 (CPB)           │ ← A6
├─────────────────────────────────┤
│    [OBIEZIONE #3 se necessario] │ ← A6
├─────────────────────────────────┤
│    CTA MEDIO #2 + URGENZA       │ ← A7
├─────────────────────────────────┤
│    FAQ (obiezioni residue)      │ ← A6 lite
├─────────────────────────────────┤
│    GARANZIA                     │ ← A6
├─────────────────────────────────┤
│    CTA CLOSING #3 (finale)      │ ← A7 (più forte)
│    + URGENZA + CONSEGUENZA      │
└─────────────────────────────────┘
```

## Pipeline Dettagliato

### Fase 1 — Briefing Esteso (A1)

Per le sales page il briefing richiede più dettagli:

```
OBBLIGATORI:
□ Prodotto + prezzo esatto
□ Target preciso (A2 costruirà l'avatar)
□ USP (se non esiste → A5 lo costruisce)
□ Risorse disponibili: testimonianze / dati / garanzie
□ Posizione nel funnel (il lead arriva da dove?)

IMPORTANTI:
□ Copy passati (cosa ha convertito / non ha convertito)
□ Competitor + come si posizionano
□ Expected CR (conversion rate target)
□ Lunghezza desiderata (1000 / 2500 / 5000 parole?)
□ Obiezioni già note dal cliente
```

### Fase 2 — Avatar + Ricerca Profonda (A2)

Per sales page, A2 deve produrre:
- Avatar **dettagliatissimo** (scenario quotidiano completo)
- **Almeno 5 obiezioni** (non 3)
- Language map con frasi reali (se possibile, citazioni da forum/recensioni)
- Mappa emotiva completa con 5 leve

### Fase 3 — Scrittura Sales Page Sezione per Sezione

**A3 — Headline + Sottotitolo + Apertura**
- 3 headline alternative
- 1 sottotitolo
- Hook di apertura (4-6 paragrafi)

**A4 — Problema Espanso**
- Storytelling del problema (personale o avatar)
- Pain point amplificato in 3 livelli (vedi framework amplificazione in A4)
- Conseguenza del non agire (breve/medio/lungo termine)

**A5 — Soluzione Completa**
- Transizione e presentazione prodotto
- USP ben articolato
- **Almeno 5 benefits** (non features)
- Chiarezza post-acquisto obbligatoria
- Chi sei/cos'è il brand (brevemente, con hook credibile)

**A6 — Obiezioni (Sales Page Full)**
- **CPB completo per le 3 obiezioni principali**
- Testimonianza reale (o simulata con nota) integrata
- Social proof quantitativo (es. "oltre 1.000 clienti")
- Garanzia (reale o finta con disclaimer)
- FAQ sezione con 5-7 domande comuni

**A7 — 3 CTA + Urgenza**
- CTA #1 soft (dopo problema): "Voglio saperne di più"
- CTA #2 medio (dopo soluzione): "Inizia ora"
- CTA #3 closing (after obiezioni): il più potente, con urgenza piena

### Fase 3 — QA con A8 (target score ≥ 85)

Per le sales page il threshold è più alto (85 invece di 80).
Se score < 85 → iterazione obbligatoria sulla sezione più debole.

## Lunghezza per Tipo di Prodotto

| Tipo Prodotto | Lunghezza Consigliata | Note |
|---|---|---|
| Info product / Corso online | 2500-4000 parole | Molte obiezioni da gestire |
| Software / SaaS | 1500-2500 parole | Più visual, meno copy |
| Consulenza / Servizio | 2000-3500 parole | Focus su trust e prova sociale |
| Prodotto fisico low-ticket | 800-1500 parole | Breve, impulsivo |
| Prodotto fisico high-ticket | 2000-4000 parole | Come un consulenza |
| Corso high-ticket > €2000 | 4000-6000 parole | Pipeline lungo, max persuasione |

## Regole Specifiche per Sales Page

### 1. Non iniziare MAI con il brand/prodotto
La prima cosa che legge il target deve riguardare LUI, non te.
❌ "Benvenuto su [Brand]! Siamo un'azienda che..."
✅ "Se ogni mattina ti alzi già stanco di [problema]..."

### 2. Struttura visiva obbligatoria
Il copy di A8 deve includere istruzioni per il designer:
- Ogni sezione principale → titolo H2 o H3
- Ogni lista di benefici → bullet list
- Ogni testimonianza → box visivamente separato
- CTA → pulsante evidenziato (colore diverso)
- Testo importante → **grassetto**

### 3. Regola della scansione
Il target non legge tutto — scansiona. Verifica che:
- Leggendo solo i titoli di sezione si capisca l'intera proposta
- Leggendo solo i bullet list si capiscano i benefici principali
- Leggendo solo i CTA si capisca cosa fare

### 4. Lunghezza dei paragrafi
- Max 4-5 righe per paragrafo
- Ogni paragrafo = un'idea
- Alterna paragrafi brevi (2-3 righe) con paragrafi normali

### 5. Formula promessa-credibilità
⚠️ Più alta è la promessa, più prove servono.
Se prometti "guadagnerai 10.000€ in 30 giorni" → hai bisogno di 5+ prove solide.
Se prometti "migliorai il tuo copy" → 1-2 prove bastano.
