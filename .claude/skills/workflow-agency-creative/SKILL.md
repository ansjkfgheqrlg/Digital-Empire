# Workflow Agency Creative

Sistema di produzione contenuti creativi per Digital Empire agency.

## Quando usarla

USE THIS SKILL when the user wants to:
- Generate Instagram carousels for agency or pre-sales
- Run the creative production pipeline
- Create product carousels from templates
- Automate carousel generation with caroselli.py

## Struttura

- `caroselli.py` — Script principale generazione caroselli
- `caroselli_prodotti.json` — Template prodotti per caroselli
- `Arsenale Caroselli/` — Asset e template caroselli
- `caroselli - agency/` — Caroselli per brand agency
- `caroselli - preventa/` — Caroselli per preventa
