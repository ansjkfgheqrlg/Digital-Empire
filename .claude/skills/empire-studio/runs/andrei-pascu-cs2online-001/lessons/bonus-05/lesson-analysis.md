## Knowledge Atoms

| ID | Atom | Fonte |
|---|---|---|
| KA-01 | Differenza tra prompt isolato (domanda singola → risposta → fine) e progetto continuo: nel progetto il loop prompt-risposta si ripete e Claude accumula context nel tempo, invece di ripartire da zero ogni volta. | "Cosa hai imparato" + frame t3m10s |
| KA-02 | 3 vantaggi chiave dei Projects in Cowork: (1) memoria specifica per progetto, (2) file allegati persistenti, (3) accesso diretto a una cartella sul device — non serve riallegare/ricondividere materiale a ogni nuovo task. | "Cosa hai imparato" |
| KA-03 | Metodo organizzativo di Andrei: un Project Cowork per singolo cliente, con cartella condivisa e tutti i file del cliente dentro quella cartella. | "Cosa hai imparato" |
| KA-04 | 3 modalità Claude distinte (chat, Cowork, Claude Code da terminale) — strategia consigliata: provarle tutte fino a sviluppare intuizione su quando usare quale, non esiste una risposta univoca. | "Cosa hai imparato" |
| KA-05 | Possibilità di creare un nuovo Project in Cowork oppure importarne uno già esistente dalla chat normale — non serve ricominciare da zero se il progetto esiste già altrove. | "Cosa hai imparato" |
