## Le 12 categorie di task (fonte primaria, integrale)

| # | Categoria | Nota dell'autore |
|---|---|---|
| 1 | Copywriting | Sales page, email, caption, ad, opt-in, FAQ, pop-up |
| 2 | Ricerca | "Il topic più interessante per me" — usa Perplexity + Google Scholar (solo paper) + AI per sintesi |
| 3 | Ideazione/brainstorming | Task che convince MENO l'autore stesso ("lo faccio spesso con la mia testa") |
| 4 | Web dev / vibe coding | La sales page del corso è fatta così: copy/immagini umani, struttura AI |
| 5 | Analisi e strategia | Supporto decisionale tra opzioni, richiede contesto sufficiente |
| 6 | Organizzazione e planning | Prioritizzazione task settimanali con Claude |
| 7 | Comunicazione | Email clienti/brief — **regola esplicita**: "controllate sempre quello che scrive l'AI, sempre" |
| 8 | Revisione ed editing | Es. revisione veloce contratti per errori |
| 9 | Automazioni | Rimando ad altre lezioni |
| 10 | Problem solving | Stress-test di ragionamenti/business plan per bias logici |
| 11 | Analisi dati | Spreadsheet — **warning esplicito**: "qui tende a inventarsi cose, controllate" |
| 12 | Formattazione e struttura | Riassumere, riorganizzare headline, strutturare contenuti |
