## SOP domenicale completa (fonte primaria)

1. Google Calendar: inserire prima gli impegni fissi/non negoziabili (call team, meeting clienti, palestra) → definisce il tempo disponibile
2. Esportare/collegare il calendario a Claude (Settings→Import/Export, o integrazione nativa "+")
3. Brain dump in Markdown: tutti i task che vengono in mente, senza filtro, con contesto scritto nel file stesso e vincoli specifici (es. scadenze non negoziabili)
4. Allegare business plan (obiettivi/scadenze) per la prioritizzazione
5. Allegare review settimana precedente (cosa fatto/non fatto)
6. Prompt a Claude (Opus + Extended Thinking) → genera documento con task per fascia oraria (8-12, 12-15, 15-18) e assegnazione (umano/AI/50-50)
