## Panoramica ufficiale

In questa lezione impari come funzionano i Projects dentro Cowork, la nuova feature che ti permette di avere context persistente e chat continue direttamente in Cowork. Scopri la differenza tra Cowork, chat normale e Claude Code, quando usare ciascuno, e come organizzare i tuoi progetti per cliente con cartelle condivise. Il vantaggio principale: non devi più ricondividere il context a ogni nuovo task.

## "Cosa hai imparato" (ufficiale, integrale)

- Come funzionano i Projects dentro Cowork e perché sono diversi dai Projects in chat normale
- Che esistono più modi per usare Claude (chat, Cowork, Claude Code da terminale) e che la strategia migliore è provarli tutti fino a sviluppare un'intuizione
- Come creare un nuovo Project dentro Cowork o importarne uno già esistente dalla chat normale
- Come collegare una cartella locale del tuo computer a un Project Cowork per avere un database condiviso
- La differenza tra un prompt isolato (domanda singola → risposta → fine) e un progetto continuo dove il loop prompt-risposta si ripete e Claude accumula context
- Che i Projects in Cowork hanno tre vantaggi chiave: memoria specifica per progetto, file allegati, e accesso diretto a una cartella sul tuo device
- Come organizzare i Projects per singolo cliente, con cartella condivisa e tutti i file dentro
- Che grazie ai Projects in Cowork non devi più riallegare il context o ricondividere materiale manualmente a ogni nuovo task
