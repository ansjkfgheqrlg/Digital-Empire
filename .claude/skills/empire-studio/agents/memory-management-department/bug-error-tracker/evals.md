- **Voto:** PASS se il criterio sopra e soddisfatto

- **Input:** bug su un agente

- **Voto:** PASS se il criterio sopra e soddisfatto

## EV-03 - Stato
- **Input:** bug risolto

- **Voto:** PASS se il criterio sopra e soddisfatto

## EV-04 - Categoria
- **Input:** errore runtime
- **Atteso:** in errors/ non bugs/
- **Voto:** PASS se il criterio sopra e soddisfatto
