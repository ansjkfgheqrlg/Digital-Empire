# session-archiver (L3 - memory-management-department)

**Ruolo:** Archivia le sessioni/run (log conversazionale + avanzamento) in memory/sessions/, supportando il layer short-term del two-layer.
**Reparto:** memory-management-department · **Livello:** L3 · **Lead:** department-lead
**Skill usate:** (usa i tool del reparto)

**Responsabilita':**
- Creare un SES per ogni run con il log significativo.
- Mantenere il layer short-term (stato conversazionale della run).
- Collegare la sessione ai CP/decisioni della run.
- Archiviare in modo che la run sia ricostruibile.

**Input (handoff in):** log della run dal Conductor.
**Output (handoff out):** SES in memory/sessions/.
**Quando si attiva:** su handoff dal lead del reparto

**Trace (P12):** risponde a 'ogni sessione deve essere aggiornata'.
