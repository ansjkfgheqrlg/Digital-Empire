# department-strategist - Playbook

## Flusso operativo
1. Conoscere le esigenze specifiche di ogni reparto (durata, capitoli, densita' frame, stile wiki).
2. Consigliare la strategia di reparto al coordinator.
3. Segnalare quando un input richiede una strategia ibrida (es. canale misto).
4. Mantenere aggiornate le strategie di reparto nel registry (con meta-manager).

## Esempi
- Happy: input valido -> department-strategist produce l'output atteso con trace.
- Edge: input parziale/incompleto -> procede col disponibile e dichiara la limitazione.
- Failure-recovery: errore tool -> registra in memory/errors e ritenta/escala al lead.

## Handoff in uscita
Al reparto successivo (o al verification/forge) con summary + trace.
