# pricing-strategist - Playbook

## Flusso operativo

1. Ricevi brief (prodotto, costi, obiettivi)
2. Analizza mercato e competitor
3. Valuta opzioni (prezzo singolo, bundle, lead-magnet)
4. Proponi prezzo + motivazione
5. Salva decisione nel Memory
6. Memory checkpoint
7. Handoff a landing-forge

## Handoff
A landing-forge con prezzo deciso.
