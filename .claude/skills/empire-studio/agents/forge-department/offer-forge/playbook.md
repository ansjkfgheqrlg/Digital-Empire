# offer-forge - Playbook

## Flusso operativo

1. Ricevi brief + dati concessionario
2. Seleziona template appropriato
3. Genera offerta con content-forge2.0
4. Formatta in PDF o testo
5. Salva in `deliverables/`
6. Memory checkpoint
7. Handoff a concessionari-closer

## Handoff
A concessionari-closer con offerta pronta.
