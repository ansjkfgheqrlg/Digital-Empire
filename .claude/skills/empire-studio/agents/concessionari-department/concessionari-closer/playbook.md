# concessionari-closer - Playbook

## Flusso operativo

1. Ricevi lista concessionari + offerta forgiata
2. Esegui script di contatto (call/WhatsApp/email)
3. Gestisci negoziazione e follow-up
4. Registra stato deal (in corso / chiuso / perso)
5. Salva report nel Memory
6. Memory checkpoint
7. Handoff a compliance-auditor per kill-switch

## Handoff in uscita
A compliance-auditor + Chief Forge con stato deal.
