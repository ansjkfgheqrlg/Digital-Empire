## LEGGE (non derogabile)
1. **§13 SOLO AGGIUNGERE.** Non toccare NESSUN file che esiste già, tranne quelli elencati come «nostri» qui sotto. `page.tsx`, `layout.tsx`, `hero.tsx`,
   `globals.css`, `vivo.css`, tutto `src/components/**`: **vietato** (li inserisce Emperator). Tu crei SOLO file nuovi in `src/sezioni-aggiunte/` e UN file CSS
   nuovo `src/app/aggiunte-<tuo-blocco>.css`. File «nostri» modificabili: `src/sezioni-aggiunte/specchio.tsx`, `prove-vere.tsx`, `cosa-ottieni.tsx` (nati il 12/09).
2. **§14 IMMAGINE INTERA.** Ogni `<img>` di contenuto: `width`/`height` reali, `alt` che descrive, `loading="lazy" decoding="async"`, contenitore con
   `aspect-ratio: w/h`, **mai `object-fit: cover`, mai ingrandita oltre il suo pixel** (larghezza CSS ≤ larghezza nativa; per i file piccoli ≤ nativa/1).
   **Mai grana o gradiente sopra il soggetto**: la classe `.foto` di vivo.css (cover + grana) NON si usa. Usa `<figure class="foto-intera">` (definiscila tu nel tuo CSS:
   `margin:0; border-radius:6px; overflow:hidden; background:#000; img{display:block;width:100%;height:auto}`). La riga di testo va **sotto** la figura
   (`<figcaption>`), tranne dove il brief dice «sopra» (D5): allora in `<figcaption>` assoluta in basso, corsivo serif `var(--font-serif)` peso 400, 18px,
   banda `linear-gradient(180deg, transparent, rgba(0,0,0,.62) 45%, rgba(0,0,0,.84))`, niente text-shadow pesante.
3. **§15 RITMO.** Nessuna CTA di vendita nuova nelle sezioni che stanno sopra metà pagina (Atto I-III): lì solo micro-CTA di scorrimento («↓», ancore).
   Le CTA di vendita (`<Link href={prenotaDa("Axx")} className="sv-btn">`) solo in Atto IV-VI.
4. **§6/§8 NUMERI.** Nessun numero scritto a mano: `FATTI` da `@/lib/fatti`, prezzi da `@/lib/listino` (`eur(LISTINO.outreach)`, `MESI_PAREGGIO`, `SAAS_ANNO`,
   `RISPARMIO_ENGINE`). Numeri ammessi = quelli in `cantieri/agency-empire-landing-vivo/FATTI.md`. Se un numero non c'è, la frase non lo dice.
5. **VOCE.** Prima persona plurale/singolare («noi», «ti», «Max»), frasi corte, niente «rivoluzionario/innovativo/soluzione/leader», niente claim senza fonte,
   niente canoni promessi. Copy della tavola v2.1 = riferimento (riportato sotto per ogni sezione).
6. **CANONE CSS.** Ogni sezione: `<div className="vivo"><section id="..." className="sv sv-<superficie> sv-section" aria-labelledby="..."><div className="sv-container">…`.
   Superfici: `sv-ink` (scuro), `sv-carta` (chiaro), `sv-stanza`, `sv-fascia` (arancione pieno: SOLO D4). Classi tipografiche esistenti: `sv-h2 sv-h3 sv-lead sv-body
   sv-muted sv-mono sv-eyebrow sv-it sv-btn sv-btn-ghost sv-hair`. Colori: `--sv-orange #fb4604`, `--sv-silver`, ink `#0a0a0a/#1c1c1c`, carta `#faf6ee`.
   Le TUE regole nuove: tutte prefissate `.vivo .` + una classe tua (es. `.vivo .scala`), mai selettori generici. **Grana**: la superficie `sv-*` la porta già;
   su ogni superficie composta che aggiungi (card, blocco arancione, sfumatura) metti una grana locale in `::after` (feTurbulence data-uri, `mix-blend-mode:
   overlay` o `multiply`, opacity .3-.5) — legge di Max: la grana sta su tutto, anche sulle sfumature. **Mai sulle foto.**
7. **MOVIMENTO.** Ogni animazione dentro `@media (prefers-reduced-motion: no-preference)` o spenta in `reduce`. 0 KB di JS nuovo salvo dove indicato.
8. **ALTEZZA.** Rispetta `h max` di ogni aggiunta (tolleranza +15%). Mobile: in colonna, mai overflow orizzontale (`overflow-x` mai sul body).
9. **PEZZI CHE MANCANO.** Ritratti veri, foto di lavoro, video, dati legali: **non esistono ancora**. Il componente legge da `@/lib/media` (`RITRATTI`, `TEXTURE`)
   e se il pezzo è `null` rende `null` (o la variante senza immagine dove indicato). Mai inventare un nome, un dato legale, un numero.
10. **CONSEGNA.** Ogni componente esporta una funzione con nome PascalCase dal file indicato. Alla fine: `cd agency-empire-landing && npx tsc --noEmit -p .`
    deve passare (o `npm run build`). NON deployare, NON committare, NON toccare `page.tsx`. Riporta: file creati, export, dove va inserito, altezza stimata, dubbi.
