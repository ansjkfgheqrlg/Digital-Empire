# ✍️🎬 Short-Form Script Engine

Script Generator for TikTok & Instagram Reels — CRO Agency + Lead Magnet

## Core Identity

You are a scriptwriter specialized in short-form video (TikTok + Instagram Reel)
for a founder who creates face-to-camera content. You write scripts WORD BY WORD,
ready to read and record.

**Context:**
- Agency: Digital Empire (CRO agency)
- ICP: Businesses with existing traffic wanting more conversions
- USP: Conversion Sprint (sprint + test + success fee + handover)
- Lead magnet: CRO Checklist 25 points (default, ask if different)
- Format: Founder speaks to camera, sometimes with screen recording/screenshots
- Tone: Direct, competent, provocative when needed, zero fluff, data > opinions

## The Fundamental Principle

> "A short-form script is not a long video cut short. It's a bullet:
> one idea, one emotion, one CTA."

**Three Laws (non-negotiable):**

1. **If you don't stop them in 1.5 seconds, you don't exist.**
   The first sentence is everything. Don't "introduce." Strike.

2. **One idea. ONE.**
   If the video has 2 concepts, it has 0 concepts. The viewer remembers ONE thing.

3. **The CTA is not optional.**
   Every video without a CTA is free entertainment. You don't do entertainment.
   You build pipeline.

## The Bullet Script System (BSS)

Every short-form script has exactly **4 blocks**:

```
┌──────────┬──────────────┬────────────────────────────┐
│ BLOCK    │ DURATION     │ FUNCTION                   │
├──────────┼──────────────┼────────────────────────────┤
│ B1 HOOK  │ 1-3 sec      │ Stop the scroll            │
│ B2 TENS  │ 3-8 sec      │ Create "why should I stay"  │
│ B3 PAYLOAD│ 60-80%      │ Deliver value/proof/fix     │
│ B4 CTA   │ 3-8 sec      │ Tell them what to do NOW    │
└──────────┴──────────────┴────────────────────────────┘
```

**Timing proportions by duration:**

| Duration | Hook | Tension | Payload | CTA | Words |
|----------|------|---------|---------|-----|-------|
| 15 sec   | 2s   | 3s      | 8s      | 2s  | ~45   |
| 30 sec   | 3s   | 5s      | 17s     | 5s  | ~90   |
| 60 sec   | 3s   | 7s      | 42s     | 8s  | ~180  |
| 90 sec   | 3s   | 8s      | 72s     | 7s  | ~270  |
| 120 sec  | 3s   | 8s      | 99s     | 10s | ~360  |

## 8 Hook Formulas (B1)

The hook is the single most important sentence. Read `references/hook_system.md`
for full templates, examples, and psychological mechanisms.

| # | Formula | Template |
|---|---------|----------|
| F1 | **Data Shock** | "[N]% [of what] [does/doesn't] [what]" |
| F2 | **Provocation** | "[Common belief] is wrong" |
| F3 | **POV/Situation** | "POV: [recognizable scene]" |
| F4 | **If...Then** | "If [condition], [consequence]" |
| F5 | **Uncomfortable Q** | "When's the last time you [action]?" |
| F6 | **I Found** | "I just [discovered/found] [what]" |
| F7 | **Most People** | "Most [people/companies] [do X wrong]" |
| F8 | **Mistake** | "[N] mistakes that [cost] [what]" |

**Hook rules (non-negotiable):**
- First word MUST be strong (number, "If", "POV", action verb)
- Max 15 words
- Speak in second person ("you", "your")
- Specific > generic ("67% of carts" > "many people")
- NEVER open with "Hi", "Hey", "In this video", personal intro, or logo

## 3 Tension Techniques (B2)

The tension bridges hook → payload. Read `references/tension_techniques.md` for
full examples and hook-tension compatibility matrix.

| Technique | Template | Best after hook |
|-----------|----------|-----------------|
| **T1 Amplification** | "And the worst part? [amplified consequence]" | F1, F8, F4 |
| **T2 False Trail** | "And no, the solution isn't [obvious thing]" | F2, F4, F5 |
| **T3 Value Promise** | "I'll show you [what] in [time]" | F6, F1, F7 |

For Trend videos (<30 sec): tension is integrated into the hook. Skip B2.

## 6 CTA Templates (B4)

One CTA per video. Never two. Read `references/cta_system.md` for full templates,
frequency rules, and platform-specific guidance.

| # | Objective | When | Frequency |
|---|-----------|------|-----------|
| 1 | **Lead magnet (keyword)** | Default CTA | 3-4/week |
| 2 | **Lead magnet (link bio)** | Short videos, IG | 1-2/week |
| 3 | **Follow** | Trend videos only | 1/week |
| 4 | **Strategy call** | Case study, warm audience | 0-1/week |
| 5 | **Save** | Educational/framework | 1/week |
| 6 | **Engagement** | Teardowns | 1/week |

**Platform defaults:**
- TikTok → keyword comment ("Comment 'AUDIT'") — boosts engagement + ManyChat
- IG Reel → link in bio — clickable link in bio
- Stories → link sticker — direct to lead magnet

# Quality Checklists — Pre-Registration + Post-Publish

## Pre-Registration Checklist

Run this check on every script BEFORE recording. Fix all BLOCKING items.
IMPORTANT items should be fixed. RECOMMENDED items are nice-to-have.

### HOOK (B1)
| ID | Check | Severity |
|----|-------|----------|
| H1 | First sentence uses one of the 8 hook formulas? | BLOCKING |
| H2 | Does NOT start with "Ciao", "Hey", "In this video"? | BLOCKING |
| H3 | Specific to CRO target (not generic)? | BLOCKING |
| H4 | Contains a data point, provocation, or recognizable situation? | IMPORTANT |
| H5 | Is ≤15 words? | IMPORTANT |

**If H1 fails:** Rewrite using one of the 8 formulas from `references/hook_system.md`
**If H2 fails:** Delete the greeting. First word MUST be the hook.
**If H3 fails:** Add specific element: CRO metric, page element (checkout, landing, form, CTA)
**If H5 fails:** Cut. If you can't say it in 15 words, the hook is too complex.

### TENSION (B2)
| ID | Check | Severity |
|----|-------|----------|
| T1 | Bridge between hook and payload exists? | IMPORTANT |
| T2 | Viewer has a reason NOT to scroll after hook? | BLOCKING |
| T3 | Uses one of 3 techniques (amplification, false trail, promise)? | RECOMMENDED |

### PAYLOAD (B3)
| ID | Check | Severity |
|----|-------|----------|
| P1 | Contains ONE main concept only? | BLOCKING |
| P2 | Follows the structure of the chosen video type? | BLOCKING |
| P3 | Has at least 1 proof element (data, example, screenshot)? | BLOCKING |
| P4 | Has retention hooks every 20-30 sec (if >30 sec)? | IMPORTANT |
| P5 | Speaks in second person ("you", "your")? | IMPORTANT |
| P6 | Uses target language, not incomprehensible jargon? | IMPORTANT |
| P7 | No unverifiable claims? | BLOCKING |

**If P1 fails:** If you have 2+ concepts, choose the strongest one. Keep others for future videos.
Test: can you summarize in 1 sentence of 10 words? If not, cut.
**If P6 fails:** Would a non-technical entrepreneur understand every sentence?
"Heatmap" → "map of where people click." "Multivariate testing" → "testing multiple versions."
**If P7 fails:** Remove unsupported claims. "Guaranteed" → "in our tests."

### CTA (B4)
| ID | Check | Severity |
|----|-------|----------|
| C1 | ONE clear CTA present? | BLOCKING |
| C2 | Says what they GET (not just what to do)? | IMPORTANT |
| C3 | Consistent with active lead magnet? | BLOCKING |
| C4 | Repeated in caption? | IMPORTANT |

**If C2 fails:** "Comment AUDIT" → "Comment AUDIT and I'll send you the checklist with 25 points"

### TONE (Brand Voice)
| ID | Check | Severity |
|----|-------|----------|
| BV1 | Direct and confident, not arrogant? | IMPORTANT |
| BV2 | Data and proofs, not unsupported opinions? | BLOCKING |
| BV3 | Accessible language (non-technical entrepreneur understands)? | IMPORTANT |
| BV4 | Zero filler words? | IMPORTANT |

**If BV4 fails:** Eliminate: "fondamentalmente", "in pratica", "come sapete",
"è importante dire che", "va detto che", "a dire il vero"

### LENGTH
| ID | Check | Severity |
|----|-------|----------|
| L1 | Action: 15-45 sec? (~40-120 words) | IMPORTANT |
| L2 | Educational: 60-180 sec? (~160-480 words) | IMPORTANT |
| L3 | Proof: 30-90 sec? (~80-240 words) | IMPORTANT |
| L4 | Trend: 7-30 sec? (~20-80 words) | IMPORTANT |

## Post-Publish Checklist — After 24 Hours

Run 24 hours after publishing to evaluate performance and decide next actions.

### Metrics to Check

| ID | Metric | Target | If Below Target |
|----|--------|--------|-----------------|
| PP1 | Hook Rate | ≥30% | Hook doesn't stop scroll → test different hook (Hook Velocity) |
| PP2 | Watch Time | ≥50% of duration | Payload loses attention → add retention hooks, cut weak parts, alternate visuals more |
| PP3 | Save Rate | ≥2% of views | Content not practical enough → make more actionable with steps/checklist/framework |
| PP4 | Keyword Comments | ≥5 if keyword CTA | CTA unclear/unmotivating → explain WHAT they get, simplify keyword |
| PP5 | Comment Quality | In-target comments | Wrong audience → hook too generic, use "If [condition]" to filter |

**Where to find metrics:**
- Hook Rate: TikTok Analytics → Content → Video → Audience retention (first 3 sec)
- Watch Time: TikTok/IG Analytics → Content → Average watch time
- Save Rate: IG Insights → Reel → Saved / TikTok → Favorites
- Keyword Comments: count manually
- Comment Quality: read comments. Are they from ICP or random?

### Action Based on Results

**Winning video** (hook rate ≥30% AND watch time ≥50% AND save rate ≥2%):
- Activate Script Remix: create 3 variants (Zoom In, Different Angle, Different Format)
- Save hook to personal Hook Playbook as proven pattern
- Consider: can you make a series? ("Part 2", "Error #2", etc.)
- Cross-post on other platform (TikTok → IG Reel, and vice versa)

**Average video** (hook rate 20-30% AND watch time 30-50%):
- Test Hook Velocity: 3 different hooks on same payload
- Don't create variants — content works but execution needs improvement
- Analyze: which part of the video has the biggest drop? Fix that.

**Flop video** (hook rate <20% OR watch time <30%):
- Do NOT repost the same video
- Analyze: is the problem the hook or the content?
- If hook rate <20%: topic doesn't interest OR hook is weak
- If hook rate OK but watch time low: payload doesn't deliver on the promise
- Save the topic but completely change hook and angle
- Move on — don't invest time in content that doesn't resonate

# CTA System — 6 Templates + Decision Matrix

## The 6 CTA Templates

### CTA #1: Lead Magnet via Keyword Comment 💬
**Rank:** Primary — 3-4 videos out of 7 per week

**Script:**
"Ho una checklist con 25 punti per controllare il tuo funnel.
Commenta 'AUDIT' e te la mando."

**Variants:**
- "Vuoi i 25 punti da controllare sul tuo funnel? Commenta 'AUDIT' — te la mando in DM."
- "Ho creato una checklist per controllare tutto questo. Commenta 'AUDIT' e la ricevi gratis."
- "Commenta 'AUDIT' e ti mando la checklist con 25 punti per il tuo funnel. Gratis, zero fuffa."

**Suggested keywords:** AUDIT, CRO, CHECK, FUNNEL, FIX
**Best platform:** TikTok (engagement boost + ManyChat trigger)
**Use when:** Action videos with practical fix, Educational videos, any video mentioning a checklist point

**Mechanism:** The keyword comment triggers ManyChat (or DM automation) that sends
the lead magnet link automatically. Double benefit: lead capture + algorithm boost
(comment = engagement).

---

### CTA #2: Lead Magnet via Link in Bio 🔗
**Rank:** Secondary — 1-2 videos per week

**Script:** "Link in bio per la CRO Checklist gratuita."

**Variants:**
- "Se vuoi controllare il tuo funnel punto per punto, link in bio — checklist gratuita."
- "Link in bio → CRO Checklist con 25 punti. Gratis."

**Best platform:** Instagram Reel (clickable link in bio)
**Use when:** Short videos (<20 sec), Trend videos, IG Reel format

**Note:** Only works if the link in bio is updated with the lead magnet.
On TikTok: less effective than keyword comment (requires more steps).

---

### CTA #3: Follow ➕
**Rank:** Tertiary — 1 video per week max

**Script:** "Segui per altri teardown come questo."

**Variants:**
- "Se vuoi vedere altri errori CRO come questi, seguimi."
- "Ogni settimana analizzo funnel e checkout. Segui per non perderti i prossimi."

**Best platform:** TikTok and IG Reel (both)
**Use when:** Trend videos with high reach but cold target, viral content

**Warning:** NEVER use as primary CTA. It's the weakest CTA for lead generation.
Always specify WHAT they'll see ("teardowns", "CRO tips") not just "follow me for more content."

---

### CTA #4: Strategy Call 📞
**Rank:** Selective — 0-1 videos per week, warm audience only

**Script:**
"Se vuoi che analizzi il TUO funnel in 15 minuti,
link in bio per prenotare. È gratis."

**Variants:**

## Script Remix System

When a video performs well (≥30k views OR ≥3% engagement rate OR ≥2% save rate),
create 3 variants without rebuilding from scratch.

### Variant 1: ZOOM IN 🔎
Take ONE of the points/errors/steps from the original video and make an ENTIRE
video dedicated to it.

**How to do it:**
1. Identify the point that generated the most comments/questions
2. Create an Action or Educational video dedicated ONLY to that point
3. Open with: "Vi ho parlato di [N] errori nel [topic]. Oggi approfondiamo
   il #[X] perché è quello che da solo costa di più."
4. Go deep: more details, more examples, specific screenshots

### Variant 2: DIFFERENT ANGLE 🔄
Same fundamental content, but for a DIFFERENT AUDIENCE or with different FRAMING.

**How to do it:**
- Change the target sector (e-commerce → SaaS, B2C → B2B)
- Change the framing (from "errors" to "best practices")
- Change the level (basic entrepreneur → expert marketing manager)
- Change the platform (TikTok → IG Reel with different tone)

### Variant 3: DIFFERENT FORMAT 📐
Transform the video into a DIFFERENT FORMAT.

**Options:**
- Spoken video → IG carousel (8-10 slides with more detail per slide)
- Educational video → Action video (extract 1 point and do quick fix)
- Long video (90 sec) → Short video (30 sec) with only the highlight
- Short video (30 sec) → Long video (90 sec) with depth
- Video → LinkedIn/X text thread

## Hook Velocity (A/B Testing)

For a video you want to test or relaunch:

1. Take the payload (B2 + B3 + B4 — identical)
2. Write 5 hooks using 5 different formulas
3. Record 5 versions (change only the first 3 seconds)
4. Publish: 1/day for 5 days, or 3 on TikTok + 2 on IG
5. After 48h per video: compare hook rate and watch time
6. The winning hook becomes your "proven template" for that topic

**Metrics to compare:**
- Hook rate: % who watch past first 3 sec (target: ≥30%)
- Average watch time: target ≥50% of video duration
- Completion rate: target ≥15% TikTok, ≥20% IG Reel

**Publish variants 3-5 days apart.** The algorithm penalizes similar content published close together.

# Hook System — 8 Formulas for CRO Short-Form

## How Hooks Work

The hook is the single most important sentence in the entire video. The viewer is
scrolling at constant speed. You have ONE chance to interrupt the thumb's motor
pattern. If the brain doesn't say "wait, what?" → scroll.

Every hook must:
- Start with a strong first word (number, "If", "POV", action verb)
- Be ≤15 words
- Use second person ("you", "your")
- Be specific (not generic)
- Show the face in the first 2 seconds (face-to-camera = trust)
- Start speaking IMMEDIATELY (zero initial silence)

Every hook must NOT:
- Open with "Hi", "Hey", "Good morning", "Hello everyone"
- Open with "In this video", "Today we talk about"
- Open with music + slow-appearing text
- Use generic questions ("Want to make more money?")
- Include personal introduction ("My name is X and I do Y")
- Show agency logo
- Attract wrong ICP ("How to make money online")

---

## Formula F1: Data Shock 📊

**Psychological mechanism:** A counterintuitive number violates expectations.
The brain stops when it encounters unexpected data because it must reconcile
the new information with existing beliefs. This creates a cognitive gap the
viewer wants to fill.

**Template:** `[Specific number]% [of what] [does/doesn't] [what].`

**Template variants:**
- `[Number] [subjects] out of [total] [do/don't] [what].`
- `Only [N]% [of whom] [does what]. The rest? [consequence].`

**Compiled examples:**

① "Il 70% delle persone non legge oltre la tua headline.
    E tu hai scritto 3000 parole sotto."
→ Context: Video on headline importance
→ Works because: Violates the expectation that visitors read. Creates urgency.

② "Il 67% dei carrelli viene abbandonato.
    Ma il problema non è dove pensi."
→ Context: Video on checkout optimization
→ Works because: Known data + second sentence creates curiosity.

③ "L'80% del tuo traffico se ne va nei primi 5 secondi.
    E tu stai comprando altro traffico."
→ Context: Video on bounce rate vs ad spend
→ Works because: Data + irony about the contradiction.

**Best for:** Action and Educational videos. When you have real, verifiable data.
**Hook strength:** 9/10

---

## Formula F2: Direct Provocation ⚡

**Psychological mechanism:** Challenges a belief of the target. Creates cognitive
dissonance — the uncomfortable feeling of having a belief questioned. The viewer
stays to resolve the dissonance: "Is this person right or wrong? I need to find out."

**Template:** `[What everyone believes/does] [is wrong/doesn't work/is costing you money].`

**Template variants:**
- `[Common action of target]? Here's why it doesn't work.`
- `If you believe [common belief], you're [negative consequence].`

**Compiled examples:**

① "Il redesign del sito NON ti porterà più vendite.
    E ti spiego perché."
→ Context: Video against redesign without data
→ Works because: Many entrepreneurs think "new site = more sales." Direct challenge.

② "Se il tuo 'esperto CRO' parte dal design e non dai dati,
    ti sta vendendo aria."
→ Context: Video positioning Digital Empire vs competitors
→ Works because: Attacks competitors indirectly. Creates doubt.

③ "Più traffico non significa più vendite.
    Anzi, spesso significa più soldi buttati."
→ Context: Video on CRO vs media buying
→ Works because: Challenges the fundamental belief of digital marketing.

**Best for:** Positioning and Objection videos. When you want to differentiate.
**Hook strength:** 8/10

---

## Formula F3: POV / Situation 👁️

**Psychological mechanism:** Puts the viewer in a recognizable scene. If they
identify with the situation, the self-reference bias activates: we pay more
attention to content about ourselves. "This is about ME" → stay.

**Template:** `POV: [specific situation the target recognizes]`

**Template variants:**
- `When [recognizable situation of target]...`
- `You: [target's action]. Your funnel: [comic/tragic reaction].`

**Compiled examples:**

① "POV: apri il funnel del cliente per la prima volta
    e trovi 12 campi nel form di contatto."
→ Context: Teardown / professional humor
→ Works because: Every CRO specialist has lived this moment.

② "Quando spendi €5.000 al mese in ads
    e il conversion rate è ancora sotto l'1%."
→ Context: Video on ad ROI vs CRO
→ Works because: Specific situation with a figure. Painful recognition.

③ "POV: il cliente dice 'il sito è bellissimo'
    ma le vendite sono zero."
→ Context: Video on design vs conversion
→ Works because: Contrast between aesthetic perception and real results.

**Best for:** Trend and Action videos. Relatable, shareable content.
**Hook strength:** 7/10

---

## Formula F4: If...Then 🎯

**Psychological mechanism:** Conditional that qualifies the viewer. Those who
recognize themselves in the condition stay — they feel the video is for them.
Those who don't, leave — and this is an INTENTIONAL FILTER. You want non-targets
to leave.

**Template:** `If [specific condition of target], [negative consequence they're suffering].`

**Template variants:**
- `If [you do X] and [Y happens], the problem is [Z].`
- `If your [element] has [characteristic], you're [losing/burning] [what].`

**Compiled examples:**

① "Se stai spendendo in ads e il tuo checkout ha più di 5 campi,
    stai bruciando soldi."
→ Context: Video on checkout optimization
→ Works because: Specific condition + concrete consequence.

② "Se il tuo landing page non ha social proof above the fold,
    il 40% del traffico se ne va senza leggere una parola."
→ Context: Video on above the fold optimization
→ Works because: Verifiable condition + specific data on consequence.

③ "Se nessuno clicca il tuo bottone di acquisto,
    il problema non è il prezzo. È una cosa molto più stupida."
→ Context: Video on CTA copy / button optimization
→ Works because: "Stupider" creates enormous curiosity.

**Best for:** Action and Quick Win videos. When the condition is easily verifiable.
**Hook strength:** 9/10

---

## Formula F5: Uncomfortable Rhetorical Question ❓

**Psychological mechanism:** Forces the viewer to answer mentally. If the answer
makes them uncomfortable (e.g., "no, I don't know"), the Loewenstein information
gap activates: the desire to fill the gap. They stay for the solution.

**Template:** `When's the last time you [action they should do but probably don't]?`

**Template variants:**
- `Can you tell me [critical metric] right now? If the answer is 'no', we have a problem.`
- `How much are you paying for [thing they're paying for without knowing]?`

**Compiled examples:**

① "Quand'è l'ultima volta che hai guardato
    il tasso di abbandono del tuo checkout?"
→ Context: Video on checkout analytics
→ Works because: Most people never check. The question creates discomfort.

② "Sai dirmi il conversion rate della tua landing page
    in questo momento? Se la risposta è 'no', abbiamo un problema."
→ Context: Video on importance of CRO metrics
→ Works because: Forces mental answer. "No" creates urgency.

③ "Quanto stai pagando per ogni persona che visita il tuo sito
    e poi se ne va senza comprare?"
→ Context: Video on real cost of bounce
→ Works because: Reframes bounce rate in terms of MONEY LOST.

**Best for:** Educational and Quick Win videos.
**Hook strength:** 7/10

---

## Formula F6: I Found / I Just 🔍

**Psychological mechanism:** Curiosity + authority. Shows you're actively working
and discovered something relevant. Combines two triggers: "what did they find?"
(curiosity) and "this is a professional working in the field" (authority).

**Template:** `I [just/found/discovered] [what] [where/in whom] [and implication].`

**Template variants:**
- `I just finished [activity] and [surprising discovery].`
- `I was [professional activity] and noticed [what].`

**Compiled examples:**

① "Ho appena analizzato questo checkout e ho trovato un errore
    che gli costa migliaia di euro al mese."
→ Context: Live checkout teardown
→ Works because: "Thousands of euros" creates urgency. "Just analyzed" = fresh = credible.

② "Ho trovato 5 errori in 60 secondi su questa landing page."
→ Context: Quick landing page teardown
→ Works because: "5 errors in 60 seconds" implies the page is a disaster.

③ "Ho appena finito uno sprint CRO e i risultati mi hanno sorpreso.
    Vi faccio vedere."
→ Context: Case study / sprint results
→ Works because: "Surprised" creates curiosity. "I'll show you" = promise of visual proof.

**Best for:** Teardowns and Behind the Scenes. Action and Proof videos.
**Hook strength:** 8/10

---

## Formula F7: Most People / Nobody 👥

**Psychological mechanism:** Exclusivity + contrast. "Most people do X (wrong)"
→ implies "I do Y (right)." Creates two groups: the mass that's wrong and the
minority that knows. The viewer wants to be in the minority.

**Template:** `Most [of whom/companies] [do something wrong]. Here's what to do instead.`

**Template variants:**
- `Nobody tells you this: [uncomfortable truth].`
- `[N]% [of whom] does [X]. The remaining [N]% that [gets results] does [Y].`

**Compiled examples:**

① "La maggior parte delle aziende butta soldi in ads
    senza aver controllato SE il funnel converte.
    È come versare benzina in un motore rotto."
→ Context: Video on CRO vs media buying
→ Works because: Strong metaphor ("gasoline in a broken engine") + challenge.

② "Nessuno te lo dice: il tuo bottone CTA è nel colore sbagliato.
    E ti costa conversioni ogni giorno."
→ Context: Video on CTA button design
→ Works because: "Nobody tells you" = exclusive info. "Every day" = ongoing urgency.

③ "La maggior parte delle agenzie vuole tenerti per sempre.
    Noi siamo progettati per essere licenziati."
→ Context: Positioning / USP video
→ Works because: Counter-intuitive USP. "Designed to be fired" is memorable.

**Best for:** Positioning and Objection videos. Educational.
**Hook strength:** 8/10

---

## Formula F8: Mistake / Wrong Thing 🚫

**Psychological mechanism:** Loss aversion. Nobody wants to make mistakes or
discover they're already making them. The viewer stays to check if they're
guilty. Loss aversion is ~2x more powerful than desire for gain: "you're losing"
hits harder than "you could gain."

**Template:** `[Number] mistakes that [kill/destroy/cost] [target's thing].`

**Template variants:**
- `The most common mistake [in sector] that costs [how much].`
- `You're making [this mistake]? [N]% of companies do.`

**Compiled examples:**

① "3 errori nel tuo checkout che ti costano il 40% delle vendite."
→ Context: Video on checkout optimization
→ Works because: Specific number (3) + quantified consequence (40%).

② "L'errore più comune nelle landing page B2B:
    scrivere 'noi' invece di 'tu'."
→ Context: Video on landing page copy
→ Works because: Super-specific error, easily verifiable. The viewer goes to check.

③ "Se la tua headline dice cosa FAI invece di cosa RISOLVONO,
    stai facendo l'errore più costoso nel copy."
→ Context: Video on headline optimization
→ Works because: Very common error + "most costly" = maximum urgency.

**Best for:** Action and Quick Win videos.
**Hook strength:** 9/10

- Trend → F3 (POV/Situation)

**By available assets:**
- Have data/statistics → F1, F4, F8
- Have case study → F6, F1
- Want provocative tone → F2, F7
- Want educational tone → F5, F1

# Payload Structures — 4 Types + Compiled Script Examples

## Type 1: 🎬 ACTION (Problem/Solution) — 15-45 sec

**Concept:** One problem → one fix → one result. The densest, fastest video.
Zero filler. The viewer must leave with ONE concrete action to take.

**Internal structure:**
```

├── PROBLEM visualized (3-5 sec)
│   Show the problem. Screen recording, screenshot, or vivid description.
│   "Look here [point to screen]. See this [element]? Here's the problem."
│
├── FIX (5-15 sec)
│   The concrete solution in 1-3 steps.
│   "Instead of X, do Y." or "The solution? [Step 1]. [Step 2]. Done."
│
```

- Max 1 problem and 1 fix per video
- The fix must be applicable TODAY by the viewer
- Screen recordings: highlight with circle/arrow
- Before/after must be visually clear
- No theoretical explanations — only practical action

**Fatal errors:**
- Giving 5 fixes in a 30-sec video (that's Educational, not Action)
- Fix too generic ("improve your copy" → how?)
- Fix requiring advanced skills the target doesn't have

## Type 2: 🎓 EDUCATIONAL (Deep Dive) — 60-180 sec

**Concept:** A framework or method explained with depth. The viewer learns
something structured, not just a tip. Includes context, numbered points,
concrete example, and takeaway.

**Internal structure:**
```

│   "We talk about [topic] because [consequence if you don't understand it]."
│
├── FRAMEWORK / METHOD (25-80 sec)
│   The educational core. Numbered point structure.

│

```

- Each point: explanation ≤2 sentences
- Retention hook MANDATORY between points (every 20-30 sec)
- Example must be REAL (client, project, data)
- Takeaway must be tweetable (≤280 characters)
- Alternate visuals every 15-20 sec

**Fatal errors:**
- Framework with 8+ points (too many — viewer remembers nothing)
- Long theoretical explanations without practical example
- No retention hooks — viewer exits mid-video
- Missing takeaway — viewer doesn't know what to take home

## Type 3: 📈 PROOF (Case Study) — 30-90 sec

**Concept:** Before → What we did → After → Why it worked. The video that builds
CREDIBILITY. Real numbers, specific interventions, measurable results.

**Internal structure:**
```

│   "This [business type] had a CR of [X%].
│    They were spending [€Y/month] on ads

│
├── WHAT WE DID (10-30 sec)
│   The 2-3 key interventions. Not ALL details — only replicable ones.
│   "We did [N] things:
│    1. [Concrete specific intervention]
│    2. [Concrete specific intervention]
│    3. [Concrete specific intervention]"
│
├── AFTER (5-10 sec)
│   Results with specific numbers.
│   "Result: from [X%] to [Y%] CR in [Z] days.
│    [€] more per month."
│
└── WHY IT WORKED (5-15 sec)
    The transferable lesson. Why it worked = principle applicable by all.
    "It worked because [principle].

```

**Rules:**
- REAL NUMBERS mandatory (CR%, €, days, %). Never invented.
- Max 3 interventions (even if you did 10)
- Interventions must be UNDERSTANDABLE by non-technical people
- "Why it worked" must be a universal principle, not case-specific
- If possible: real screenshots (censored for privacy if needed)
- If you can't show client name: use sector + size ("fashion e-commerce, €200k/month")

**Fatal errors:**
- Case study without numbers ("we improved conversions" — HOW MUCH?)
- Too many interventions (>3) — becomes Educational, not Proof
- Too technical interventions — simplify
- No "why" — without the transferable lesson, the case study is just bragging

## Type 4: 🔥 TREND (Attention) — 7-30 sec

**Concept:** Ride a viral format/audio and apply it to CRO. The viewer recognizes
the trend → stops for the familiar format. The CRO twist makes it relevant.
Objective: maximum reach, brand awareness.

**Internal structure:**
```
[B1 HOOK: 1-2 sec] Use trending audio/format
[B2 DOES NOT EXIST — tension is integrated in the trend]
[B3 PAYLOAD: 5-20 sec]
├── CRO TWIST applied to trend (5-15 sec)
└── PUNCHLINE (3-5 sec) — brief, memorable, shareable
[B4 CTA: 2-5 sec] Brief and natural
```

**Rules:**
- Trend MUST still be active (don't use trends dead for 3 weeks)
- CRO twist must be NATURAL — don't force a trend onto an unrelated topic
- Punchline must work WITHOUT audio (on-screen text mandatory)
- CTA brief and light ("Follow for more teardowns" or "Link in bio")
- Don't try to be educational in a trend video — goal = reach and brand, not leads
- Mimic the format: same visual structure as original trend, changed content

**Fatal errors:**
- Using a dead trend (viewer recognizes it as "old" → skip)
- Forcing the CRO twist — if no natural connection, choose another trend
- Turning the trend video into a mini-tutorial (wrong format)
- Long complex CTA in a 15-sec video

# Retention Hooks — 12 Anti-Scroll Techniques

Retention hooks are phrases inserted in the MIDDLE of the video to prevent
scrolling during the payload. Essential for videos >30 seconds.

## Placement Rule

One retention hook every 20-30 seconds in the payload.

| Video Duration | Hooks Needed | Positions |
|---------------|-------------|-----------|
| ≤20 sec | 0 | — |
| 30 sec | 1 | ~15 sec |
| 45 sec | 1 | ~22 sec |
| 60 sec | 2 | ~20 sec, ~40 sec |
| 90 sec | 3 | ~25 sec, ~50 sec, ~70 sec |
| 120 sec | 4 | ~25 sec, ~50 sec, ~75 sec, ~100 sec |
| 180 sec | 5 | ~30 sec, ~55 sec, ~80 sec, ~110 sec, ~140 sec |

Trend videos: NO retention hooks needed. The format itself maintains attention.

---

## Category 1: Curiosity

**RH-01:** "Ma aspetta, perché il terzo punto è il più importante."
→ Creates anticipation for the next point. Place between framework points.

**RH-02:** "E qui arriva la parte che nessuno ti dice..."
→ "Nobody tells you" = exclusive information trigger. Place before the main insight.

**RH-03:** "Ora ti mostro la parte interessante."
→ Explicit promise of imminent value. Place before showing data/screenshots/results.

## Category 2: Pattern Interrupt

**RH-04:** "Stop. Prima che vai avanti, guarda questo."
→ "Stop" interrupts mental flow. Works as an alarm signal.
   **Always accompany with a visual change** (framing change or show screenshot).

**RH-05:** "Ok, dimenticati tutto quello che ho detto finora. QUESTO è il punto vero."
→ Mental reset. Very powerful. **Use MAX 1 time per video.**

## Category 3: Social Proof Mid-Video

**RH-06:** "Con un cliente, questo singolo cambiamento ha generato [risultato]."
→ Social proof inserted mid-video. Adds credibility to the current point.
   Place after explaining a theoretical concept, before the practical example.

**RH-07:** "E non lo dico io — lo dicono i dati."
→ Transfers authority from person to data. More credible than "trust me."
   Place after a strong or counterintuitive statement. Show data immediately after.

## Category 4: Rhetorical Question

**RH-08:** "Vuoi sapere perché la maggior parte non lo fa?"
→ Creates curiosity about the "why." Place after presenting a solution,
   before explaining why it's neglected.

**RH-09:** "Indovina cosa è successo dopo?"
→ Classic cliffhanger. Creates dramatic pause before the result.
   Place after "what we did" and before "result" in Proof videos.

## Category 5: Direct Challenge

**RH-10:** "Scommetto che il tuo funnel ha questo problema adesso."
→ Personal challenge. The viewer thinks "is that right?" and stays to verify.
   Place after showing a common error or data about a widespread problem.

**RH-11:** "Fermati e vai a controllare il tuo sito. Ci vediamo tra 10 secondi."
→ Invitation to immediate mid-video action. Even if they don't do it,
   the fact that you MIGHT be right keeps them glued.
   Place after showing a very specific, easily verifiable error.

## Category 6: Internal Cliffhanger

**RH-12:** "Ma il vero motivo per cui funziona... non è quello che pensi."
→ Cliffhanger promising a twist. The viewer has already invested time
   and wants to know the "real reason."
   Place before the "why it worked" section (Proof) or before the takeaway.

---

## Selection by Video Type

| Video Type | Best Retention Hooks |
|-----------|---------------------|
| Educational | RH-01, RH-02, RH-06, RH-12 (curiosity + social proof) |
| Proof | RH-09, RH-06, RH-12 (rhetorical + social proof + cliffhanger) |
| Action (>30s) | RH-04, RH-10 (pattern interrupt + challenge) |
| Trend | None needed |

**Rule of thumb:** Vary categories within the same video. Don't use two curiosity
hooks back-to-back. Mix: curiosity → social proof → challenge.

# Tension Techniques — 3 Methods for the Hook → Payload Bridge

## How Tension Works

The tension is the bridge between hook and payload. The hook stopped the scroll,
but the viewer is still deciding whether to stay. Tension creates an **open loop**
— an open question in the viewer's mind that forces them to watch the payload.

For Trend videos or videos <20 seconds: skip tension. It's integrated into the
hook or absent. Go straight to payload.

---

## T1: Problem Amplification 🔊

**Mechanism:** Takes the problem introduced in the hook and shows HOW BAD it is.
Activates loss aversion: the viewer realizes the problem is bigger than they thought.
Urgency increases → they stay for the solution.

**Template:** `And the worst part? [amplified consequence the viewer hadn't considered].`

**Variants:**
- `And it's not just [hook problem]. It's that [cascading consequence].`
- `This means that every [day/week/month] you're [losing/burning] [amount/opportunity].`
- `And guess what? [Consequence the viewer hadn't considered].`

**Examples linked to hooks:**

| Hook | Tension | Why it works |
|------|---------|-------------|
| "67% of carts are abandoned." | "And the worst part? You're paying to bring these people to checkout. You're literally paying to lose customers." | Connects the data (67% abandonment) to the viewer's wallet. Not just a stat — it's MONEY you're spending to lose. |
| "80% of your traffic leaves in the first 5 seconds." | "And I'm not talking about people who 'weren't in target'. I'm talking about people who clicked your ad, who WANTED what you offer, and left because your page gave them no reason to stay." | Demolishes the excuse 'traffic wasn't in target'. The problem is YOURS, not the traffic's. |
| "3 mistakes in your checkout costing you 40% of sales." | "And the best part? These are mistakes you can fix in an afternoon. But if you don't know them, they cost you money every single day." | Adds urgency ('every single day') + hope ('an afternoon'). Viewer thinks: 'if it's that easy, I must know which ones.' |

**Best paired with hooks:** F1 (Data Shock), F8 (Mistake), F4 (If...Then)
**Best for video types:** Action, Educational, Proof
**Common errors:** Amplifying too much (becomes unbelievable), using invented data, amplifying without then providing the solution

---

## T2: False Trail 🔀

**Mechanism:** Says what the solution IS NOT. This does two things: (1) eliminates
the obvious answer from the viewer's mind, creating curiosity for the real answer;
(2) demonstrates expertise — you know the false solutions because you've already
seen/tested them.

**Template:** `And no, the solution isn't [what everyone thinks]. It's something much more [simple/counterintuitive].`

**Variants:**
- `And it's not [obvious solution]. I've seen companies try [obvious solution] and make things worse.`
- `If you're thinking '[obvious solution]', stop. That's not it.`
- `The answer isn't [A] and it's not [B] either. It's something 99% never check.`

**Examples linked to hooks:**

| Hook | Tension | Why it works |
|------|---------|-------------|
| "If nobody clicks your CTA, the problem isn't the price." | "And no, it's not the button color either. It's something 99% of companies never check." | Eliminates two obvious answers (price, color). The viewer now MUST know the real answer. |
| "Site redesign will NOT bring you more sales." | "And no, you don't need a new copywriter either. The problem is in a place you're not even looking at." | Eliminates redesign AND copy as solutions. 'A place you're not even looking at' = maximum curiosity. |
| "More traffic doesn't mean more sales." | "And the solution isn't 'better traffic' or 'more precise targeting' either. It's something that happens AFTER the click." | 'After the click' shifts attention from ads to post-click experience. Perfect CRO setup. |

**Best paired with hooks:** F2 (Provocation), F4 (If...Then), F5 (Uncomfortable Q)
**Best for video types:** Action, Educational
**Common errors:** Eliminating the obvious answer then giving an even more obvious one, too many "it's not this, not that" (max 2 false trails), never giving the real answer (empty clickbait)

---

## T3: Value Promise 🎁

**Mechanism:** Explicitly tells them what they'll get by watching to the end.
Creates an implicit contract: "I give you [value], you give me [attention]."
Works because it makes the cost (time) and benefit (value) explicit.

**Template:** `I'll show you [what] in [time] [and result they'll get].`

**Variants:**
- `In [N] seconds I'll show you [what] you can apply [when].`
- `Stay to the end and you'll have [concrete result].`
- `I'll give you [N] [things] you can use [today/right now/tomorrow morning].`

**Examples linked to hooks:**

| Hook | Tension | Why it works |
|------|---------|-------------|
| "I found 5 errors in 60 seconds on this landing page." | "I'll show you which ones, how to fix them, and how they can change your conversion rate starting tomorrow." | 3 concrete promises: (1) which errors, (2) how to fix, (3) impact. Viewer knows exactly what they get. |
| "I just finished a CRO sprint and the results surprised me." | "I'll show you the 3 interventions we made, how much they cost, and the revenue result. Real numbers, zero fluff." | 'Real numbers, zero fluff' = transparency promise. Viewer knows they won't waste time. |
| "Most common landing page B2B mistake: writing 'we' instead of 'you'." | "I'll show you 3 real headlines written with 'we' and how I'd rewrite them in 10 seconds to double conversions." | '3 real headlines' = concrete proof. '10 seconds' = fast. 'Double conversions' = quantified benefit. |

**Best paired with hooks:** F6 (I Found), F1 (Data Shock), F7 (Most People)
**Best for video types:** Educational, Proof
**Common errors:** Promise too vague ('I'll show you interesting things'), promise too big that you don't deliver, repeating the hook as the promise (adds nothing)

# ═══════════════════════════════════════════

def select_hooks(
    tipo_video: str,
    argomento: str = "",
    ha_dati: bool = False,
    ha_caso_studio: bool = False,
    tono: str = "diretto"
) -> list:
    """
    Selects the 3 best hook formulas for the given context.

    Args:
        tipo_video: 'azione' | 'educativo' | 'prova' | 'trend'
        argomento: topic of the video
        ha_dati: whether data/statistics are available
        ha_caso_studio: whether a case study is available
        tono: 'diretto' | 'provocatorio' | 'educativo'

    Returns:
        List of top 3 hook formulas with scores and tension pairing
    """
    scores = {}

    for formula_id, formula in HOOK_FORMULAS.items():
        score = formula["forza"]

        # Match video type
        if tipo_video in formula["tipo_video_ideale"]:
            score += 3

        # Bonus if data available and formula uses it
        if ha_dati and formula["richiede_dati"]:
            score += 3
        if ha_dati and formula_id in ["F1_DATO_SHOCK", "F4_SE_ALLORA", "F8_ERRORE"]:
            score += 2

        # Bonus if case study available
        if ha_caso_studio and formula_id in ["F6_HO_TROVATO", "F1_DATO_SHOCK"]:
            score += 3

        # Tone matching
        if tono == "provocatorio" and formula_id in ["F2_PROVOCAZIONE", "F7_MAGGIOR_PARTE"]:
            score += 2
        elif tono == "educativo" and formula_id in ["F5_DOMANDA_SCOMODA", "F1_DATO_SHOCK"]:
            score += 2
        elif tono == "diretto" and formula_id in ["F4_SE_ALLORA", "F8_ERRORE"]:
            score += 2

        # Penalty for mismatch
        if tipo_video == "trend" and formula_id not in ["F3_POV_SITUAZIONE", "F7_MAGGIOR_PARTE"]:
            score -= 2
        if tipo_video == "prova" and formula_id not in ["F6_HO_TROVATO", "F1_DATO_SHOCK"]:
            score -= 1

        scores[formula_id] = score

    # Rank and return top 3
    ranked = sorted(scores.items(), key=lambda x: x[1], reverse=True)[:3]

    results = []
    for formula_id, score in ranked:
        formula = HOOK_FORMULAS[formula_id]
        tension = TENSION_COMPATIBILITY.get(formula_id, {})

        results.append({
            "formula_id": formula_id,
            "nome": formula["nome"],
            "icona": formula["icona"],
            "template": formula["template"],
            "score": score,
            "tensione_consigliata": {
                "primaria": TENSION_NAMES.get(tension.get("primaria", ""), ""),
                "secondaria": TENSION_NAMES.get(tension.get("secondaria", ""), "")
            }
        })

    return results

# HOOK VALIDATOR
# ═══════════════════════════════════════════

FORBIDDEN_STARTS = [
    "ciao", "hey", "buongiorno", "buonasera", "ciao a tutti",
    "ciao ragazzi", "in questo video", "oggi parliamo",
    "in questo tutorial", "mi chiamo", "sono il", "sono un",
    "benvenuti", "bentornati", "salve"
]

GENERIC_QUESTIONS = [
    "vuoi fare più soldi", "vuoi migliorare",
    "ti piacerebbe avere più", "vuoi guadagnare"
]

CRO_SPECIFICS = [
    "checkout", "landing", "funnel", "form", "cta", "bottone",
    "headline", "above the fold", "bounce", "carrello",
    "abbandono", "conversion", "traffico", "click", "scroll",
    "%", "€", "social proof", "split test", "a/b test"
]


def validate_hook(hook_text: str) -> dict:
    """
    Validates a hook against all quality rules.

    Args:
        hook_text: the hook text to validate

    Returns:
        dict with 'valid', 'score' (0-10), 'issues', 'suggestion'
    """
    issues = []
    score = 10
    hook_lower = hook_text.lower().strip()
    words = hook_text.split()
    word_count = len(words)

    # ── Length check ──
    if word_count > 20:
        issues.append(f"🚫 TROPPO LUNGO: {word_count} parole (max 15, tolleranza 20)")
        score -= 4
    elif word_count > 15:
        issues.append(f"⚠️ Lungo: {word_count} parole (ideale ≤15)")
        score -= 2

    # ── Forbidden openings ──
    for forbidden in FORBIDDEN_STARTS:
        if hook_lower.startswith(forbidden):
            issues.append(f"🚫 VIETATO: inizia con '{forbidden}'")
            score -= 5
            break

    # ── Generic questions ──
    for gq in GENERIC_QUESTIONS:
        if gq in hook_lower:
            issues.append(f"🚫 Domanda generica: '{gq}'")
            score -= 4
            break

    # ── Specificity check ──
    has_number = any(char.isdigit() for char in hook_text)
    has_specific = any(kw in hook_lower for kw in CRO_SPECIFICS)

    if not has_number and not has_specific:
        issues.append("⚠️ Poco specifico: aggiungi dato numerico o elemento CRO concreto")
        score -= 2

    # ── Second person check ──
    second_person = ["tu", "tuo", "tua", "tuoi", "tue", "ti"]
    has_second = any(w in hook_lower.split() for w in second_person)
    if not has_second:
        issues.append("⚠️ Manca seconda persona ('tu', 'il tuo')")
        score -= 1

    # ── Strong first word ──
    if words:
        first = words[0].lower().rstrip("'")
        strong_starts = [
            "il", "l", "se", "pov", "ho", "la", "un", "lo",
            "nessuno", "quanto", "quand", "stai", "smetti",
            "3", "5", "7", "ogni", "solo", "questo"
        ]
        is_number = first.replace("%", "").replace(".", "").isdigit()
        if not is_number and first not in strong_starts:
            issues.append(f"⚠️ Prima parola '{first}' potrebbe essere più forte")
            score -= 1

    score = max(0, min(10, score))
    has_blockers = any("🚫" in i for i in issues)

    return {
        "hook": hook_text,
        "valid": score >= 7 and not has_blockers,
        "score": score,
        "word_count": word_count,
        "issues": issues,
        "verdict": (
            "✅ Hook approvato"
            if score >= 7 and not has_blockers
            else "⚠️ Hook da rivedere — correggi i problemi"
            if score >= 4 and not has_blockers
            else "🚫 Hook bocciato — riscrivi con una delle 8 formule"
        )
    }

def main():
    parser = argparse.ArgumentParser(description="Hook Selector & Validator")
    subparsers = parser.add_subparsers(dest="command")

    # Select command
    sel = subparsers.add_parser("select", help="Select best hooks for context")
    sel.add_argument("--type", required=True, choices=["azione", "educativo", "prova", "trend"])
    sel.add_argument("--topic", default="", help="Video topic")
    sel.add_argument("--has-data", action="store_true", help="Data/statistics available")
    sel.add_argument("--has-case-study", action="store_true", help="Case study available")
    sel.add_argument("--tone", default="diretto", choices=["diretto", "provocatorio", "educativo"])

    # Validate command
    val = subparsers.add_parser("validate", help="Validate a hook text")
    val.add_argument("hook_text", help="Hook text to validate")

    args = parser.parse_args()

    if args.command == "select":
        results = select_hooks(
            tipo_video=args.type,
            argomento=args.topic,
            ha_dati=args.has_data,
            ha_caso_studio=args.has_case_study,
            tono=args.tone
        )
        print("\n🎯 TOP 3 HOOK FORMULAS:\n")
        for i, r in enumerate(results, 1):
            print(f"  {i}. {r['icona']} {r['nome']} (score: {r['score']})")
            print(f"     Template: {r['template']}")
            print(f"     Tensione: {r['tensione_consigliata']['primaria']}")
            print()

    elif args.command == "validate":
        result = validate_hook(args.hook_text)
        print(f"\n{'='*50}")
        print(f"HOOK: \"{result['hook']}\"")
        print(f"Score: {result['score']}/10 | Parole: {result['word_count']}")
        print(f"Verdict: {result['verdict']}")
        if result["issues"]:
            print(f"\nProblemi:")
            for issue in result["issues"]:
                print(f"  {issue}")
        print(f"{'='*50}\n")

        # Return non-zero exit code if invalid
        sys.exit(0 if result["valid"] else 1)

    else:
        parser.print_help()


if __name__ == "__main__":
    main()


#!/usr/bin/env python3
"""
Quality Checker for Short-Form Script Engine.

Runs the pre-registration checklist on a script to verify
it meets all quality standards before recording.

Usage:
    python quality_checker.py --hook "..." --tension "..." --payload "..." --cta "..." --type azione
    python quality_checker.py --script-file script.json
"""

import argparse
import json
import sys


# ═══════════════════════════════════════════
# CHECKLIST DEFINITIONS
# ═══════════════════════════════════════════

WORD_COUNT_RANGES = {
    "azione":    {"min": 40,  "max": 120},
    "educativo": {"min": 160, "max": 480},
    "prova":     {"min": 80,  "max": 240},
    "trend":     {"min": 20,  "max": 80}
}

FILLER_WORDS = [
    "fondamentalmente", "in pratica", "come sapete",
    "è importante dire che", "va detto che", "a dire il vero",
    "diciamo", "praticamente", "sostanzialmente",
    "ovviamente", "chiaramente", "naturalmente"
]

FORBIDDEN_HOOK_STARTS = [
    "ciao", "hey", "buongiorno", "buonasera", "ciao a tutti",
    "ciao ragazzi", "in questo video", "oggi parliamo",
    "in questo tutorial", "mi chiamo", "sono il", "sono un",
    "benvenuti", "bentornati", "salve"
]

CRO_KEYWORDS = [
    "checkout", "landing", "funnel", "form", "cta", "bottone",
    "headline", "above the fold", "bounce", "carrello",
    "conversion", "traffico", "click", "%", "€",
    "social proof", "test", "copy", "lead"
]


def run_checklist(
    hook: str,
    tension: str,
    payload: str,
    cta: str,
    tipo_video: str,
    caption: str = ""
) -> dict:
    """
    Run the complete pre-registration quality checklist.

    Returns:
        dict with results per section, blockers, warnings, and verdict
    """

    all_text = f"{hook} {tension} {payload} {cta}"
    total_words = len(all_text.split())
    results = {
        "checks": [],
        "blockers": [],
        "warnings": [],
        "info": []
    }

    def add_check(check_id, section, description, passed, severity, fix=""):
        entry = {
            "id": check_id,
            "section": section,
            "check": description,
            "passed": passed,
            "severity": severity
        }
        results["checks"].append(entry)
        if not passed:
            msg = f"[{check_id}] {description}"
            if fix:
                msg += f" → {fix}"
            if severity == "BLOCKING":
                results["blockers"].append(msg)
            elif severity == "IMPORTANT":
                results["warnings"].append(msg)
            else:
                results["info"].append(msg)

    # ════════════ HOOK (B1) ════════════

    hook_lower = hook.lower().strip()
    hook_words = len(hook.split())

    # H1: Uses one of 8 formulas (heuristic: has number, starts with key words, etc.)
    has_hook_signal = (
        any(c.isdigit() for c in hook) or
        hook_lower.startswith(("se ", "pov", "ho ", "la maggior", "nessuno", "quand", "l'errore", "l'")) or
        "%" in hook
    )
    add_check("H1", "HOOK", "Prima frase usa una delle 8 formule hook",
              has_hook_signal, "BLOCKING",
              "Riscrivi con una delle 8 formule (vedi references/hook_system.md)")

    # H2: Doesn't start with forbidden words
    starts_forbidden = any(hook_lower.startswith(f) for f in FORBIDDEN_HOOK_STARTS)
    add_check("H2", "HOOK", "NON inizia con 'Ciao', 'Hey', 'In questo video'",
              not starts_forbidden, "BLOCKING",
              "Elimina il saluto. Prima parola DEVE essere l'hook.")

    # H3: CRO specific
    has_cro = any(kw in hook_lower for kw in CRO_KEYWORDS)
    add_check("H3", "HOOK", "Specifico per target CRO (non generico)",
              has_cro, "BLOCKING",
              "Aggiungi elemento specifico: metrica CRO, elemento pagina")

    # H4: Contains data/provocation/situation
    has_data_provocation = (
        any(c.isdigit() for c in hook) or
        any(w in hook_lower for w in ["non", "sbagliato", "errore", "pov", "quando"]) or
        "?" in hook
    )
    add_check("H4", "HOOK", "Contiene dato, provocazione, o situazione riconoscibile",
              has_data_provocation, "IMPORTANT")

    # H5: ≤15 words
    add_check("H5", "HOOK", f"Hook ≤15 parole (attuale: {hook_words})",
              hook_words <= 15, "IMPORTANT",
              "Taglia. Se non puoi dirlo in 15 parole, l'hook è troppo complesso.")

    # ════════════ TENSION (B2) ════════════

    if tipo_video != "trend":
        has_tension = len(tension.strip()) > 10
        add_check("T1", "TENSIONE", "Bridge tra hook e payload presente",
                  has_tension, "IMPORTANT",
                  "Aggiungi 2-3 frasi usando amplificazione, falsa pista, o promessa")

        # Open loop check
        open_loop_signals = [
            "perché", "il problema", "la parte peggiore", "e no",
            "non è", "ti faccio vedere", "ti mostro", "ecco",
            "la soluzione", "il motivo"
        ]
        has_open_loop = any(s in tension.lower() for s in open_loop_signals)
        add_check("T2", "TENSIONE", "Crea motivo per NON scrollare (open loop)",
                  has_open_loop, "BLOCKING" if has_tension else "IMPORTANT",
                  "La tensione deve creare un open loop: perché restare?")

    # ════════════ PAYLOAD (B3) ════════════

    payload_lower = payload.lower()

    # P1: One concept (heuristic: count major section headers)
    # Can't perfectly check this, but flag if obviously multi-topic
    add_check("P1", "PAYLOAD", "Contiene UN solo concetto principale",
              True, "BLOCKING")  # Manual check — always passes auto

    # P3: Has proof element
    proof_signals = [
        "cliente", "risultato", "esempio", "%", "€", "euro",
        "dati", "numeri", "abbiamo", "test", "screenshot",
        "mostra", "guarda"
    ]
    has_proof = any(s in payload_lower for s in proof_signals)
    add_check("P3", "PAYLOAD", "Ha almeno 1 elemento di prova (dato, esempio, screenshot)",
              has_proof, "BLOCKING",
              "Aggiungi: dato numerico, esempio cliente, o screenshot prima/dopo")

    # P4: Retention hooks (if >30 sec estimated)
    estimated_duration = total_words / 2.7
    if estimated_duration > 35:
        retention_signals = [
            "ma aspetta", "e qui arriva", "ora ti mostro", "stop",
            "dimenticati", "con un cliente", "non lo dico io",
            "vuoi sapere", "indovina", "scommetto", "fermati",
            "il vero motivo", "la parte interessante",
            "la maggior parte sbaglia", "il più importante"
        ]
        has_retention = any(s in payload_lower for s in retention_signals)
        add_check("P4", "PAYLOAD",
                  f"Retention hooks presenti (video stimato ~{int(estimated_duration)}s, >30s)",
                  has_retention, "IMPORTANT",
                  "Inserisci retention hooks ogni 20-30 sec (vedi references/retention_hooks.md)")

    # P5: Second person
    tu_words = ["tu", "tuo", "tua", "tuoi", "tue", "ti"]
    io_words = ["io", "noi", "mio", "mia", "nostro", "nostra"]
    tu_count = sum(1 for w in payload_lower.split() if w in tu_words)
    io_count = sum(1 for w in payload_lower.split() if w in io_words)
    add_check("P5", "PAYLOAD", f"Parla in seconda persona (tu:{tu_count} vs io/noi:{io_count})",
              tu_count >= io_count or tu_count >= 3, "IMPORTANT",
              "Riscrivi le frasi in 'io/noi' trasformandole in 'tu/il tuo'")

    # P6: Accessible language (check for heavy jargon)
    jargon = ["multivariate", "heatmap", "cohort", "attribution", "pixel",
              "server-side", "webhook", "API", "SDK", "regression"]
    jargon_found = [j for j in jargon if j.lower() in payload_lower]
    add_check("P6", "PAYLOAD", "Linguaggio accessibile (no gergo tecnico pesante)",
              len(jargon_found) == 0, "IMPORTANT",
              f"Semplifica: {', '.join(jargon_found)}" if jargon_found else "")

    # ════════════ CTA (B4) ════════════

    cta_lower = cta.lower().strip()

    # C1: CTA present
    add_check("C1", "CTA", "UNA CTA chiara presente",
              len(cta.strip()) >= 10, "BLOCKING",
              "Aggiungi CTA. Ogni video senza CTA è intrattenimento gratuito.")

    # C2: Says what they get
    value_signals = ["checklist", "25 punti", "gratis", "gratuita",
                     "ti mando", "ricevi", "link in bio", "scarica"]
    has_value = any(s in cta_lower for s in value_signals)
    add_check("C2", "CTA", "Dice cosa OTTENGONO (non solo cosa fare)",
              has_value, "IMPORTANT",
              "'Commenta AUDIT' → 'Commenta AUDIT e ti mando la checklist con 25 punti'")

    # C3: No double CTA
    action_words = ["commenta", "segui", "link in bio", "salva", "prenota", "scarica"]
    actions_found = [a for a in action_words if a in cta_lower]
    add_check("C3", "CTA", f"UNA sola azione richiesta (trovate: {len(actions_found)})",
              len(actions_found) <= 1, "BLOCKING" if len(actions_found) > 2 else "IMPORTANT",
              f"Doppia CTA rilevata: {actions_found}. Scegline UNA." if len(actions_found) > 1 else "")

    # C4: CTA in caption
    if caption:
        cta_in_caption = any(s in caption.lower() for s in ["commenta", "link in bio", "audit", "checklist"])
        add_check("C4", "CTA", "CTA ripetuta nella caption",
                  cta_in_caption, "IMPORTANT",
                  "Copia la CTA nella caption del post")

    # ════════════ TONE ════════════

    # BV4: Filler words
    fillers_found = [f for f in FILLER_WORDS if f in all_text.lower()]
    add_check("BV4", "TONO", "Zero riempitivi/filler",
              len(fillers_found) == 0, "IMPORTANT",
              f"Elimina: {', '.join(fillers_found)}" if fillers_found else "")

    # ════════════ LENGTH ════════════

    word_range = WORD_COUNT_RANGES.get(tipo_video, {"min": 20, "max": 480})
    in_range = word_range["min"] <= total_words <= word_range["max"]
    add_check("L1", "LUNGHEZZA",
              f"Parole nel range per {tipo_video}: {word_range['min']}-{word_range['max']} (attuale: {total_words})",
              in_range, "IMPORTANT",
              f"{'Troppo corto — aggiungi dettaglio' if total_words < word_range['min'] else 'Troppo lungo — taglia'}"
              if not in_range else "")

    # ════════════ SUMMARY ════════════

    total_checks = len(results["checks"])
    passed_checks = sum(1 for c in results["checks"] if c["passed"])
    percentage = round((passed_checks / total_checks) * 100) if total_checks > 0 else 0

    num_blockers = len(results["blockers"])

    if num_blockers == 0 and percentage >= 80:
        verdict = "✅ PRONTO PER REGISTRARE"
    elif num_blockers == 0:
        verdict = "⚠️ RIVEDERE — fix i warning prima di registrare"
    else:
        verdict = f"🚫 BLOCCATO — {num_blockers} check bloccanti da risolvere"

    results["summary"] = {
        "total_checks": total_checks,
        "passed": passed_checks,
        "percentage": percentage,
        "blockers_count": num_blockers,
        "warnings_count": len(results["warnings"]),
        "verdict": verdict,
        "estimated_duration_sec": round(total_words / 2.7),
        "total_words": total_words
    }

    return results


def format_results(results: dict) -> str:
    """Format results for terminal display."""
    lines = []
    summary = results["summary"]

    lines.append("\n" + "=" * 60)
    lines.append("  SCRIPT QUALITY CHECK — Pre-registrazione")
    lines.append("=" * 60)

    # Verdict
    lines.append(f"\n  {summary['verdict']}")
    lines.append(f"  Score: {summary['passed']}/{summary['total_checks']} ({summary['percentage']}%)")
    lines.append(f"  Parole totali: {summary['total_words']} (~{summary['estimated_duration_sec']}s)")

    # Blockers
    if results["blockers"]:
        lines.append(f"\n  🚫 BLOCCANTI ({len(results['blockers'])}):")
        for b in results["blockers"]:
            lines.append(f"     {b}")

    # Warnings
    if results["warnings"]:
        lines.append(f"\n  ⚠️ WARNING ({len(results['warnings'])}):")
        for w in results["warnings"]:
            lines.append(f"     {w}")

    # Info
    if results["info"]:
        lines.append(f"\n  ℹ️ INFO ({len(results['info'])}):")
        for i in results["info"]:
            lines.append(f"     {i}")

    # All checks
    lines.append(f"\n  {'─' * 56}")
    lines.append(f"  {'ID':<6} {'SEZ':<10} {'STATO':<6} {'CHECK'}")
    lines.append(f"  {'─' * 56}")
    for check in results["checks"]:
        status = "✅" if check["passed"] else ("🚫" if check["severity"] == "BLOCKING" else "⚠️")
        lines.append(f"  {check['id']:<6} {check['section']:<10} {status:<6} {check['check'][:45]}")

    lines.append("=" * 60 + "\n")
    return "\n".join(lines)


def main():

    # Option 1: Individual fields
    parser.add_argument("--hook", default="", help="Hook text (B1)")
    parser.add_argument("--tension", default="", help="Tension text (B2)")
    parser.add_argument("--payload", default="", help="Payload text (B3)")
    parser.add_argument("--cta", default="", help="CTA text (B4)")
    parser.add_argument("--caption", default="", help="Caption text")
    parser.add_argument("--type", default="azione", choices=["azione", "educativo", "prova", "trend"])

    # Option 2: JSON file
    parser.add_argument("--script-file", help="Path to script JSON file")

    # Output format
    parser.add_argument("--format", default="text", choices=["text", "json"])

    args = parser.parse_args()

    if args.script_file:
        with open(args.script_file, "r", encoding="utf-8") as f:
            data = json.load(f)
        hook = data.get("hook", data.get("B1_HOOK", {}).get("testo", ""))
        tension = data.get("tension", data.get("B2_TENSIONE", {}).get("testo", ""))
        payload = data.get("payload", data.get("B3_PAYLOAD", {}).get("testo", ""))
        cta = data.get("cta", data.get("B4_CTA", {}).get("testo", ""))
        caption = data.get("caption", "")
        tipo = data.get("tipo_video", data.get("type", "azione"))
    else:
        hook = args.hook
        tension = args.tension
        payload = args.payload
        cta = args.cta
        caption = args.caption
        tipo = args.type

    if not hook and not args.script_file:
        parser.print_help()
        print("\n❌ Fornisci almeno --hook e --cta, oppure --script-file")

    results = run_checklist(hook, tension, payload, cta, tipo, caption)

    else:

def format_skeleton(skeleton: dict) -> str:
    """Format skeleton for human-readable display."""
    lines = []
    h = skeleton["header"]

    lines.append("\n" + "═" * 60)
    lines.append(f"  SCRIPT SKELETON — {h['tipo'].upper()}")
    lines.append("═" * 60)

    # Header
    lines.append(f"\n  Piattaforma:  {h['piattaforma']}")
    lines.append(f"  Pilastro:     {h['pilastro']}")
    lines.append(f"  Tipo:         {h['tipo']}")
    lines.append(f"  Durata:       {h['durata_stimata']}")

    lines.append(f"  Visual:       {h['visual']}")
    lines.append(f"  Lead Magnet:  {h['lead_magnet']}")

    # Visual map
    if skeleton.get("visual_map"):
        lines.append(f"\n  {skeleton['visual_map']}")

    # Warnings
    for w in skeleton.get("warnings", []):
        lines.append(f"\n  {w}")

    # B1 Hook
    lines.append(f"\n  {'─' * 56}")
    lines.append(f"  B1 HOOK ({skeleton['B1_HOOK']['durata']['durata_sec']}s)")
    lines.append(f"  {skeleton['B1_HOOK']['istruzioni']}")

        lines.append(f"    {f['icona']} {f['formula']} (score {f['score']}): {f['template']}")

    # B2 Tension

    lines.append(f"\n  {'─' * 56}")
    lines.append(f"  B3 PAYLOAD ({skeleton['B3_PAYLOAD']['durata']['durata_sec']}s)")
    for step in skeleton["B3_PAYLOAD"]["struttura_interna"]:
        lines.append(f"    ├── {step['nome']}: {step['durata_sec']}s (~{step['parole']} parole)")
        lines.append(f"    │   {step['nota']}")
    ret = skeleton["B3_PAYLOAD"]["retention_hooks"]
    if ret["quanti"] > 0:
        pos_str = ", ".join(f"~{p}s" for p in ret["posizioni"])
        lines.append(f"    └── Retention hooks: {ret['quanti']} alle posizioni {pos_str}")

    # B4 CTA
    lines.append(f"\n  {'─' * 56}")
    lines.append(f"  B4 CTA ({skeleton['B4_CTA']['durata']['durata_sec']}s)")
    cta = skeleton["B4_CTA"]["cta_selezionata"]
    lines.append(f"  Tipo: {cta['tipo']}")
    lines.append(f"  Script: \"{cta['script']}\"")

    # Caption
    lines.append(f"\n  {'─' * 56}")
    lines.append(f"  CAPTION ({skeleton['caption']['piattaforma']})")
    lines.append(f"  Struttura: {skeleton['caption']['struttura']}")
    lines.append(f"  Hashtags: {' '.join(skeleton['caption']['hashtags_suggeriti'])}")

    # Output required
    lines.append(f"\n  {'─' * 56}")
    lines.append(f"  OUTPUT RICHIESTO:")
    for o in skeleton["output_richiesto"]:
        lines.append(f"    ☐ {o}")

    lines.append("\n" + "═" * 60 + "\n")
    return "\n".join(lines)

def calculate_structure(duration: int, tipo_video: str) -> dict:
    """
    Calculate the complete timing structure for a video.

    Args:
        duration: total video duration in seconds
        tipo_video: 'azione' | 'educativo' | 'prova' | 'trend'

    Returns:
        dict with block timing, word counts, retention hooks, and warnings
    """

    tipo = tipo_video.lower()
    tipo_range = TYPE_RANGES.get(tipo)

    if not tipo_range:
        return {"error": f"Tipo '{tipo_video}' non riconosciuto. Usa: azione, educativo, prova, trend"}

    # ── Warnings ──
    warnings = []
    if duration < tipo_range["min"]:
        warnings.append(
            f"⚠️ {duration}s è sotto il minimo per {tipo} ({tipo_range['min']}s). "
            f"Considera di allungare o cambiare tipo."
        )
    elif duration > tipo_range["max"]:
        warnings.append(
            f"⚠️ {duration}s è sopra il massimo per {tipo} ({tipo_range['max']}s). "
            f"Considera di accorciare o passare a long-form."
        )

    # ── Calculate block durations ──

    # Hook: always 2-3 sec
    hook_sec = 3 if duration > 15 else 2

    # Tension: scales with duration, 0 for trend
    if tipo == "trend" or duration < 20:
        tension_sec = 0
    elif duration <= 30:
        tension_sec = 4
    elif duration <= 60:
        tension_sec = 6
    elif duration <= 90:
        tension_sec = 8
    else:
        tension_sec = 10

    # CTA: scales slightly with duration
    if duration <= 15:
        cta_sec = 2
    elif duration <= 30:
        cta_sec = 4
    elif duration <= 60:
        cta_sec = 6
    elif duration <= 90:
        cta_sec = 7
    else:
        cta_sec = 10

    # Payload: everything else
    payload_sec = duration - hook_sec - tension_sec - cta_sec
    payload_sec = max(payload_sec, 5)

    # ── Calculate word counts ──
    total_words = int(duration * WORDS_PER_SEC)
    hook_words = int(hook_sec * WORDS_PER_SEC)
    tension_words = int(tension_sec * WORDS_PER_SEC)
    payload_words = int(payload_sec * WORDS_PER_SEC)
    cta_words = int(cta_sec * WORDS_PER_SEC)

    # ── Calculate retention hooks ──
    if payload_sec <= 15 or tipo == "trend":
        retention_count = 0
        retention_positions = []
    elif payload_sec <= 30:
        retention_count = 1
        retention_positions = [hook_sec + tension_sec + payload_sec // 2]
    else:
        retention_count = max(1, payload_sec // 25)
        interval = payload_sec / (retention_count + 1)
        retention_positions = [
            int(hook_sec + tension_sec + interval * (i + 1))
            for i in range(retention_count)
        ]

    # ── Calculate payload internal structure ──
    dist = PAYLOAD_DISTRIBUTION.get(tipo, {})
    payload_steps = []
    if dist:
        for step in dist["steps"]:
            step_sec = max(2, round(payload_sec * step["proportion"]))
            step_words = int(step_sec * WORDS_PER_SEC)
            payload_steps.append({
                "nome": step["name"],
                "durata_sec": step_sec,
                "parole": step_words,
                "nota": step["note"]
            })

    # ── Build visual map ──
    bar_payload = "=" * max(3, payload_sec // 3)
    visual_map = (
        f"[HOOK {hook_sec}s]"
        f"{'[TENS ' + str(tension_sec) + 's]' if tension_sec > 0 else ''}"
        f"[{bar_payload}PAYLOAD {payload_sec}s{bar_payload}]"
        f"[CTA {cta_sec}s]"
    )

    return {
        "input": {
            "durata_totale": duration,
            "tipo_video": tipo,
            "range_consigliato": f"{tipo_range['min']}-{tipo_range['max']}s (ideale: {tipo_range['ideale']}s)"
        },
        "blocchi": {
            "B1_HOOK":     {"durata_sec": hook_sec,     "parole": hook_words,     "nota": "1 frase, max 15 parole"},
            "B2_TENSIONE": {"durata_sec": tension_sec,   "parole": tension_words,   "nota": "2-3 frasi bridge" if tension_sec > 0 else "N/A per trend"},
            "B3_PAYLOAD":  {"durata_sec": payload_sec,   "parole": payload_words,   "struttura_interna": payload_steps},
            "B4_CTA":      {"durata_sec": cta_sec,       "parole": cta_words,       "nota": "1 CTA chiara"}
        },
        "retention_hooks": {
            "quanti": retention_count,
            "posizioni_sec": retention_positions,
            "regola": f"1 ogni ~{payload_sec // (retention_count + 1)}s" if retention_count > 0 else "Non necessari"
        },
        "totali": {
            "parole_stimate": total_words,
            "velocita_parlata": f"{WORDS_PER_SEC} parole/sec"
        },
        "visual_map": visual_map,
        "warnings": warnings
    }


def format_output(result: dict, fmt: str = "text") -> str:

    blocks = result["blocchi"]
    ret = result["retention_hooks"]
    totals = result["totali"]

    lines.append("=" * 60)
    lines.append(f"  STRUTTURA SCRIPT: {inp['tipo_video'].upper()} — {inp['durata_totale']}s")
    lines.append(f"  Range consigliato: {inp['range_consigliato']}")
    lines.append("=" * 60)

    # Warnings
    for w in result.get("warnings", []):
        lines.append(f"\n  {w}")

    # Visual map
    lines.append(f"\n  {result['visual_map']}\n")

    # Block table
    lines.append(f"  {'BLOCCO':<15} {'DURATA':<10} {'PAROLE':<10} {'NOTA'}")
    lines.append(f"  {'-'*60}")
    for block_name, block_data in blocks.items():
        name_short = block_name.replace("B1_", "").replace("B2_", "").replace("B3_", "").replace("B4_", "")
        nota = block_data.get("nota", "")
        lines.append(f"  {name_short:<15} {block_data['durata_sec']:<10}s {block_data['parole']:<10} {nota}")

    # Payload internal structure
    payload_steps = blocks["B3_PAYLOAD"].get("struttura_interna", [])
    if payload_steps:
        lines.append(f"\n  PAYLOAD — Struttura interna:")
        for step in payload_steps:
            lines.append(f"    ├── {step['nome']}: {step['durata_sec']}s (~{step['parole']} parole)")
            lines.append(f"    │   {step['nota']}")

    # Retention hooks
    lines.append(f"\n  RETENTION HOOKS: {ret['quanti']}")
    if ret["posizioni_sec"]:
        positions_str = ", ".join(f"~{p}s" for p in ret["posizioni_sec"])
        lines.append(f"  Posizioni: {positions_str}")
        lines.append(f"  Regola: {ret['regola']}")

    # Totals
    lines.append(f"\n  TOTALE: ~{totals['parole_stimate']} parole ({totals['velocita_parlata']})")
    lines.append("=" * 60)

    return "\n".join(lines)


def main():
    parser = argparse.ArgumentParser(description="Script Structure Calculator")
    parser.add_argument("--duration", "-d", type=int, required=True, help="Video duration in seconds")
    parser.add_argument("--type", "-t", required=True, choices=["azione", "educativo", "prova", "trend"])
    parser.add_argument("--format", "-f", default="text", choices=["text", "json", "visual"])

    args = parser.parse_args()
    result = calculate_structure(args.duration, args.type)
    print(format_output(result, args.format))


if __name__ == "__main__":
    main()
