# Captions & Stories — Templates and Rules

## TikTok Caption Template

**Max characters:** 2200

**Structure:**
```
LINE 1: Text hook (video reprise or different angle)
[blank line]
LINE 2-3: Expansion in 1-2 sentences (added value, NOT video repetition)
[blank line]
LINE 4: CTA (identical to video CTA)
[blank line]
LINE 5: Hashtags (3-5 specific)
```

**Example:**
```
Il tuo bottone CTA dice "Submit"?
Stai regalando conversioni alla concorrenza.

Un bottone efficace non dice cosa FAI
(submit, procedi, invia).
Dice cosa OTTIENI (scarica la guida,
prenota gratis, inizia ora).

Commenta "AUDIT" → ti mando la CRO Checklist
con 25 punti per il tuo funnel 📩

#CRO #ConversionRate #LandingPage
#FunnelOptimization #CROtips
```

## Instagram Reel Caption Template

**Max characters:** 2200
**Critical: first visible line without clicking "more" = MAX 125 CHARACTERS**

The first line of an IG caption is a **SECOND HOOK**. It's visible in the feed
without clicking "more". Treat it like a hook: it must contain the strongest
data/benefit/provocation in ≤125 characters.

**Structure:**
```
LINE 1: Hook (≤125 characters, visible without clicking "more") = SECOND HOOK
[blank line]
LINES 2-5: Added value / context (for those who click "more")
[blank line]
LINE 6: CTA with directional emoji
[blank line]
LINE 7: Hashtags (3-5)
```

**Example:**
```
Da 1.2% a 3.4% conversion rate in 14 giorni 📈

3 interventi sul checkout. Stesso traffico.
€23.000 in più al mese.

Il checkout è dove la maggior parte dei soldi
si perde. Non perché il prodotto non interessa
— perché il processo di acquisto è troppo complicato.

⬇️ Link in bio → CRO Checklist gratuita
con 25 punti da controllare sul tuo funnel.

#CRO #CaseStudy #ConversionRate
#EcommerceTips #DigitalEmpire
```

## Caption Rules (Non-Negotiable)

**Mandatory:**
- IG first line is a SECOND HOOK (≤125 chars, must contain data/benefit/provocation)
- Repeat the video CTA in the caption (many watch without audio)
- Add value NOT in the video (extra data, additional tip, different angle)
- Include CRO/conversion/funnel keywords in caption (social SEO)
- 3-5 specific hashtags

**Forbidden:**
- Empty caption or emoji-only
- "New video! Watch to the end 🔥🔥🔥" (zero value, zero SEO, zero hook)
- More than 5 hashtags (spam signal)
- Generic hashtags (#marketing #business #entrepreneur #success)

**Approved hashtags:**
#CRO, #ConversionRate, #LandingPage, #FunnelOptimization, #CROtips,
#DigitalEmpire, #AboveTheFold, #CheckoutOptimization, #EcommerceTips,
#CaseStudy, #ConversionOptimization, #ABTesting, #UXDesign,
#LandingPageTips, #FunnelProblems, #MarketingMemes

**Banned hashtags:**
#marketing, #business, #entrepreneur, #success, #motivation, #hustle,
#millionaire, #grind, #bossbabe, #digitalmarketing (too generic)

## Instagram Stories Templates

Stories spoken with the face are the most trust-building format on Instagram.
They must be quick to script (they're daily) but structured.

### Template A: Quick Thought 💭 (15 sec, 1 Story)

An observation made during work. Informal, direct, like talking to a colleague.

**Script template:**
```
"Una cosa veloce che ho notato oggi
mentre lavoravo su un funnel:
[specific insight in 1-2 sentences].
[Question to viewer or on-screen text with poll]"
```

**Example:**
```
"Ho appena analizzato un checkout
e il form aveva il campo 'fax'.
Nel 2025.
Chi usa ancora il fax?"

[Poll: "Il tuo form ha campi inutili?"
Options: "SÌ" / "Probabilmente sì"]
```

**Visual:** Face-to-camera, informal tone, slight sarcastic smile
**Use when:** Noticed something interesting at work, want quick audience interaction

---

### Template B: Behind the Work 🔧 (15-30 sec, 1-2 Stories)

Show what you're working on. Screen recording or screen photo.
Builds authority by showing WORK IN PROGRESS, not just results.

**Script template:**
```
"Vi faccio vedere su cosa sto lavorando.
[Screen recording or screen photo]
[Explain what you're doing in 2-3 sentences
without revealing sensitive client data]
[Professional comment/insight]"
```

**Example:**
```
"Sto facendo l'audit di una landing page.
[Show censored screenshot]
La prima cosa che noto:
zero social proof above the fold.
Il visitatore non ha motivo di fidarsi."
```

**Visual:** Story 1: face-to-camera intro. Story 2: censored screenshot with voiceover
**Privacy note:** ALWAYS censor client name, URL, and sensitive data
**Use when:** Working on an audit or CRO sprint, have an interesting screenshot to comment on

---

### Template C: CTA Story 🎯 (10-15 sec, 1 Story)

Story dedicated to the lead magnet. Brief, direct, with link sticker.
Use 1-2 times per week, NEVER every day (becomes spam).

**Script template:**
```
"Se [target's condition],
ho creato [lead magnet]
che ti mostra [benefit].
[Link sticker → lead magnet]"
```

**Example:**
```
"Se spendi in ads ma il tuo funnel
non converte come dovrebbe,
ho creato una checklist con 25 punti
da controllare prima di scalare.
[Link sticker: 'Scarica gratis']"
```

**Visual:** Face-to-camera, direct but not "salesy" tone. Link sticker at bottom.
**Link sticker text:** "Scarica gratis" or "Checklist →"

**Rules:**
- NEVER more than 2 CTA Stories per week
- ALWAYS after value Stories (never open with CTA)
- If possible, personalize for the Reel published the same day

---

### Stories Sequence (Daily Order)

Always: **Value → Value → CTA** (never CTA first)

**Example daily sequence:**
1. Quick Thought or Behind the Work (value)
2. If Reel published today: comment/amplify the Reel topic (value)
3. CTA Story (only if <2 this week)

**Estimated recording time:** 5-10 minutes for 2-3 structured Stories
