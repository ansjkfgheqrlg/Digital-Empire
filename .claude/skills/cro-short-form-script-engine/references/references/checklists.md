# Quality Checklists — Pre-Registration + Post-Publish

## Pre-Registration Checklist

Run this check on every script BEFORE recording. Fix all BLOCKING items.
IMPORTANT items should be fixed. RECOMMENDED items are nice-to-have.

### HOOK (B1)
| ID | Check | Severity |
|----|-------|----------|
| H1 | First sentence uses one of the 8 hook formulas? | BLOCKING |
| H2 | Does NOT start with "Ciao", "Hey", "In this video"? | BLOCKING |
| H3 | Specific to CRO target (not generic)? | BLOCKING |
| H4 | Contains a data point, provocation, or recognizable situation? | IMPORTANT |
| H5 | Is ≤15 words? | IMPORTANT |

**If H1 fails:** Rewrite using one of the 8 formulas from `references/hook_system.md`
**If H2 fails:** Delete the greeting. First word MUST be the hook.
**If H3 fails:** Add specific element: CRO metric, page element (checkout, landing, form, CTA)
**If H5 fails:** Cut. If you can't say it in 15 words, the hook is too complex.

### TENSION (B2)
| ID | Check | Severity |
|----|-------|----------|
| T1 | Bridge between hook and payload exists? | IMPORTANT |
| T2 | Viewer has a reason NOT to scroll after hook? | BLOCKING |
| T3 | Uses one of 3 techniques (amplification, false trail, promise)? | RECOMMENDED |

### PAYLOAD (B3)
| ID | Check | Severity |
|----|-------|----------|
| P1 | Contains ONE main concept only? | BLOCKING |
| P2 | Follows the structure of the chosen video type? | BLOCKING |
| P3 | Has at least 1 proof element (data, example, screenshot)? | BLOCKING |
| P4 | Has retention hooks every 20-30 sec (if >30 sec)? | IMPORTANT |
| P5 | Speaks in second person ("you", "your")? | IMPORTANT |
| P6 | Uses target language, not incomprehensible jargon? | IMPORTANT |
| P7 | No unverifiable claims? | BLOCKING |

**If P1 fails:** If you have 2+ concepts, choose the strongest one. Keep others for future videos.
Test: can you summarize in 1 sentence of 10 words? If not, cut.
**If P6 fails:** Would a non-technical entrepreneur understand every sentence?
"Heatmap" → "map of where people click." "Multivariate testing" → "testing multiple versions."
**If P7 fails:** Remove unsupported claims. "Guaranteed" → "in our tests."

### CTA (B4)
| ID | Check | Severity |
|----|-------|----------|
| C1 | ONE clear CTA present? | BLOCKING |
| C2 | Says what they GET (not just what to do)? | IMPORTANT |
| C3 | Consistent with active lead magnet? | BLOCKING |
| C4 | Repeated in caption? | IMPORTANT |

**If C2 fails:** "Comment AUDIT" → "Comment AUDIT and I'll send you the checklist with 25 points"

### TONE (Brand Voice)
| ID | Check | Severity |
|----|-------|----------|
| BV1 | Direct and confident, not arrogant? | IMPORTANT |
| BV2 | Data and proofs, not unsupported opinions? | BLOCKING |
| BV3 | Accessible language (non-technical entrepreneur understands)? | IMPORTANT |
| BV4 | Zero filler words? | IMPORTANT |

**If BV4 fails:** Eliminate: "fondamentalmente", "in pratica", "come sapete",
"è importante dire che", "va detto che", "a dire il vero"

### LENGTH
| ID | Check | Severity |
|----|-------|----------|
| L1 | Action: 15-45 sec? (~40-120 words) | IMPORTANT |
| L2 | Educational: 60-180 sec? (~160-480 words) | IMPORTANT |
| L3 | Proof: 30-90 sec? (~80-240 words) | IMPORTANT |
| L4 | Trend: 7-30 sec? (~20-80 words) | IMPORTANT |

## Post-Publish Checklist — After 24 Hours

Run 24 hours after publishing to evaluate performance and decide next actions.

### Metrics to Check

| ID | Metric | Target | If Below Target |
|----|--------|--------|-----------------|
| PP1 | Hook Rate | ≥30% | Hook doesn't stop scroll → test different hook (Hook Velocity) |
| PP2 | Watch Time | ≥50% of duration | Payload loses attention → add retention hooks, cut weak parts, alternate visuals more |
| PP3 | Save Rate | ≥2% of views | Content not practical enough → make more actionable with steps/checklist/framework |
| PP4 | Keyword Comments | ≥5 if keyword CTA | CTA unclear/unmotivating → explain WHAT they get, simplify keyword |
| PP5 | Comment Quality | In-target comments | Wrong audience → hook too generic, use "If [condition]" to filter |

**Where to find metrics:**
- Hook Rate: TikTok Analytics → Content → Video → Audience retention (first 3 sec)
- Watch Time: TikTok/IG Analytics → Content → Average watch time
- Save Rate: IG Insights → Reel → Saved / TikTok → Favorites
- Keyword Comments: count manually
- Comment Quality: read comments. Are they from ICP or random?

### Action Based on Results

**Winning video** (hook rate ≥30% AND watch time ≥50% AND save rate ≥2%):
- Activate Script Remix: create 3 variants (Zoom In, Different Angle, Different Format)
- Save hook to personal Hook Playbook as proven pattern
- Consider: can you make a series? ("Part 2", "Error #2", etc.)
- Cross-post on other platform (TikTok → IG Reel, and vice versa)

**Average video** (hook rate 20-30% AND watch time 30-50%):
- Test Hook Velocity: 3 different hooks on same payload
- Don't create variants — content works but execution needs improvement
- Analyze: which part of the video has the biggest drop? Fix that.

**Flop video** (hook rate <20% OR watch time <30%):
- Do NOT repost the same video
- Analyze: is the problem the hook or the content?
- If hook rate <20%: topic doesn't interest OR hook is weak
- If hook rate OK but watch time low: payload doesn't deliver on the promise
- Save the topic but completely change hook and angle
- Move on — don't invest time in content that doesn't resonate
