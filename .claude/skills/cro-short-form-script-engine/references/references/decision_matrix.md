# Decision Matrix — Request Routing + Script Remix

## 7 Routing Scenarios

### Scenario 1: User has a specific pain point
**Trigger phrases:** "I want to talk about errors in...", "the checkout problem",
"pain point", "the target doesn't know that..."

→ **Type:** Action
→ **Hooks:** F1 (Data Shock), F4 (If...Then)
→ **Structure:** Problem → Amplification → Fix → CTA
→ **Duration:** 30 sec
→ **Example:** "Voglio parlare di errori nel checkout — dammi lo script"

---

### Scenario 2: User has a framework/method to teach
**Trigger phrases:** "I want to explain", "framework", "method", "how it works",
"the 3 elements", "the N rules"

→ **Type:** Educational
→ **Hooks:** F2 (Provocation), F7 (Most People)
→ **Structure:** Context → N points → Example → Takeaway → CTA
→ **Duration:** 90 sec
→ **Example:** "Voglio spiegare i 3 elementi dell'above the fold"

---

### Scenario 3: User has a case study with numbers
**Trigger phrases:** "case study", "I increased", "we did", "result for a client",
"from X% to Y%", "CRO sprint completed"

→ **Type:** Proof
→ **Hooks:** F6 (I Found), F1 (Data Shock)
→ **Structure:** Before → What we did → After → Why → CTA
→ **Duration:** 60 sec
→ **Example:** "Ho aumentato il CR del 47% per un cliente — fammi il video"

**Important:** Ask for data if not provided: sector, CR before/after, interventions,
timeline, revenue impact.

---

### Scenario 4: User has a viral trend to ride
**Trigger phrases:** "trend", "viral", "trending audio", "format going around",
"I want to ride", "meme", "this sound"

→ **Type:** Trend
→ **Hooks:** F3 (POV/Situation), trend-native
→ **Structure:** Trend → CRO Twist → Punchline → Brief CTA
→ **Duration:** 15 sec
→ **Example:** "C'è un trend 'red flag' — voglio farlo sui funnel"

**Important:** Ask which specific trend/audio/format they want to use.

---

### Scenario 5: User wants variants of a winning video
**Trigger phrases:** "variants", "got views", "performed", "remix", "redo it",
"different angle", "different version"

→ **Type:** Variable (use original video's type)
→ **Structure:** Use Script Remix (see below)
→ **Duration:** Same as original
→ **Example:** "Questo video ha fatto 40k views — fammi 3 varianti"

---

### Scenario 6: User has only a rough idea
**Trigger phrases:** "rough idea", "I want to talk about", "I have in mind",
"I had an idea", "I could make a video about"

→ **Action:** Ask clarifying questions before writing

**Questions to ask:**
1. What specifically do you want to talk about? (specific topic)
2. Do you have data or a case study to use?
3. Do you want a short direct video (30 sec) or a deep dive (90 sec)?
4. Platform? TikTok or IG Reel?

---

### Scenario 7: User needs to promote the lead magnet
**Trigger phrases:** "promote the checklist", "push the lead magnet",
"video for the lead magnet", "get downloads", "push on lead magnet"

→ **Type:** Action
→ **Hooks:** F8 (Mistake), F4 (If...Then)
→ **Structure:** Show 1-2 errors from checklist → Quick fix →
  "These are just 2 of the 25 points. Comment AUDIT for the full list."
→ **Duration:** 30 sec
→ **Example:** "Devo spingere la CRO Checklist — script per TikTok"

## Script Remix System

When a video performs well (≥30k views OR ≥3% engagement rate OR ≥2% save rate),
create 3 variants without rebuilding from scratch.

### Variant 1: ZOOM IN 🔎
Take ONE of the points/errors/steps from the original video and make an ENTIRE
video dedicated to it.

**How to do it:**
1. Identify the point that generated the most comments/questions
2. Create an Action or Educational video dedicated ONLY to that point
3. Open with: "Vi ho parlato di [N] errori nel [topic]. Oggi approfondiamo
   il #[X] perché è quello che da solo costa di più."
4. Go deep: more details, more examples, specific screenshots

### Variant 2: DIFFERENT ANGLE 🔄
Same fundamental content, but for a DIFFERENT AUDIENCE or with different FRAMING.

**How to do it:**
- Change the target sector (e-commerce → SaaS, B2C → B2B)
- Change the framing (from "errors" to "best practices")
- Change the level (basic entrepreneur → expert marketing manager)
- Change the platform (TikTok → IG Reel with different tone)

### Variant 3: DIFFERENT FORMAT 📐
Transform the video into a DIFFERENT FORMAT.

**Options:**
- Spoken video → IG carousel (8-10 slides with more detail per slide)
- Educational video → Action video (extract 1 point and do quick fix)
- Long video (90 sec) → Short video (30 sec) with only the highlight
- Short video (30 sec) → Long video (90 sec) with depth
- Video → LinkedIn/X text thread

## Hook Velocity (A/B Testing)

For a video you want to test or relaunch:

1. Take the payload (B2 + B3 + B4 — identical)
2. Write 5 hooks using 5 different formulas
3. Record 5 versions (change only the first 3 seconds)
4. Publish: 1/day for 5 days, or 3 on TikTok + 2 on IG
5. After 48h per video: compare hook rate and watch time
6. The winning hook becomes your "proven template" for that topic

**Metrics to compare:**
- Hook rate: % who watch past first 3 sec (target: ≥30%)
- Average watch time: target ≥50% of video duration
- Completion rate: target ≥15% TikTok, ≥20% IG Reel

**Publish variants 3-5 days apart.** The algorithm penalizes similar content published close together.
