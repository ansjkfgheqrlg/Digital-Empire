# CRO Short-Form Script Engine

USE THIS SKILL whenever the user wants to:
- Write a script for a TikTok or Instagram Reel video
- Create a short-form video script (15-180 seconds)
- Transform a rough idea into a ready-to-record script
- Write captions or descriptions for social video posts
- Create hook variants or A/B test different openings
- Generate script variants from a video that performed well
- Write scripts for Instagram Stories (spoken/face-to-camera)
- Create scripts that promote a lead magnet
- Turn a case study into a short video script

Also trigger when the user mentions: hook, script, reel, tiktok,
short-form, caption, teardown video, case study video, video breve,
CRO video content, stories parlate, varianti hook, script remix.

DO NOT use this skill for:
- Deciding WHAT to publish (use Social Growth Engine)
- Writing landing page / sales page copy (use CRO Copy Architect)
- YouTube long-form scripts 7+ min (use YouTube Script Factory PRO)
- Email sequences (use Email Sequence Master)
