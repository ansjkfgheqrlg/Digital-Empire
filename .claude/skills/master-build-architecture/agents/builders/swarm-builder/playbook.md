# Swarm-Builder Playbook

1. Receive vision + MKD + principles from Conductor.
2. Decide primary topology (log as DEC).
3. Define all agents/teams with roles, boundaries, handoffs.
4. Produce topology map and registry.
5. Emit Ruflo integration commands.
6. Ensure memory ecosystem integration.
7. Handoff specs to agent-spec-builder or specific builders.
