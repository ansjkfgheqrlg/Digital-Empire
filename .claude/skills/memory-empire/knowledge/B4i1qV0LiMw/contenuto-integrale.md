## Il Metodo in 4 Passi (estratto completo)

### Passo 1 — Il Design System
**Cos'è:** Colori, font e componenti del brand codificati in Claude Design.  
**Come si crea:**
1. claude.ai/design → New prototype → Design System
2. "Set up your design system": company name + blurb + brand materials (GitHub link, .fig file, font/logo upload)
3. "Quick questions": existing materials? · cosa fa il prodotto? · quali superfici (website/app/slide deck)?
4. Output: Slides template + Type + Colors + Spacing + Components + Brand  

**Struttura Design System Avanguardia (esempio reale):**
- Type: Body=Inter, Display=Frutiger, Hero numerals & pull-quote
- Colors: 8 categorie (sage, blue, violet, rose, peach, teal, mustard, terracotta)
- Components: Diagram nodes, Pills & icon containers, Shelf card, Slide chrome
- Brand: Logo & lockup (on paper / on ink), Wordmark

**Problema frequente:** "Missing brand fonts" → upload manuale file font

### Passo 2 — I Template
**Cos'è:** Layout di partenza pronti da riempire, salvati come Design Files nel Design System.  
**Come si usano:**
- Un nuovo progetto sceglie il design system esistente come default → brand-aligned automaticamente
- "Start with context" sidebar: Design System, Add screenshot, Attach codebase, Drag in a Figma file
- Le slide hanno già il grid, la tipografia, i colori → modificare solo il contenuto

**Esempio libreria template Avanguardia:** YouTube Templates (50+ slide), Slides YouTube, LinkedIn DS, Funnels LinkedIn, App onboarding

### Passo 3 — Le Skills (Claude Code)
**Cos'è:** Istruzioni riutilizzabili per ogni tipo di output — non in Claude Design ma in Claude Code.  
**Come si creano:**
- Skill `skill-creator` da Anthropic (github.com/anthropics/skills)
- Si descrive un workflow ripetuto → skill-creator lo converte in SKILL.md con slash command
- Le skill vengono organizzate in `.claude/skills/` del progetto

**Lista skills Social Media Manager di Giovanni (25+ skill):**
draft-to-youtube · email-digest · escaladraw-flowchart · humanizer · linkedin-post · pre-mortem · prompt-contracts · query-anthropic · research · reverse-prompting · schedule-meeting · scroll-journey · shorts · sign · skill-creator · skill-extraction-skool · skool-community-replies · skool-video-upload · step-back-prompting · video-extraction · write-skool-module · youtube-comments · youtube-description

**Skill chiave dimostrata:** `featuresheet:cheat-skill` — genera cheat sheet 1080×1350 PNG + PDF branded in un solo prompt. Include self-check automatico (Claude guarda il PNG generato e corregge errori tipografici prima di consegnare).

### Passo 4 — Il Lead Magnet Automatizzato
**Cos'è:** Connettere Design System + Template + Skills per produrre asset pronti alla distribuzione come lead magnet LinkedIn.  
**Meccanica lead magnet:**
- Keyword nel commento deve combaciar col regalo (es. "FUNNEL" per un funnel, "Claude" per la guida Claude)
- CTA: "Commenta '[keyword]' e te lo mando personalmente" + scarcity (XX/100)
- Claude Code scrive anche il LinkedIn post con il CTA già integrato

**Output dimostrati nel video:**
1. "The Thought Leader Funnel" — 5 stadi (Awareness→Authority→Intent→Conversion→Advocacy)
2. "The Founder Authority Stack" — 7 layers (Audience→Visibility→Content→Authority→Capture→Revenue→Compounding)
3. "Il Mio Claude Personal Assistant" — 4 skill categories come infografica lead magnet
