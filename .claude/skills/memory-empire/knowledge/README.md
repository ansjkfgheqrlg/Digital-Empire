# Memory Empire - knowledge/

Qui finisce, **per intero**, ogni contenuto ingerito da Digital Empire.

## Regole
- **Mai riassunti, mai compattazione.** Si salva tutto il valore e tutta la
  formazione (principio di content-forge). Espansione, non compressione.
- **Un file per ingestione** (o cartella per canale/multi-video). Nome
  Windows-safe (no `( ) : + ?`).
- **Sempre con trace** alla fonte: `video-id#timestamp + frame`, URL, o `file:riga`.
- **Doppio salvataggio**: lo stesso contenuto va anche nella wiki
  (`second-brain-vault/wiki/`). Qui resta la copia integrale "di lavoro".

## Da dove arriva
Il contenuto e' prodotto da **Empire Studio** (guarda i video, estrae transcript
+ visione + atomi, forgia via content-forge gestito dagli agenti). Il
**knowledge-keeper** di Memory Empire lo deposita qui e aggiorna `../index.md`.

## Struttura tipica di una voce
```
knowledge/<slug-fonte>/
├── contenuto-integrale.md   (transcript + visione + tutta la formazione)
├── atoms.json               (atomi con trace)
└── fonte.txt                (link/percorso originale)
```
