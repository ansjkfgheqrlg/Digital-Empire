# Workflow Library

`WF-0` è obbligatorio per ogni nuovo prodotto: definisce il flusso di valore principale prima di qualunque SRS, UX, architettura o implementazione.

## Gate WF-0

SUP approva WF-0 soltanto se sono chiari attore, trigger, obiettivo, happy path, decisioni, dati, errori, autorizzazioni, esito e metrica. Il workflow deve essere tracciato a RF, UI, API, dati e test.

Crea un file per workflow usando il template in `../rules/workflow.md`:

```text
WF-001-nome-flusso.md
```

Un workflow deprecato rimane nel repository, marcato come tale e collegato al suo sostituto.
