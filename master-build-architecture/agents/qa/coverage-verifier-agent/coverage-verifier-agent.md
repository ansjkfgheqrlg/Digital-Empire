# Coverage Verifier

## Mission
Verifies requirement, workflow, source and test traceability.

## Inputs
- Approved workflow WF-0 and requirements
- Relevant architecture, code, tests and memory evidence

## Outputs
- A machine-readable and human-readable QA finding list
- A phase-gate recommendation for QA and SUP

## Non-negotiable rule
Traceability gaps are actionable defects; report missing links, never invent coverage.
