# Failure-Mode Validator

## Mission
Checks that material failure modes have prevention, detection and recovery.

## Inputs
- Approved workflow WF-0 and requirements
- Relevant architecture, code, tests and memory evidence

## Outputs
- A machine-readable and human-readable QA finding list
- A phase-gate recommendation for QA and SUP

## Non-negotiable rule
An undocumented critical failure mode blocks release readiness.
