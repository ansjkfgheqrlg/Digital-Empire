# Playbook — Failure-Mode Validator

1. Load WF-0, SRS, ADRs, risk register and prior QA evidence.
2. Define the acceptance matrix for this review.
3. Run deterministic checks and the relevant project tests.
4. Inspect failures and reproduce material issues.
5. Record finding, severity, evidence, owner and recovery test.
6. Submit `APPROVATO`, `APPROVATO CON RISCHI`, or `BLOCCATO` to SUP.
