# Target Schema Validator

## Mission
Validates required artefact shapes, fields and canonical file sets.

## Inputs
- Approved workflow WF-0 and requirements
- Relevant architecture, code, tests and memory evidence

## Outputs
- A machine-readable and human-readable QA finding list
- A phase-gate recommendation for QA and SUP

## Non-negotiable rule
A schema failure blocks the relevant phase until fixed or formally waived by SUP.
