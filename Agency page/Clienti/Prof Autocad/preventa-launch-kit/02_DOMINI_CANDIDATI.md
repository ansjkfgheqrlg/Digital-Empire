#### DOMINIO 1 - Primario - `preventa.it` [DEFAULT CONSIGLIATO]

**Perché:** Exact match brand, massimo trust per titolare concessionario italiano (over 40, abituato a .it), perfetto per SEO "preventa concessionari". Corto, memorizzabile, coerente con materiali stampati.

- Se occupato: verifica whois data scadenza + contatta owner per acquisto (budget 300-1500€ stimato se in parking). Se prezzo alto, passa a 2/3.

**Azioni:**

#### DOMINIO 2 - Tech / Fallback professionale - `preventa.pro` + `preventa.app`

**Perché:** Se preventa.it occupato o troppo caro, `.pro` comunica professionalità B2B ("per concessionari PRO") e `.app` comunica software. Entrambi liberi con alta probabilità (meno richiesti di .it/.com). Ottimo per landing tech + docs.

**Disponibilità da verificare:**
- `preventa.pro`: probabilità libero ALTA (~80% stimato). Poco usato in Italia, perfetto per SaaS B2B.
- `preventa.app`: richiede HTTPS obbligatorio (Google Registry), vantaggio sicurezza. Probabilità libero MEDIA-ALTA. Costo ~15-20€/anno.
- `preventa.cloud`: alternativa se .pro/.app occupati.

**Strategia dual-domain:**
- Registra `preventa.it` → redirect a `preventa.pro` se .it in trattativa, o viceversa.
- Usa `preventa.pro` come dominio app (app.preventa.pro) e `preventa.it` come marketing.

**SEO:** .pro/.app non penalizzano ranking in Italia se contenuti in IT e hreflang corretto.

#### DOMINIO 3 - SEO / Azione / Fallback verbale - `usapreventa.it` o `getpreventa.it` + `preventaauto.it`

**Perché:** Se vuoi keyword esplicita per concessionari + CTA d'azione. Ottimo per campagne Google Ads "preventivi concessionari auto". Disponibilità quasi certa (domini composti).

**Opzioni valutate (scegline 1):**

A) **`usapreventa.it`** - CTA italiana diretta, suona come invito. Perfetto per bottone "Usa Preventa". Disponibilità stimata 95% libero. Pro: italiano, azione. Contro: più lungo.

B) **`getpreventa.it`** - Inglese ma standard SaaS (get + brand). Usato da Stripe, Notion ecc. Disponibilità stimata 90% libero. Pro: internazionale se apri ES. Contro: meno fiducia per titolare 55enne.

C) **`preventaauto.it`** - SEO puro, keyword "preventa auto" → rank facile su "software preventivi auto". Disponibilità stimata 95% libero. Pro: SEO immediato. Contro: meno brand, più descrittivo.

**Consiglio:** Se preventa.it libero, registra anche `usapreventa.it` come redirect per campagne: ads → usapreventa.it → landing preventa.it. Costo 6€/anno, protegge brand.
