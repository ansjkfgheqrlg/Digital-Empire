# Rulebook — Principi canonici del progetto

Questa cartella contiene regole riusabili e vincolanti. In caso di conflitto valgono: requisiti utente approvati → ADR approvato → regole qui contenute → convenzioni locali.

- `workflow.md` — ogni applicazione nasce da un workflow verificabile.
- `graphics-ui.md` — principi di grafica, UX, accessibilità e responsive design.
- `links-integrations.md` — link, navigazione, API e integrazioni esterne.
- `delivery-workflow.md` — processo operativo, quality gates e gestione cambi.

Ogni eccezione deve essere registrata in un ADR con owner, impatto e data di revisione.
