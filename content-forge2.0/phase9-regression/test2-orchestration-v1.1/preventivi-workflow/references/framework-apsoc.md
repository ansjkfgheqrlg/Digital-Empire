# Framework APSOC

> Il framework cardine applicato dal workflow.

## I 5 componenti

1. **Attention**: hook iniziale per catturare attenzione
2. **Problem**: amplifica il problema del prospect (NO mention del prodotto)
3. **Solution**: presenta la soluzione (la tua offerta)
4. **Objections**: gestisce le 11 obiezioni tipiche via CPB
5. **CTA**: call to action chiara

## Ordine non-negoziabile

A → P → S → O → C in sequenza. Saltare uno → output debole.

## Connessioni

- Apsoc-builder skill applica A+P+S
- Objections-handler agent applica O
- Cta-writer agent applica C
