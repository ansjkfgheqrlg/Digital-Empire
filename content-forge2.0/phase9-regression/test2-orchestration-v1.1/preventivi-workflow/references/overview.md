# Overview Preventivi Workflow

Workflow completo per costruzione preventivi efficaci per freelancer italiani.

## Stadi

1. Discovery (cliente, problema, budget)
2. APSOC application (Attention/Problem/Solution/Objections/CTA)
3. Pricing strategy (3 opzioni)
4. QA review (11 checklist points)
5. Humanization (eliminare LLM-speak)

## Quando usare quale comando

- /preventivo full: pipeline completo (90-120 min)
- /preventivo ad: quick ads (15-20 min)
- /preventivo sales-page: sales page completa
- /preventivo email: sequenza email

## ➕ Esempio

Cliente videomaker B2B → /preventivo full → output: preventivo strutturato 5 pagine.
