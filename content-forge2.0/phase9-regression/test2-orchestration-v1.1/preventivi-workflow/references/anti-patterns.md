# Anti-Patterns

| # | Anti-pattern | Sintomo | Fix |
|---|---|---|---|
| 1 | Skippare Discovery | Output generic | Force discovery sempre |
| 2 | Listino prezzi pure | Cliente sparisce | Strategia 3 opzioni |
| 3 | Parola "costo" | Posizionamento debole | Usa "investimento" |
| 4 | Nessuna scadenza | Cliente prende tempo infinito | Default 15gg |
| 5 | Promesse vague | "Aumenteremo vendite" | Quantifica sempre |
