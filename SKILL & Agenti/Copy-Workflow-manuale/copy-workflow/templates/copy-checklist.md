## QUALITÀ GENERALE (max ±10 punti)

### Penalità (sottrarre)

| Errore Rilevato | Penalità |
|---|---|
| Soluzione menzionata prima del problema | -15 |
| Headline generica (usabile per qualsiasi prodotto) | -10 |
| Obiezioni generate ma non gestite | -10 |
| Features senza benefits (lista tecnica senza "il che significa...") | -8 |
| Linguaggio da marketer nel corpo del copy | -8 |
| CTA superficiale ("compra ora" non connesso al pain point) | -5 |
| Tono arrogante senza prove a supporto | -5 |
| Nessuna urgenza o conseguenza del non agire | -5 |
| Struttura visiva assente (nessun titolo, nessun grassetto, paragrafi enormi) | -3 |
| Ripetizioni inutili (stessa parola/concetto più volte senza motivo) | -3 per occorrenza |

**Penalità totali**: -___

### Bonus (aggiungere)

| Elemento Bonus Presente | Bonus |
|---|---|
| Storytelling autentico nel problema | +3 |
| USP realmente differenziante (non generico) | +2 |
| Prove di alto valore (dati reali, caso studio dettagliato) | +2 |
| Sequenza logica impeccabile (ogni sezione prepara la successiva) | +2 |
| Linguaggio del target usato perfettamente | +1 |
