# Quick Ad Workflow
> Produce ads (Facebook/Instagram/TikTok/Google) in 15-20 minuti

**Durata**: 15-20 minuti
**Output**: 3 varianti ad complete (headline + copy + CTA)
**Agenti usati**: A1 lite → A2 lite → A3 → A4 breve → A7

---

## Quando Usarlo

- Hai bisogno di ads rapidamente per testare
- Budget test: non vale la pena del pipeline completo
- Target già noto (hai già l'avatar)
- Prodotto semplice / low-ticket

---

## Format Supportati

| Piattaforma | Formato | Lunghezza Max |
|---|---|---|
| Facebook/IG Ad | Immagine + testo | 125 caratteri primary text, 40 headline |
| Facebook/IG Ad | Carosello | 125 char/card |
| TikTok | Script video breve | 15-60 secondi |
| Google Search | Headline + description | 30 char headline, 90 char description |
| LinkedIn | Sponsored content | 150 char intro |

---

## Il Pipeline Quick Ad

### Step 1 — Input Veloce (2 min)

```
Domande obbligatorie:
1. Prodotto + prezzo: [...]
2. Target in 1 frase: [...]
3. Pain point principale: [...]
4. Piattaforma ad: [Facebook/IG / TikTok / Google / LinkedIn]
5. Obiettivo: [vendita / lead / click / awareness]
```

### Step 2 — Strategia (3 min)

Scegli automaticamente:
- Strategia headline: Pain Point Diretto o Curiosità (best per ads fredde)
- Approccio problema: Scenario vivido o Domanda (2-3 righe max)
- CTA: Profondo orientato al pain point

### Step 3 — Scrittura 3 Varianti (10 min)

**Variante A — Pain Point Diretto**
```
Headline: [pain point + conseguenza in 6-8 parole]
Primary Text: [scenario 2-3 righe + accenno soluzione]
CTA Button: [azione specifica]
```

**Variante B — Curiosità**
```
Headline: [domanda che genera curiosità]
Primary Text: [accenno a insight + USP]
CTA Button: [scopri/leggi/guarda]
```

**Variante C — USP / Semplicità**
```
Headline: [USP chiaro e diretto]
Primary Text: [3 bullet points vantaggi]
CTA Button: [azione di acquisto]
```

### Step 4 — QA Rapido (2 min)

Verifica:
- [ ] Ogni ad ha A + P (almeno accenno) + C
- [ ] Nessuna headline generica
- [ ] CTA è specifico (non solo "clicca qui")
- [ ] La variante A, B, C sono sufficientemente diverse per testare

## Template per Tipo di Ad

### Facebook/IG — Formula Provata

```
HEADLINE: "[Pain point o USP in 5-8 parole]"

PRIMARY TEXT:
"[Scenario vivido in 1-2 frasi che fa dire 'sono io']

[Soluzione accennata + USP in 1 frase]

[CTA diretto con micro-copy]"

BUTTON: [Scopri Come / Inizia Ora / Leggi Di Più]
```

### TikTok — Script 15-30 secondi

```
[0-3 sec] HOOK: "[Frase che ferma lo scroll — domanda o affermazione shock]"
[3-10 sec] PROBLEMA: "[Descrizione vivida del problema in modo scenico]"
[10-20 sec] SOLUZIONE: "[Il prodotto come risposta — breve e chiara]"
[20-25 sec] PROVA: "[Risultato concreto o social proof rapida]"
[25-30 sec] CTA: "[Azione + urgenza]"
```

### Google Search — Formula SEO-Copy

```
HEADLINE 1: [Keyword principale + benefit]
HEADLINE 2: [Differenziatore / USP]
HEADLINE 3: [CTA + urgenza o garanzia]

DESCRIPTION 1: [Pain point + soluzione in 90 caratteri]
DESCRIPTION 2: [Prova + CTA in 90 caratteri]
```

