# landing-forge - Playbook

## Flusso operativo

1. Ricevi brief + prezzo + copy
2. Seleziona template empire-premium-style
3. Genera landing page con content-forge2.0
4. Genera 3 email di funnel
5. Salva tutto in `deliverables/`
6. Memory checkpoint
7. Handoff a email-lifecycle-specialist

## Handoff
A email-lifecycle-specialist con funnel pronto.
