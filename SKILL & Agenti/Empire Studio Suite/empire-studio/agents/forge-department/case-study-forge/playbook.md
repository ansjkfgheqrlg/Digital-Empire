# case-study-forge - Playbook

## Flusso operativo

1. Ricevi dati del progetto (Novacar, metriche, ecc.)

3. Genera case study con content-forge2.0
4. Salva in `deliverables/`
5. Memory checkpoint
6. Handoff a landing-forge o outreach
