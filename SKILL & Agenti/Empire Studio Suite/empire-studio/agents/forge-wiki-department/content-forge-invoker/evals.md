# content-forge-invoker - Evals (casi discriminanti)

## EV-01 - Forge wiki
- **Input:** forge-input completo
- **Atteso:** wiki-notes atomiche + MKD
- **Voto:** PASS se il criterio sopra e soddisfatto

## EV-02 - Trace nelle note
- **Input:** atoms con trace
- **Atteso:** note con trace alla fonte
- **Voto:** PASS se il criterio sopra e soddisfatto

## EV-03 - Coverage
- **Input:** N atomi
- **Atteso:** >=90% atomi presenti nelle note
- **Voto:** PASS se il criterio sopra e soddisfatto

## EV-04 - Fallback
- **Input:** forge ko
- **Atteso:** MKD interno generato
- **Voto:** PASS se il criterio sopra e soddisfatto
