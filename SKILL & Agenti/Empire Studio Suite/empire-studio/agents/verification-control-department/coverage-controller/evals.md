# coverage-controller - Evals (casi discriminanti)

## EV-01 - Coverage alta
- **Input:** forge completo
- **Atteso:** >=90% atomi nelle note
- **Voto:** PASS se il criterio sopra e soddisfatto

## EV-02 - Gap
- **Input:** atomi persi
- **Atteso:** gap segnalati + ri-forge
- **Voto:** PASS se il criterio sopra e soddisfatto

## EV-03 - Trace
- **Input:** qualunque
- **Atteso:** 100% atomi con trace
- **Voto:** PASS se il criterio sopra e soddisfatto

## EV-04 - No duplicati
- **Input:** atomi ripetuti
- **Atteso:** conteggio corretto
- **Voto:** PASS se il criterio sopra e soddisfatto
