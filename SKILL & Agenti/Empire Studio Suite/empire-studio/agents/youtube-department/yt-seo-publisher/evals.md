# yt-seo-publisher - Evals

## Criteri di successo
- Video caricato con successo
- URL YouTube valido
- Descrizione contiene link Manuale
- Trace P12 presente
- Checkpoint Memory salvato

## Casi di fallimento
- Errore di autenticazione API
- Quota giornaliera esaurita
- Video troppo lungo
- Errore thumbnail

## Metriche
- Tempo di pubblicazione
- Tasso di successo upload
- CTR medio primi 24h (da yt-performance-analyzer)
