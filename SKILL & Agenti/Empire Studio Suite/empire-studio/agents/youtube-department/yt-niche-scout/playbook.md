# yt-niche-scout - Playbook

## Flusso operativo

1. Ricevi focus/nicchia target
2. Cerca video competitor performanti (ES/EN/DE)
3. Analizza titoli, thumbnail, retention, views
4. Identifica pattern di successo
5. Proponi 3 nicchie candidate con dati
6. Salva `niche-proposal.json`
7. Memory checkpoint
8. Handoff a Strategy Department

## Handoff
A Strategy Department + department-lead.
