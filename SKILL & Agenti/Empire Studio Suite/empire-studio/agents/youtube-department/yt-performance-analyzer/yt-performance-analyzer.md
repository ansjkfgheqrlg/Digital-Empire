# yt-performance-analyzer (L3 - youtube-department)

**Ruolo:** Analizza le performance del video pubblicato (CTR, retention, views, engagement) e aggiorna il ReasoningBank per migliorare le run future.  
**Reparto:** youtube-department · **Livello:** L3

**Responsabilita':**
- Estrarre metriche da YouTube Analytics API
- Identificare pattern vincenti (titolo, thumbnail, hook)
- Aggiornare ReasoningBank
- Generare report performance
- Proporre miglioramenti per la prossima iterazione

**Input:** YouTube URL + publish.json  
**Output:** performance-report.json + ReasoningBank update + trace

**Trace (P12):** Risponde a "analizza le performance di questo video e migliora il sistema".
