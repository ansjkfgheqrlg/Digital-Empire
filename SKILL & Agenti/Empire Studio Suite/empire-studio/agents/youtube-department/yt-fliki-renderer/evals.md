# yt-fliki-renderer - Evals

## Criteri di successo
- Video generato entro 5 minuti
- Status "completed"
- File MP4 valido (1080p)
- Trace P12 presente
- Checkpoint Memory salvato

## Casi di fallimento
- Timeout API
- Limite rate raggiunto
- Errore di autenticazione
- Video corrotto

## Metriche
- Tempo medio di render
- Tasso di successo
- Errori per 100 render
