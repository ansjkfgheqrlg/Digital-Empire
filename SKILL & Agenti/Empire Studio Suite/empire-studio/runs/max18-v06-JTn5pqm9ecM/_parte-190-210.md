# Commit

## Goal
Ship code to GitHub with automated testing and PR creation — no manual git commands.

Full pipeline: test check -> staged diff review -> selective git add -> commit -> push -> open PR.

## Gotchas

**Never use `git add .` or `git add -A`**
The project root has loose files (.env, credentials, data/) that must stay
untracked. Always `git add` specific files or directories by name.

**Tests first, push second**
Run `pytest tests/ -v` before committing. If tests fail, abort the pipeline and fix
the issue. Never push broken tests.

**Force push is always the user's call**
If `git push` is rejected, stop and ask. Never force push to main.

**Always open a PR after pushing**
Per project rules, always create a PR automatically after pushing a feature branch.
Never ask for permission — just do it (see feedback_always_open_pr.md).

**Never commit directly to main**
Always use feature branches (see .claude/rules/git.md).
