AI - PER CODING E SIMILI
Lezione 17 - Introduzione al vibe coding
Panoramica

In questa lezione impari cos'è il vibe coding e come creare un sito web da zero usando Claude, senza saper programmare. Installi Visual Studio Code con l'estensione Live Server, capisci la struttura base di HTML5 (tag, elementi semantici come header/main/footer), CSS3 (reset, collegamento al foglio di stile) e JavaScript (variabili, getElementById, event listener). Impari a comunicare con Claude in formato JSON, a fargli generare un prompt ottimizzato e poi il codice del sito diviso in tre file separati. Carichi tutto su GitHub e scopri come inserire immagini tramite hosting esterno. Una panoramica pratica per partire.

Cosa hai imparato

Cos'è il vibe coding: generare codice (siti web, automazioni) sfruttando l'AI, senza saper programmare

Per usare bene l'AI nel coding, serve capire almeno le basi di come funziona un sito web o un'automazione

Scaricare e installare Visual Studio Code come interprete/editor di codice

Creare il primo file HTML e chiamarlo index.html (perché gli hoster lo riconoscono come pagina principale)

Creare un nuovo file in VS Code: cliccare nella cartella, scrivere il nome del file nella riga "New File"

Usare la shortcut html:5 per generare automaticamente la struttura base di una pagina HTML

Differenza tra <head> (collegamenti, CSS, SEO) e <body> (contenuto visibile della pagina)

Usare i tag principali dell'HTML: <h1> fino a <h6> per i titoli, <p> per i paragrafi

Usare il trucco lorem + numero di parole per generare testo placeholder in VS Code

Installare l'estensione Live Server su VS Code per vedere le modifiche al sito in tempo reale

Aprire il sito in locale con tasto destro → "Open with Live Server"

Dividere lo schermo tra codice e browser per lavorare più comodi

Strutturare il body in tre contenitori semantici: <header> (navbar), <main> (contenuto), <footer> (info legali, copyright)

Perché usare i tag semantici: servono per accessibilità (screen reader per non vedenti), SEO e indicizzazione su Google

Creare un file style.css separato per lo stile del sito

Resettare il CSS di default con il reset universale: * { padding: 0; margin: 0; box-sizing: border-box; }

Collegare il CSS all'HTML inserendo nel <head> il tag <link rel="stylesheet" href="./style.css">

Cos'è padding (spaziatura interna), margin (spaziatura esterna) e box-sizing

Modificare lo stile di un elemento tramite CSS (es. h1 { color: red; })

Il ruolo di JavaScript: rendere le pagine dinamiche (bottoni, popup, interazioni)

Usare gli ID per identificare i tag HTML e recuperarli con JavaScript tramite document.getElementById()

Creare un file main.js e collegarlo alla fine del body (prima della chiusura </body>) con <script src="./main.js">

Usare le variabili in JavaScript (let) per salvare elementi della pagina

Aggiungere un event listener a un bottone per eseguire un'azione al click

Modificare il contenuto di un tag con .innerHTML

Per le automazioni, usare Python perché ha più librerie e possibilità (incluse le chiamate API)

Cosa sono le API: prendono dati, li inviano a un server/database e ricevono una risposta

Usare il formato JSON per comunicare con l'AI, perché lo capisce molto meglio del linguaggio naturale

Il JSON funziona come una scaletta strutturata che divide il progetto in sezioni e sottosezioni

Workflow vibe coding: prima farsi generare un prompt in formato JSON dall'AI, poi usare quel prompt per farle creare il sito

Chiedere a Claude "È il miglior prompt che puoi darmi?" per farlo iterare e migliorare il risultato

Rispondere alle domande di approfondimento di Claude (target, stile visivo, servizi extra) per ottenere un prompt più preciso

Specificare a Claude le tecnologie da usare (HTML5, CSS3, JavaScript) nel prompt

Copiare il prompt JSON finale, aprire una nuova chat e incollarlo per far generare il codice del sito

Chiedere a Claude di separare il codice in tre file distinti (HTML, CSS, JS) se li genera in un file unico

Tenere sempre HTML, CSS e JS in file separati: migliora la leggibilità, facilita le modifiche con l'AI e evita errori del server

Copiare il codice generato da Claude nei rispettivi file su VS Code e aprire con Live Server per vedere il risultato

Cos'è un code block: una piccola parte di codice che puoi individuare e modificare manualmente o con l'AI

Differenza tra front-end (ciò che vede l'utente) e back-end (ciò che accade dietro le quinte, es. automazioni)

Il form di contatto generato dall'AI non funziona da solo: va collegato a un back-end tramite API

Come inserire immagini nel sito: non basta mandarle a Claude. Devi prima hostarle (es. su Imgur), copiare il link dell'immagine e passare quel link a Claude

Testare la responsiveness del sito restringendo la finestra del browser

Creare un account su GitHub come "social media dei programmatori" per salvare e gestire il codice

Creare un repository su GitHub: cliccare New, dare un nome senza spazi né caratteri speciali (usare underscore), scegliere visibilità pubblica o privata

Caricare i file su GitHub con drag and drop tramite "Upload an existing file", poi fare Commit Changes

Usare GitHub per collegare il codice a un servizio di hosting e mettere il sito online (funziona anche con repo privati)

Approccio reale al lavoro: usare un website builder (Squarespace, WordPress) per la struttura, e il codice generato dall'AI solo per personalizzazioni specifiche (code block custom)

Non fare tutto in un singolo prompt: dividere il lavoro in chat separate (una per il copy, una per il branding, una per la struttura, ecc.) per dare a Claude il contesto giusto

Gestione errori: copiare l'errore dalla console e incollarlo direttamente a Claude, senza cercare di spiegarlo tu — l'AI capisce subito dove intervenire

Usare Ctrl+S / Cmd+S per salvare le modifiche ogni volta che si tocca un file

Sfruttare la memoria della chat di Claude: tornare nella stessa conversazione per chiedere modifiche successive al sito
