## 4 modi per dare contesto (framework completo, fonte primaria)

| Modo | Descrizione | Quando |
|---|---|---|
| 1. Allegare tutti i file | Semplice, funziona, ma spreca contesto | — |
| 2. Allegare solo i file rilevanti | "Più intelligente" — selezione mirata per task | Task singolo |
| 3. Cowork (cartella condivisa) | Accesso diretto a cartella locale, multi-step, context window "praticamente illimitato" ma consuma disponibilità giornaliera | Task pesanti, presentazioni, molti file |
| 4. Projects | Chat raggruppate + memory automatica + instructions fisse + files | Lavori continuativi (giorni/settimane) su un cliente |

**Da evitare**: link esterni come contesto (eccezione: Perplexity, unica AI con cui l'autore si trova bene a condividerli direttamente).

## Struttura cartelle personale dell'autore (osservata su schermo, confermata anche in lezione 6)

Cartella principale "Claude" > assets (immagini/brand guidelines), B2B Client Work (sottocartella per cliente), Business Planning, Claude Speedrun (progetto corso), Productivity (task/pianificazione settimanale). Regola: con Cowork condividere SOLO la sottocartella del cliente rilevante, mai l'intera cartella Claude — per non sprecare token/context window.
