## Framework "3 tipi di contesto" (fonte primaria)

### 1. Obiettivo — gerarchia a 4 livelli
| Livello | Orizzonte | Esempio |
|---|---|---|
| Vision | direzione intera dell'azienda | missione, cultura, dove vuoi andare |
| Obiettivo | lungo termine (~5 anni) | 100K€/mese |
| Target | medio termine (fine anno) | 20K€/mese |
| Task | brevissimo termine (questo mese) | chiudere 2 clienti |

Ogni livello si inserisce dentro quello superiore (task→target→obiettivo→vision).

### 2. Road block (ostacoli)
- Difetti personali noti
- Limitazioni di risorse (budget, tempo)

### 3. Contesto tecnico
Dipende dal task: design→JSON brand guidelines; copy→avatar target.
