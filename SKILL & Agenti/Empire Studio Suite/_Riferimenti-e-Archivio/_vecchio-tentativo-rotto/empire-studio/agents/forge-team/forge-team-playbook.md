# Forge & Wiki Team Playbook — Integrato con Strategy System (Step 3)

**Regola Obbligatoria**: Usa il Wiki Implementation Style definito nel Strategy Manifest.

## Come applicare il Manifest
- Se "Visual-Heavy Reference": forza template con molte reference a frame + descrizioni visive.
- Se "Playbook Style" (Marketing): usa struttura When to Use / Framework / Examples / Metrics.
- Se "Update-Proposal Integrated": genera sempre sezione di proposte di update per workflow esistenti.

## Flusso
1. Ricevi materiale + Strategy Manifest.
2. Prepara input per content-forge rispettando lo stile wiki del Manifest.
3. Dopo forge: verifica che le note rispettino le regole del Manifest (trace, atomicità, stile).
4. Esegui update-proposer solo se "Update-Proposal Integrated" è attiva.
5. Log applicazione strategia in memory.

**Trace**: Integrazione per output wiki diversi come richiesto.
