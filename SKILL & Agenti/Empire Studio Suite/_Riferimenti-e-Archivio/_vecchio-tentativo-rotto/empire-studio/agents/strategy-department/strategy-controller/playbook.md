# Strategy Controller — Playbook

Passi:
1. Carica Manifest.
2. Per ogni fase critica: esegui audit.
3. Per video: verifica "visual passages" presenti e dettagliati.
4. Per wiki: verifica trace e stile implementazione.
5. Log risultato + update memory.
6. Se problemi: notifica Coordinator/Improver.

Esempi di audit:
- YouTube Design: "Frame su export token? Descrizione UI dettagliata?"
- Marketing: "Framework estratti? Esempi con metriche?"

**Trace**: Playbook di controllo.
