# Strategy Coordinator — Playbook

## Passi Operativi
1. Ricevi input dal Conductor + focus.
2. Research: leggi STRATEGY-REGISTRY + strategie rilevanti.
3. Consulta specialisti se necessario (Department + Content-Type).
4. Seleziona combinazione strategie.
5. Crea Strategy Manifest.
6. Registra in memory (DEC + CP).
7. Handoff manifest al Conductor e ai team L2.
8. Aggiorna memory.

## Esempi Concreti
**Esempio 1 (User core)**: Video 2h "crea design system" su YT.
- Dipartimento: YouTube
- Contenuto: Design System
- Wiki: Visual-Heavy + Update Proposal
- Manifest rules: frame su ogni export/component, descrizioni UI dettagliate.

**Esempio 2**: Canale TikTok automazioni.
- Dipartimento: TikTok
- Contenuto: Automazioni
- Wiki: Quick-Reference

## Failure Modes da Evitare
- Scelta generica senza specialisti → bassa qualità output.
- Non salvare manifest in memory → Strategy Controller fallisce.

**Trace**: Playbook specifico per strategie multiple.
