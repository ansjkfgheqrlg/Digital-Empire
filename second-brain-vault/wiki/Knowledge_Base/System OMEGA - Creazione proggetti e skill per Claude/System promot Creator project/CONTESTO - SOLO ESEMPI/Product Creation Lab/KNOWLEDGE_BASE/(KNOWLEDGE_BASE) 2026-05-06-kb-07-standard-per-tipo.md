# 📋 COME UTILIZZARE QUESTO FILE
# ──────────────────────────────────────────────────────

Questo file contiene gli standard minimi per ogni tipo di prodotto info.

Usalo in tre momenti:
1. **Step 1.4** — verifica che l'outline rispetti gli standard prima di produrre
2. **Fase 2** — usa i parametri come target durante la creazione
3. **Step 3.1** — verifica che il prodotto finito rispetti gli standard

Se non rispetti anche solo uno standard obbligatorio → non procedere. Adatta l'outline prima.


# ──────────────────────────────────────────────────────
# 📄 PDF GRATUITO (Lead Magnet)
# ──────────────────────────────────────────────────────

**Prezzo**: €0 | **Tempo**: ~7h | **Beta**: NO

| Elemento | Standard Minimo |
|---|---|
| Lunghezza | 8-20 pagine |
| Framework | 1 con nome proprietario |
| Template/Checklist | Almeno 1 compilabile con esempio compilato |
| Design | Professionale (Canva, non Word base) |
| CTA | 1 CTA verso prodotto successivo (specifica) |
| Tempo lettura | 15-30 minuti |
| Output pratico | Almeno 1 azione immediata post-lettura |

**Struttura raccomandata** (10-15 pagine):
Cover → Il Problema → L'Errore Principale → Il Framework (3-5 step) → Template/Checklist → CTA

**Red flag**: >3 argomenti / nessun template / CTA generica / wall-of-text

| Elemento | Standard Minimo |
|---|---|
| Video | 3-5 video |
| Durata totale | 45-90 minuti |

# ──────────────────────────────────────────────────────
# 🔄 QUANDO SCEGLIERE OGNI FORMATO
# ──────────────────────────────────────────────────────

- **PDF gratuito**: lead magnet, test interesse, 1 framework + 1 template
- **Ebook**: topic da leggere (non video), entry-point basso rischio, target che legge
- **Mini-corso**: topic che si impara guardando, risultato in 1-2 sessioni, upsell a PDF
- **Corso completo**: trasformazione che richiede settimane, asset principale del catalogo
- **Percorso premium**: accompagnamento > informazione, accountability, feedback personale

**Regola di ridimensionamento**: Se l'outline ha meno contenuto degli standard minimi → riduci il formato e il prezzo. Non gonfiare il contenuto per giustificare un formato più alto.


# ──────────────────────────────────────────────────────
# ⚠️ EDGE CASE E GESTIONE ERRORI
# ──────────────────────────────────────────────────────

## Il prodotto è a metà tra due formati

**Situazione**: 6 video (70 min) — troppo per mini-corso, troppo poco per corso completo.
**Soluzione**: Opzione A — lancia come mini-corso a €47 ("intensivo e ultra-pratico"). Opzione B — aggiungi 2-3 lezioni per arrivare agli standard del corso completo a €97. Scegli in base a: hai materiale aggiuntivo di valore? Se sì → B. Se no → A.

## Il beta suggerisce che il prodotto vuole essere premium

**Situazione**: I beta tester a €197 chiedono live, community, feedback personalizzato.
**Soluzione**: Lancia il corso a €197 come previsto. Pianifica una versione Premium a €497+ per il ciclo successivo con live + community. Usa questo lancio come market test. Nota in Sezione H del Documento Handoff.

## Gli standard sembrano eccessivi per il tempo disponibile

**Soluzione**: Gli standard sono MINIMI. Se non hai tempo per rispettarli → riduci il formato. Un mini-corso con 2 template eccellenti è meglio di un "corso" con 5 template mediocri.
