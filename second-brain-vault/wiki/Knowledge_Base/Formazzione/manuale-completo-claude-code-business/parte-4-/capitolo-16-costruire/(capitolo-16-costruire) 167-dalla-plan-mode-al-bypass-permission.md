# 16.7 — Dalla Plan Mode al Bypass Permission
            
> Path: [[Map - Formazzione|Formazzione > manuale-completo-claude-code-business > parte-4- > capitolo-16-costruire]]

## Content

Una volta approvato il piano, l'autore fa il passaggio chiave: 
text 
TRANSIZIONE: 
 
Plan Mode (pianificazione) 
     ↓ 
[Piano approvato dall'utente] 
     ↓ 
Bypass Permission (esecuzione) 
     ↓ 
Claude Code costruisce in autonomia 
L'autore spiega la logica: "Una volta che il piano ha senso ed è fatto in maniera corretta, allora Claude Code può fare il 
cosiddetto one-shot." 
Il principio è: investire tempo nella pianificazione per poi lasciare che l'esecuzione sia completamente autonoma. Il 
piano di qualità è la precondizione per un'esecuzione autonoma di qualità.
