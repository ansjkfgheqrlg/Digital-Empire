# 16.11 — Gestione delle Aspettative
            
> Path: [[Map - Formazzione|Formazzione > manuale-completo-claude-code-business > parte-4- > capitolo-16-costruire]]

## Content

L'autore dedica un passaggio importante alla gestione delle aspettative, che è una lezione di valore inestimabile: 
"Ci aspettavamo che l'integrazione end-to-end funzionasse molto bene, perché siamo stati iper specifici. Abbiamo dato 
indicazioni per quanto riguardava come questa integrazione doveva andare, abbiamo dato API key, abbiamo dato dei 
collegamenti, abbiamo addressato un paio di step che ci ha chiesto. Quello che non abbiamo dato sono state le direttive 
di styling e design — che ovviamente, se volesse, uno andrebbe in serenità ad averle." 
REGOLA FONDAMENTALE: 
 
Specificità dell'input → Qualità dell'output 
 
SPECIFICO nel prompt → ACCURATO nell'output 
├── API keys fornite → ✅ Integrazione funzionante 
├── Screenshot di riferimento → ✅ Struttura replicata 
├── Schema database definito → ✅ Backend corretto 
└── Flusso autenticazione definito → ✅ Login funzionante 
 
VAGO nel prompt → APPROSSIMATIVO nell'output 
├── "Fai un design carino" → ⚠️ Design mediocre 
├── Nessuna guida di stile → ⚠️ Font/colori casuali 

--- PAGE 54 ---
└── Dark mode non richiesta → ⚠️ Dark mode non funzionante
