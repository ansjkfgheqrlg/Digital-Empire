# 6.1 — Definizione del Concetto

## Content

Un IDE (Integrated Development Environment), in italiano "Ambiente di Sviluppo Integrato", è un software che fornisce 
un'interfaccia visiva completa per lavorare su progetti. Un IDE tipicamente include: un esploratore di file (per navigare la 

--- PAGE 17 ---
struttura del progetto), un editor di testo (per modificare i file), un terminal integrato, e — nel nostro caso — 
l'integrazione con Claude Code.
