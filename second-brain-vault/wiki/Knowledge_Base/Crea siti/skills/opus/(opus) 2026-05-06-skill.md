# OPUS — Ultra-Premium Web Creation System
*Digital Empire | Standard $50.000 website*

---

## Cos'è OPUS

OPUS è il sistema **ultra-premium** di Digital Empire per la creazione di siti web.

**La differenza rispetto a `/site`:**
- `/site` → sito di qualità professionale, workflow standard
- `/opus` → sito di livello agenzia internazionale, 21 fasi, anti-AI by design

Ogni sito OPUS supera lo standard "$50.000 website": la differenza sta nelle 100 micro-decisioni su spacing, peso tipografico, timing delle animazioni, e capacità di resistere all'istinto di "riempire".

---

## Quando usare OPUS

**Usa `/opus` quando:**
- Stai creando una landing page per un lancio di prodotto (corso, coaching, membership)
- Il sito deve sembrare realizzato da un'agenzia di design di livello mondiale
- Hai bisogno del Polish Loop completo (7 pass anti-AI)
- Vuoi il sistema Silver-Mixed + Grain Texture obbligatorio
- Il progetto ha budget/importanza che giustifica il processo completo

**Usa `/site` quando:**
- Hai bisogno di qualcosa rapidamente
- Il sito è semplice (vetrina base, landing veloce)
- Non hai tempo per le 21 fasi complete

## 5 Elementi Signature OPUS

### 1. Silver-Mixed (obbligatorio su tutto)
Ogni colore — incluso brand primary — ha saturazione ridotta 20-35% + silver undertones.
```css
/* Esempio: brand blue silver-mixed */
--color-accent: hsl(210, 35%, 60%); /* NON hsl(210, 80%, 50%) */
```

### 2. Grain Texture (obbligatorio su ogni sfondo)
SVG feTurbulence — NON PNG importato.
```css
body::before {
  position: fixed;
  background-size: 180px;
  opacity: 0.045;
  mix-blend-mode: overlay;
}
```
Se la grana sembra pixel → riduci `background-size`. Non aumentare `baseFrequency`.

### 3. Lowercase Headings
H1, H2, H3 tutti in sentence case. Mai Title Case.
```
✅ "il metodo che ha cambiato tutto"
❌ "Il Metodo Che Ha Cambiato Tutto"
```

### 4. Bold Word System
1-3 parole font-weight 600 per frase. Skeleton test obbligatorio.
Le parole in grassetto da sole formano il messaggio?

### 5. Polish Loop 7 Pass
Anti-AI → Typography → Spacing → Color+Grain → States → Motion → Detail Sweep
Minimum 5 pass. Standard OPUS: tutti i 7.
