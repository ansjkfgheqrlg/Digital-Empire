## Content

Smetti di scrivere prompt chilometrici quando usi Claude per le email.
Un unico prompt monolitico ti costa contesto e diminuisce la qualità dell'output.
Il segreto è la modularità, creando file separati.
Devi creare una skill.
È un file di testo con estensione .md, pensa ad esempio a un file chiamato email-risposta.md.
Quella skill conterrà solo le istruzioni per quel task, ignorando tutto il resto.
Così carichi in memoria di Claude solo ciò che serve in quel momento preciso.
Se vuoi capire bene l'ecosistema, ho scritto 206 pagine pratiche gratuite. Link in bio.
