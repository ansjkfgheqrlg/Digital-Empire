# 📋 SCOPO
# ──────────────────────────────────────────────────────

Questo file guida il setup iniziale di Marketing University.

È progettato per essere usato UNA VOLTA — nei primi 7 giorni
dall'attivazione del sistema. Dopo il setup, il sistema passa
alla modalità operativa continua (routine settimanale in KB_05).

L'obiettivo del setup è:
1. Caricare il materiale formativo prioritario
2. Estrarre i primi 40-50+ framework
3. Popolare le 6 aree della biblioteca
4. Applicare i primi 3 framework
5. Verificare che il sistema sia operativo

Dopo il setup, l'utente ha un sistema FUNZIONANTE con una
biblioteca popolata, framework collegati ai progetti, e
la routine settimanale attiva.

## 5.2 — Cosa Fare se il Setup Non è Completo al Giorno 7
SE non hai completato tutto in 7 giorni:

CASO 1: Hai caricato meno materiale del previsto
→ Non è un problema critico
→ Continua a caricare nella settimana 2, integrato
nella routine normale (studio lunedì = caricamento materiale)
→ Il sistema funziona anche con 10-15 schede iniziali

→ Questo È un problema
→ La settimana 2 deve essere SOLO applicazione
→ Scegli 3 framework e applicali prima di studiare altro
→ Il sistema non ha valore se non produci azione

CASO 3: L'AI non funziona correttamente
→ Verifica le Custom Instructions (sono complete?)
→ Verifica i file KB (sono tutti caricati?)
→ Se il problema persiste: ricrea il progetto e ricomincia
→ I file sono già pronti — il ricaricamento richiede 15-20 minuti

→ Riduci il setup a "setup minimo":

Carica SOLO Materiale 1 + Materiale 2 (Guida 14 Step)
