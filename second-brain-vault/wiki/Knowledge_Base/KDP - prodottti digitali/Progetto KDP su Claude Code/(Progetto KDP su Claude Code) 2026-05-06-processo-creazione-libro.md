# PROCESSO creazione LIBRO
            
> Path: [[Map - Kdp_-_Prodottti_Digitali|KDP - prodottti digitali > Progetto KDP su Claude Code]]

## Content

### REGOLA FONDAMENTALE
 TUTTO deve essere scritto SEMPRE e SOLO in Markdown.
 Mai in DOC. Mai in JSON. Mai in blocchi di codice.
 Il testo deve essere pulito, leggibile, formattato esclusivamente in Markdown.

## FASE 0 — INPUT STRATEGICO
 L'utente fornisce a Claude la strategia completa del libro (argomento, target, struttura, tono, obiettivo)
 L'utente dà il VIA
 ⛔ Claude NON attiva nessuna skill. Nessuna. Zero.

## FASE 1 — SCRITTURA COMPLETA DEL LIBRO. Il libro, i capitoli NON devono essere ripetitivi stile del libro umano, sincero. IL LIBRO DEVE DARE DEL VERO VALORE. 
 Claude procede con la scrittura integrale del libro, capitolo per capitolo
 Ogni capitolo viene scritto in Markdown puro
 Claude scrive tutto il contenuto, dall'introduzione alla conclusione
 Al termine, Claude fornisce il libro completo assemblato
 ⛔ Claude NON attiva la skill Book Optimizer in questa fase.

## FASE 2 — ATTIVAZIONE SKILL BOOK OPTIMIZER
 Una volta che il libro completo è stato consegnato:

- # Step 2.1 — Preparazione
  L'utente dice: "Attiva la skill Book Optimizer"
  Claude conferma l'attivazione e chiede: "Posso procedere con la Fase 1?"

- # Step 2.2 — Fase 1 della Skill
  L'utente dice: "Via Fase 1"
  Claude esegue la Fase 1 come da skill (analisi e ottimizzazione strutturale)
  Claude si ferma e aspetta.

- # Step 2.3 — Fase 2 della Skill
  L'utente dice: "Via Fase 2"
  Claude esegue la Fase 2: AMPLIAMENTO ed ESTENSIONE
  Ogni singolo capitolo viene espanso significativamente
  Più contenuto, più profondità, più pagine
  L'obiettivo è aumentare in modo consistente la lunghezza e la ricchezza del libro
  Claude si ferma e aspetta.

- # Step 2.4 — Fase 3 della Skill
  L'utente dice: "Via Fase 3"
  Claude esegue la Fase 3 come da skill (rifinitura finale)
  Il libro è ora completo e ottimizzato.

- ## FASE 3 — PROMPT PER IMMAGINI
  L'utente chiede i prompt per le immagini
  Claude fornisce una lista completa di tutti i prompt pronti per generazione immagini:
    🎨 Prompt copertina
    🖼️ Prompt per ogni immagine interna presente nel libro.
    Tutti i prompt sono ottimizzati per Leonardo AI / strumenti pro.
    Pronti all'uso, dettagliati e perfetti.

- ## FASE 4 — DATI PER AMAZON KDP
  Claude fornisce tutti i dati necessari per la pubblicazione:

   📌 Titolo (principale + sottotitolo)
   📝 Descrizione ottimizzata
   🏷️ Tag / Parole chiave
   🔍 SEO (ottimizzazione ricerca Amazon)
   🌍 GEO (categorie e mercati target)
   📂 Categorie BISAC
    Tutto pronto per l'inserimento diretto su KDP.

- ## FASE 5 — MARKETING (Chat separata)
  Caroselli promozionali
  Contenuti social
  Strategie di lancio
  ➡️ Da gestire in una conversazione dedicata.
  📋 RIEPILOGO ORDINE DI ESECUZIONE.

- ## Step	Azione	Chi avvia
  0	Input strategia + VIA	Utente
  1	Scrittura completa libro (Markdown)	Claude
  2	Attivazione Book Optimizer	Utente
  2.1	Fase 1 skill	Utente dice "Via"
  2.2	Fase 2 skill (ampliamento massivo)	Utente dice "Via"
  2.3	Fase 3 skill (rifinitura)	Utente dice "Via"
  3	Prompt immagini (copertina + interne)	Utente chiede
  4	Dati Amazon KDP completi	Utente chiede
  5	Marketing (chat separata)	Utente
  Questo è il sistema. Questo è l'ordine. Non si cambia. Non si salta. Non si anticipa nulla.

## IL LIBRO CARICALO SUlla CARTELLA CONTESTO E ANCHE SULLA CARTELLA NEW LIBRO.
 Ascolta,voglio che metti alcuni file dentro la cartella new libro. Devi mettere dentro la cartella new libro il libro completo, che devi mettere anche sul contesto, cioè devi mettere il libro completo ogni volta, ogni volta, devi metterlo sulla cartella new libro e sulla cartella contesto/Libri. Ovviamente, in questo caso stai attento che non ci sia già il libro della cartella contesto. Ok? Quindi io intendo il libro ampliato, finito e completo al 100%. Devi metterlo nella cartella new libro e nella cartella contesto. Poi, il file con tutti i prompt, devi metterlo nella cartella new libro, il file con tutti i dettagli di Amazon KDP, devi metterlo nella cartella new libro.

## DENTRO LA CARTELLA CONTESTO
 ci sono due cartelle:
 - LIbri: qui dentro devi sempre caricare il libro nuovo e non devi toccare i libri vecchi, tutti i libri devono rimanere li.
 - Strategie: qui dentro devi sempre caricare la strategia nuova e non devi toccare le vecchie strategie, tutte le strategie devono sempre rimanere li
