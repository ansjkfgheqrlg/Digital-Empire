## Tool Insegnato: Meta Ads Library Stack

```
1. Vai su library.meta.com (o facebook.com/ads/library)
2. Imposta Location (Italy o paese target)
3. Filtra: Platform → Instagram
4. Filtra: Active Status → Active ads (o Inactive per vedere cosa ha funzionato)
5. Filtra: Media Type → Videos (quelli che convertono)
6. Filtra: Language → Italian
7. Cerca keyword: inserisci fino a 50 parole del tuo settore
8. Per competitor specifico: cerca per advertiser name
9. Clicca "See ad details" → EU Transparency: eta/genere/esclusi/EU Reach
10. Salva con "Save Search" per monitoraggio mensile
```
