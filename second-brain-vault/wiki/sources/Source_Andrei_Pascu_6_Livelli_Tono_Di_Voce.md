## I 6 Livelli

| Livello | Criteri |
|---|---|
| 1. Insicuro | No eye contact, braccia conserte |
| 2. Normale | Eye contact, parla veloce |
| 3. Decente | + parla lento, mette pause / non proietta, è fermo |
| 4. Persuasivo | + alza e abbassa il tono / non proietta, è fermo |
| 5. Quasi perfetto | + proietta la voce / non gesticola, troppo "da film" |
| 6. Perfetto | + gesticola, confident |
