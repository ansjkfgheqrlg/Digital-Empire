## Tool Insegnato: Google Docs Operating System per Copywriter

```
1. File → Impostazione pagina → Senza pagine (+ imposta come default)
2. Crea SEMPRE il documento da dentro la cartella Drive giusta, mai da Google Docs diretto
3. Cartella cliente → sottocartelle "visibile al cliente" / "NON visibile" (colorata rosso)
4. Seleziona testo → Stili → Intestazione (mai bold+size manuale) → genera outline navigabile
5. Per cambiare stile ovunque: formatta un'istanza → Stili → "Aggiorna [stile] perché corrisponda"
6. Note operative (non-copy) → heading dedicato con colore testo giallo
7. Inserisci → Menu a discesa → crea stati sezione (Da iniziare/In corso/In revisione/Pronto)
8. Vai a inizio sezione → Inserisci → Segnalibro → copia link → incolla come link cliccabile
9. Strumenti → Conteggio parole → spunta "visualizza durante la digitazione"
10. Seleziona un testo per vedere conteggio parole/caratteri della sola selezione
```
