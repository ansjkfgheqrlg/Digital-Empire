## Overview

The Market Technical SEO Subagent is a technical marketing analysis specialist that evaluates technical foundations impacting marketing effectiveness: SEO infrastructure, site performance, tracking setup, and content architecture.

## Purpose

This agent performs technical audits by:
- Analyzing technical SEO elements (title tags, meta descriptions, H1 hierarchy)
- Evaluating crawlability and indexability
- Assessing site performance and mobile readiness
- Analyzing content architecture and information hierarchy
- Checking tracking and analytics implementation
- Evaluating schema/structured data markup
- Assessing content quality and E-E-A-T signals

## Key Components

### Technical SEO Framework
- **Page Structure** (0-10): Title tags, meta descriptions, heading hierarchy, alt text, URLs
- **Crawlability & Indexability** (0-10): robots.txt, sitemap, noindex tags, internal linking
- **Site Performance** (0-10): Page size, render-blocking resources, lazy loading, compression
- **Mobile Readiness** (0-10): Viewport meta tag, responsive design, touch-friendly elements

### Content Architecture Analysis
- Navigation structure and logical hierarchy
- Blog/resource organization
- Content freshness and depth assessment
- Internal linking strategy effectiveness

### Analytics & Tracking Assessment
- Google Analytics / GA4 presence
- Google Tag Manager implementation
- Pixel tracking (Facebook, LinkedIn, etc.)
- Session recording tools
- Cookie consent mechanisms
- UTM parameter usage

### Schema & Structured Data
- Organization schema
- Website schema with SearchAction
- Product/Service schema
- FAQ, Review, Article schemas
- Breadcrumb schema

## How It Applies to Digital Empire

The Technical SEO agent identifies:
- **CRO/Copy/Funnel Service**: Technical barriers to organic traffic and conversion
- **AI Implementation Service**: Analytics and data tracking optimization opportunities
- SEO improvement opportunities and quick technical wins

## Output Format

Generates comprehensive technical analysis with:
- Overall SEO score (0-10)
- Technical dimensions breakdown with scores
- Content architecture assessment
- Tracking and analytics gaps
- Schema implementation audit
- Specific technical recommendations prioritized by impact
- Quick wins and long-term improvements
