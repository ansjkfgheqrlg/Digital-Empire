## Overview

The Market Copy Generator is a specialized skill for generating optimized, high-converting copy for any webpage, landing page, or marketing material.

## Purpose

This tool automates copywriting by:
- Analyzing existing copy and identifying improvement opportunities
- Generating before/after copy examples
- Creating variations optimized for different audiences
- Improving headlines for clarity and persuasion
- Strengthening value propositions with specific proof
- Crafting benefit-focused body copy
- Optimizing call-to-action text

## Key Components

### Copy Analysis Framework
- **Headline Analysis**: Clarity, specificity, and persuasion scoring
- **Value Proposition**: Differentiation and proof assessment
- **Body Copy**: Benefits vs features analysis
- **CTA Effectiveness**: Clarity and urgency evaluation
- **Overall Persuasion**: Emotional triggers and objection handling

### Generation Capabilities
- Copy variation generation for A/B testing
- Audience-specific copy adaptation
- Industry-specific language and terminology
- Benefit-focused rewriting of feature-heavy copy
- Social proof integration suggestions
- Urgency and scarcity element recommendations

## How It Applies to Digital Empire

The Copy Generator supports:
- **CRO/Copy/Funnel Service**: Primary deliverable for copy optimization projects
- **Client Proposals**: Copy improvements as a service offering
- **Landing Page Optimization**: High-impact copy enhancements

## Output Format

Generates copy recommendations with:
- Original vs optimized copy comparison
- Explanation of improvements and rationale
- Multiple variations for A/B testing
- Audience-specific adaptations
- Implementation guidance
- Expected impact on conversion metrics
