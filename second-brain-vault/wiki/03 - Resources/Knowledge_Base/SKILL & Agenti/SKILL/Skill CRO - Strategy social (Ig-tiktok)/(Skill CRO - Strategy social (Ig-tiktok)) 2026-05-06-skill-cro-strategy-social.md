## Principio fondamentale

> **"I social non sono il palcoscenico. Sono il filtro."**

Un video con 500 views che genera 2 call qualificate vale più di uno con 500k views e 0 call. Ogni contenuto filtra: respinge chi non è in target, attrae chi ha il problema esatto che risolvi.

**Implicazioni:**
- Non inseguire trend scollegati dalla CRO
- Non annacquare il messaggio per "piacere a tutti"
- Ogni contenuto ha una CTA che porta al lead magnet o alla call
- Misura call booked, non follower

## Contesto Agency

- **Agency:** Digital Empire (CRO agency productizzata)
- **USP:** Conversion Sprint (sprint + implementazione + test + success fee + handover)
- **ICP:** Aziende con traffico esistente e offerta validata, basse conversioni
- **Copy framework:** APP-SOC
- **TikTok** = Discovery (TOFU) | **Instagram** = Validazione (MOFU/BOFU)
- **Contenuti:** sempre col volto del founder

## KPI e Metriche

**TikTok:** Hook Rate ≥30% | Watch Time ≥50% | Saves ≥2% | Keyword Comments ≥0.5% | Profile Visits ≥3%

**Instagram:** Reel Reach ≥2x follower | Carousel Saves ≥3% reach | DM ≥5/sett | Link Click ≥1% | Story Views ≥15% follower

**Funnel:** Lead ≥10/sett | Call ≥2-3/sett | Close Rate ≥30%

## Hook Velocity

Quando hook rate <30%, testa 5 hook diversi sullo stesso tema:
1. ❓ Domanda Diretta
2. 📊 Statistica Shock
3. 🔥 Provocazione
4. 🎬 POV/Storytelling
5. 🔄 Controintuitivo

Pubblica 1 hook, misura dopo 24h. Se <30%, pubblica il successivo. Winner ≥30% → annota nel Playbook.

Esegui `scripts/hook_velocity.py` per generare 5 hook su un tema specifico.

## TikTok

### Hook Rate
- **Target:** ≥30%
- **Critico:** <15%
- **Sotto target:** Cambia i primi 3 sec. Apri con dato/provocazione/POV. Testa pattern diversi. Attiva Hook Velocity.
- **Critico:** STOP formato. Analizza i 3 video con hook rate più alto. Replica quel pattern. Il TEMA potrebbe non interessare.

### Watch Time Medio
- **Target:** ≥50% del video
- **Critico:** <25%
- **Sotto target:** Video troppo lungo — taglia a <45 sec (azione), <90 sec (educativo). Pattern interrupt a metà. Rimuovi sezioni con retention drop.
- **Critico:** Mismatch hook-contenuto. Prometti X, parli di Y. Entro 10 sec mantieni la promessa dell'hook.

### Salvataggi
- **Target:** ≥2% delle views
- **Critico:** <0.5%
- **Sotto target:** Non abbastanza "utile". Più valore pratico — tip implementabili, framework, checklist. Dì "salva questo video". Più Quick Win.

@dataclass
class PillarMixReport:
    """Report del mix pilastri."""
    period_label: str
    total_contents: int
    counts: dict
    targets: dict

    def display(self) -> str:
        lines = [
            f"\n{'━' * 55}",
            f"  📊 PILLAR MIX REPORT — {self.period_label}",
            f"  Contenuti totali: {self.total_contents}",
            f"{'━' * 55}",
            f"  {'Pilastro':<22} {'Actual':>7} {'Target':>7} {'Delta':>7}  Status",
            f"  {'─' * 52}",
        ]
        for pillar in Pillar:
            cfg = PILLAR_CONFIG[pillar]
            count = self.counts.get(pillar, 0)
            actual_pct = (count / self.total_contents * 100) if self.total_contents > 0 else 0
            target_pct = self.targets.get(pillar, cfg["target_mix_pct"])
            delta = actual_pct - target_pct
            status = "✅" if abs(delta) <= 5 else ("⚠️ TROPPO" if delta > 5 else "⚠️ POCO")
            lines.append(
                f"  {cfg['emoji']} {cfg['label']:<18} "
                f"{actual_pct:>5.1f}% {target_pct:>5.0f}% "
                f"{delta:>+5.1f}%  {status}"
            )
        lines.append(f"{'━' * 55}\n")
        return "\n".join(lines)


class PillarMixAnalyzer:
    """Analizza il mix di pilastri e suggerisce correzioni."""

    def __init__(self, custom_targets: Optional[dict] = None):
        self.targets = {}
        for pillar in Pillar:
            if custom_targets and pillar in custom_targets:
                self.targets[pillar] = custom_targets[pillar]
            else:
                self.targets[pillar] = PILLAR_CONFIG[pillar]["target_mix_pct"]

    def analyze(self, contents: list, period_label: str = "Settimana corrente") -> PillarMixReport:
        """Analizza lista di ContentIdea o di stringhe pillar."""
        counts = {p: 0 for p in Pillar}
        for c in contents:
            if isinstance(c, ContentIdea):
                counts[c.pillar] += 1
            elif isinstance(c, Pillar):
                counts[c] += 1
            elif isinstance(c, str):
                try:
                    counts[Pillar(c)] += 1
                except ValueError:
                    pass
        return PillarMixReport(
            period_label=period_label,
            total_contents=len(contents),
            counts=counts,
            targets=self.targets,
        )

    def analyze_from_counts(
        self, td: int, rs: int, qw: int, op: int, tr: int,
        period_label: str = "Settimana corrente",
    ) -> PillarMixReport:
        """Analizza da conteggi diretti."""
        counts = {
            Pillar.TEARDOWN: td, Pillar.RISULTATI: rs,
            Pillar.QUICK_WIN: qw, Pillar.OPINIONE_FORTE: op,
            Pillar.TREND_HOOK: tr,
        }
        total = td + rs + qw + op + tr
        return PillarMixReport(
            period_label=period_label, total_contents=total,
            counts=counts, targets=self.targets,
        )

    def suggest_next_pillar(self, contents: list) -> Pillar:
        """Suggerisce quale pilastro pubblicare per avvicinarsi al target."""
        if not contents:
            return Pillar.TEARDOWN

        total = len(contents)
        counts = {p: 0 for p in Pillar}
        for c in contents:
            if isinstance(c, ContentIdea):
                counts[c.pillar] += 1
            elif isinstance(c, Pillar):
                counts[c] += 1

        max_deficit = -999.0
        best = Pillar.TEARDOWN
        for pillar in Pillar:
            actual_pct = (counts[pillar] / total) * 100
            target_pct = self.targets[pillar]
            deficit = target_pct - actual_pct
            if deficit > max_deficit:
                max_deficit = deficit
                best = pillar
        return best

    def get_weekly_plan_pillars(self, n_contents: int = 7) -> list:
        """Genera sequenza pilastri per n contenuti rispettando il mix."""
        plan = []
        for pillar in Pillar:
            count = round(n_contents * self.targets[pillar] / 100)
            plan.extend([pillar] * count)
        while len(plan) < n_contents:
            plan.append(Pillar.TEARDOWN)
        while len(plan) > n_contents:
            plan.pop()
        random.shuffle(plan)
        return plan

class ContentIdeaPicker:
    """Seleziona idee dal database in base a criteri."""

    def __init__(self, ideas_db: list = None):
        self.db = ideas_db or CONTENT_IDEAS_DB

    def by_pillar(self, pillar: Pillar) -> list:
        return [i for i in self.db if i.pillar == pillar]

    def by_video_type(self, vtype: VideoType) -> list:
        return [i for i in self.db if i.video_type == vtype]

    def by_platform(self, platform: Platform) -> list:
        return [i for i in self.db if platform in i.platforms]

    def random_idea(
        self, pillar: Optional[Pillar] = None,
        video_type: Optional[VideoType] = None,
        platform: Optional[Platform] = None,
    ) -> Optional[ContentIdea]:
        pool = list(self.db)
        if pillar:
            pool = [i for i in pool if i.pillar == pillar]
        if video_type:
            pool = [i for i in pool if i.video_type == video_type]
        if platform:
            pool = [i for i in pool if platform in i.platforms]
        return random.choice(pool) if pool else None

    def weekly_selection(self, n: int = 7) -> list:
        """Selezione settimanale bilanciata secondo il mix target."""
        analyzer = PillarMixAnalyzer()
        pillar_sequence = analyzer.get_weekly_plan_pillars(n)
        selected = []
        used_ids = set()

        for pillar in pillar_sequence:
            candidates = [i for i in self.db if i.pillar == pillar and i.id not in used_ids]
            if candidates:
                choice = random.choice(candidates)
                selected.append(choice)
                used_ids.add(choice.id)
            else:
                remaining = [i for i in self.db if i.id not in used_ids]
                if remaining:
                    choice = random.choice(remaining)
                    selected.append(choice)
                    used_ids.add(choice.id)
        return selected

    def list_by_pillar(self) -> str:
        lines = []
        for pillar in Pillar:
            cfg = PILLAR_CONFIG[pillar]
            ideas = self.by_pillar(pillar)
            lines.append(f"\n{'━' * 55}")
            lines.append(f"  {cfg['emoji']} {cfg['label']} — {len(ideas)} idee")
            lines.append(f"{'━' * 55}")
            for idea in ideas:
                vcfg = VIDEO_TYPE_CONFIG[idea.video_type]
                hook_display = idea.hook[:70] + "..." if len(idea.hook) > 70 else idea.hook
                lines.append(f"  #{idea.id} {vcfg['emoji']} {idea.title}")
                lines.append(f"     \"{hook_display}\"")
        return "\n".join(lines)

@dataclass
class ProductionStatus:
    """Stato di produzione settimanale con barre progresso."""
    week_label: str
    tiktok_target: int = 6
    ig_reel_target: int = 3
    ig_carousel_target: int = 2
    ig_stories_target: int = 5  # sessioni
    tiktok_done: int = 0
    ig_reel_done: int = 0
    ig_carousel_done: int = 0
    ig_stories_done: int = 0

    def completion_pct(self) -> float:
        total_target = self.tiktok_target + self.ig_reel_target + self.ig_carousel_target + self.ig_stories_target
        total_done = self.tiktok_done + self.ig_reel_done + self.ig_carousel_done + self.ig_stories_done
        return (total_done / total_target * 100) if total_target > 0 else 0

    def display(self) -> str:
        def bar(done, target):
            pct = (done / target * 100) if target > 0 else 0
            filled = int(pct / 10)
            return "█" * filled + "░" * (10 - filled) + f" {done}/{target}"

        status = "✅" if self.completion_pct() >= 80 else "⚠️"
        lines = [
            f"\n{'━' * 50}",
            f"  📊 PRODUCTION TRACKER — {self.week_label}",
            f"  Completamento: {self.completion_pct():.0f}% {status}",
            f"{'━' * 50}",
            f"  TikTok Video:  {bar(self.tiktok_done, self.tiktok_target)}",
            f"  IG Reel:       {bar(self.ig_reel_done, self.ig_reel_target)}",
            f"  IG Carosello:  {bar(self.ig_carousel_done, self.ig_carousel_target)}",
            f"  IG Stories:    {bar(self.ig_stories_done, self.ig_stories_target)}",
            f"{'━' * 50}",
        ]
        return "\n".join(lines)

@dataclass
class PublishingWindow:
    """Finestra oraria di pubblicazione per una piattaforma."""
    platform: Platform
    windows: list  # [(time_start, time_end), ...]
    best_days: list  # [DayOfWeek, ...]
    rationale: str

    def get_random_time(self) -> time:
        window = random.choice(self.windows)
        start_min = window[0].hour * 60 + window[0].minute
        end_min = window[1].hour * 60 + window[1].minute
        rand_min = random.randint(start_min, end_min)
        return time(rand_min // 60, rand_min % 60)

    def get_best_time(self, day: DayOfWeek) -> time:
        if day in (DayOfWeek.SABATO, DayOfWeek.DOMENICA):
            for w in self.windows:
                if w[0].hour >= 9:
                    return time(w[0].hour, 30)
            return self.windows[0][0]
        return time(self.windows[0][0].hour, 15)

    def display(self) -> str:

class ChecklistScorer:
    """Calcola punteggio CRO Checklist 25 punti."""

    THRESHOLDS = {
        "rosso": {"range": (0, 10), "emoji": "🔴",
            "message": "Il tuo funnel brucia soldi. Ogni €1 in ads lavora al 40%. Intervento urgente."},
        "giallo": {"range": (11, 18), "emoji": "🟡",
            "message": "Ci sei quasi. Pochi fix strategici possono sbloccare 20-40% in più."},
        "verde": {"range": (19, 25), "emoji": "🟢",
            "message": "Ottimo. Pronto per scalare. Servono test A/B per fine-tuning."},
    }

    def __init__(self, checklist=None):
        self.checklist = checklist or CRO_CHECKLIST_25

    def score(self, answers: dict) -> ChecklistScore:
        """answers: {numero_punto: True/False}"""
        total = 0
        max_points = 0
        category_scores = {}
        failed = []
        high_impact = []

        for category in self.checklist:
            cat_score = 0
            cat_max = len(category.items)
            for item in category.items:
                max_points += 1
                passed = answers.get(item.number, False)
                if passed:
                    total += 1
                    cat_score += 1
                else:
                    failed.append(item)
                    if item.impact_level == "alto":
                        high_impact.append(item)
            category_scores[category.name] = (cat_score, cat_max)

        score_pct = (total / max_points * 100) if max_points > 0 else 0
        level = "rosso"
        for lname, cfg in self.THRESHOLDS.items():
            low, high = cfg["range"]
            if low <= total <= high:
                level = lname
                break
        lcfg = self.THRESHOLDS[level]

        return ChecklistScore(
            total_points=total, max_points=max_points, score_pct=score_pct,
            level=level, level_emoji=lcfg["emoji"], message=lcfg["message"],
            category_scores=category_scores, failed_items=failed,
            high_impact_fails=high_impact,
        )

    def score_from_string(self, s: str) -> ChecklistScore:
        """Score da stringa '1,1,0,1,...' (25 valori)."""
        values = [v.strip() for v in s.split(",")]
        answers = {}
        for i, v in enumerate(values[:25], 1):
            answers[i] = v in ("1", "true", "True", "s", "si", "sì", "y", "yes")
        return self.score(answers)

    def generate_priority_fixes(self, result: ChecklistScore, max_fixes: int = 5) -> list:
        """Lista prioritizzata di fix."""
        order = {"alto": 0, "medio": 1, "basso": 2}
        sorted_fails = sorted(result.failed_items, key=lambda x: order.get(x.impact_level, 3))
        return [
            {"priority": i + 1, "point": item.number, "category": item.category,
             "question": item.question, "impact": item.impact_level, "fix": item.quick_fix}
            for i, item in enumerate(sorted_fails[:max_fixes])
        ]

        for lm in self.db:
            if lm.is_primary and lm.is_active:
                return lm
        return None

    def get_by_id(self, lm_id: int) -> Optional[LeadMagnet]:
        for lm in self.db:
            if lm.id == lm_id:
                return lm
        return None

        kw = keyword.upper()
        for lm in self.db:
            if lm.manychat_keyword.upper() == kw:
                return lm
        return None

        primary = self.get_primary()
        if primary:
            return primary.recommended_cta

            and lm.id != (primary.id if primary else -1)

class WeeklyCalendar:
    """Calendario settimanale con gestione slot."""

    def __init__(self, template=None, week_start_date=None):
        self.template = template or WEEKLY_TEMPLATE
        self.week_start = week_start_date or self._next_monday()
        self.slots: list[ContentSlot] = []
        self._generate()

    @staticmethod
    def _next_monday() -> date:
        today = date.today()
        days = (7 - today.weekday()) % 7
        if days == 0:
            days = 7
        return today + timedelta(days=days)

    def _generate(self):
        self.slots = []
        for day_cfg in self.template:
            day = day_cfg["day"]
            for s in day_cfg["slots"]:
                slot = ContentSlot(
                    day=day, platform=s["platform"],
                    pillar=s.get("pillar"), video_type=s.get("video_type"),
                    title_hint=s["title_hint"], duration_hint=s["duration_hint"],
                    is_repurposed=s.get("is_repurposed", False),
                    repurposed_from=s.get("repurposed_from", ""),
                )
                self.slots.append(slot)

    def get_day_slots(self, day: DayOfWeek) -> list:
        return [s for s in self.slots if s.day == day]

    def get_platform_slots(self, platform: Platform) -> list:
        return [s for s in self.slots if s.platform == platform]

    def count_by_platform(self) -> dict:
        counts = {}
        for s in self.slots:
            counts[s.platform] = counts.get(s.platform, 0) + 1
        return counts

    def count_by_pillar(self) -> dict:
        counts = {p: 0 for p in Pillar}
        for s in self.slots:
            if s.pillar:
                counts[s.pillar] += 1
        return counts

    def update_slot_status(self, day: DayOfWeek, platform: Platform, new_status: str) -> bool:
        for s in self.slots:
            if s.day == day and s.platform == platform:
                s.status = new_status
                return True
        return False

    def assign_content(self, day: DayOfWeek, platform: Platform,
                       content_id: int = None, title: str = "") -> bool:
        for s in self.slots:
            if s.day == day and s.platform == platform:
                if content_id:
                    s.content_id = content_id
                if title:
                    s.title_hint = title
                return True
        return False

    def export_json(self) -> str:
        return json.dumps({
            "week_start": self.week_start.isoformat(),
            "slots": [s.to_dict() for s in self.slots],
        }, indent=2, ensure_ascii=False)

    def display(self) -> str:
        lines = [
            f"\n{'═' * 75}",
            f"  📅 CALENDARIO — Settimana del {self.week_start.strftime('%d/%m/%Y')}",
            f"{'═' * 75}",
        ]
        for day in DayOfWeek:
            day_slots = self.get_day_slots(day)
            if not day_slots:
                continue
            day_date = self.week_start + timedelta(days=day.value)
            lines.append(f"\n  ┌{'─' * 71}┐")
            lines.append(f"  │ {DAY_LABELS[day].upper():<10} {day_date.strftime('%d/%m')}{'':>55}│")
            lines.append(f"  ├{'─' * 71}┤")
            for slot in day_slots:
                compact = slot.display_compact()
                lines.append(f"  │{compact[2:]:<71}│")
            lines.append(f"  └{'─' * 71}┘")

        # Summary
        pc = self.count_by_platform()
        lines.append(f"\n  📊 Totale:")
        plat_names = {
            Platform.TIKTOK: "TikTok", Platform.IG_REEL: "IG Reel",
            Platform.IG_CAROUSEL: "IG Carosello", Platform.IG_STORIES: "Stories",
        }
        for p, c in pc.items():
            lines.append(f"    {plat_names.get(p, p.value)}: {c}")
        lines.append(f"{'═' * 75}")
        return "\n".join(lines)

class RepurposingEngine:
    """Valuta contenuti e suggerisce repurposing."""

    def __init__(self, rules=None):
        self.rules = rules or REPURPOSE_RULES

    def evaluate(self, platform: Platform, pillar: Pillar,
                 video_type: VideoType, views_24h: int, hours_since: int) -> list:
        applicable = []
        for rule in self.rules:
            if rule.source_platform != platform:
                continue
            if views_24h < rule.min_views_24h:
                continue
            if rule.pillar_filter and pillar not in rule.pillar_filter:
                continue
            if rule.video_type_filter and video_type not in rule.video_type_filter:
                continue
            if hours_since < rule.wait_hours:
                continue
            applicable.append(rule)
        return applicable

    def suggest(self, platform: Platform, pillar: Pillar,
                video_type: VideoType, views_24h: int, hours_since: int) -> str:
        rules = self.evaluate(platform, pillar, video_type, views_24h, hours_since)
        if not rules:
            if views_24h < 500:
                return (
                    "  ⏸️  Views basse (<500). Non consigliato.\n"
                    "     Analizza: hook debole? Orario? Tema?\n"
                    "     💡 Testa hook diverso (Hook Velocity)."
                )
            return "  ⏸️  Nessuna regola applicabile."

        lines = [
            f"\n{'━' * 55}",
            f"  ♻️  SUGGERIMENTI REPURPOSING",
            f"  📊 Views 24h: {views_24h} | ⏱️ Ore: {hours_since}",
            f"{'━' * 55}",
        ]
        for i, rule in enumerate(rules, 1):
            lines.append(f"\n  Opzione {i}: {rule.name}")
            lines.append(rule.display())
        lines.append(f"\n{'━' * 55}")
        return "\n".join(lines)

    def run_checklist(self, checklist_key: str, answers: dict) -> str:
        """Esegue checklist pre-repurposing. answers: {index: True/False}"""
        checklist = REPURPOSING_CHECKLISTS.get(checklist_key)
        if not checklist:
            return "  ❌ Checklist non trovata."

        checks = checklist["checks"]
        passed = 0
        failed = []
        for i, (text, reason) in enumerate(checks):
            if answers.get(i, False):
                passed += 1
            else:
                failed.append(f"{text} — {reason}")

        total = len(checks)
        is_ready = passed == total
        status = "✅ PRONTO" if is_ready else "❌ NON PRONTO"

        lines = [
            f"\n  {'─' * 50}",
            f"  ♻️  Checklist: {checklist['name']}",
            f"  Status: {status} ({passed}/{total})",
            f"  {'─' * 50}",
        ]
        if failed:
            lines.append(f"  ⚠️  Da completare:")
            for f in failed:
                lines.append(f"     □ {f}")
        lines.append(f"  {'─' * 50}")
        return "\n".join(lines)

    def display_all_rules(self) -> str:
        lines = [
            f"\n{'═' * 59}",
            f"  ♻️  REGOLE REPURPOSING — {len(self.rules)} attive",
            f"{'═' * 59}",
        ]
        for rule in self.rules:
            lines.append("")
            lines.append(rule.display())
        lines.append(f"\n{'═' * 59}")
        return "\n".join(lines)

    parser = argparse.ArgumentParser(description="📱 Social Growth Engine — Funnel")
    parser.add_argument("--demo", action="store_true", help="Demo completa")
    parser.add_argument("--score", type=str, metavar="'1,1,0,...'",
                        help="Score checklist 25 punti (25 valori 0/1 separati da virgola)")
    parser.add_argument("--lm-status", action="store_true", help="Stato lead magnet")
    parser.add_argument("--lm-keyword", type=str, metavar="KEYWORD", help="Lookup lead magnet per keyword")
    parser.add_argument("--calendar", action="store_true", help="Genera calendario con slot")
    parser.add_argument("--calendar-json", action="store_true", help="Calendario in JSON")
    parser.add_argument("--repurpose", nargs=4, metavar=("PLATFORM", "PILLAR", "VIEWS", "HOURS"),
                        help="Valuta repurposing: platform pillar views_24h hours_since")
    parser.add_argument("--repurpose-rules", action="store_true", help="Mostra tutte le regole")
    parser.add_argument("--repurpose-check", type=str, metavar="KEY",
                        help="Checklist repurposing (tiktok_to_ig_reel / tiktok_to_carousel / general_cross_post)")
    parser.add_argument("--checklist-display", action="store_true", help="Mostra CRO Checklist 25 punti")
    args = parser.parse_args()

    if args.score:
        scorer = ChecklistScorer()
        result = scorer.score_from_string(args.score)
        print(result.display())
        fixes = scorer.generate_priority_fixes(result)
        if fixes:
            print(f"\n  🔧 TOP {len(fixes)} FIX:")
            for f in fixes:
                print(f"     {f['priority']}. [{f['impact'].upper()}] #{f['point']}: {f['question'][:50]}")
                print(f"        ✅ {f['fix'][:60]}")

    elif args.lm_status:
        mgr = LeadMagnetManager()
        print(mgr.list_all())
        primary = mgr.get_primary()
        if primary:
            print(f"\n  📢 CTA attuale: \"{mgr.get_cta_for_content()}\"")
            print(f"  🔄 Rotazione ogni {primary.rotation_weeks} settimane")

    elif args.lm_keyword:
        mgr = LeadMagnetManager()
        lm = mgr.get_by_keyword(args.lm_keyword)
        if lm:
            print(lm.display())
        else:
            print(f"  ❌ Nessun LM con keyword \"{args.lm_keyword}\"")
            print(f"  Disponibili: {', '.join(lm.manychat_keyword for lm in mgr.db)}")

    elif args.calendar:
        cal = WeeklyCalendar()
        print(cal.display())

    elif args.calendar_json:
        cal = WeeklyCalendar()
        print(cal.export_json())

    elif args.repurpose:
        platform_str, pillar_str, views_str, hours_str = args.repurpose
        try:
            platform = Platform(platform_str.lower())
            pillar = Pillar(pillar_str.lower())
        except ValueError:
            print(f"  ❌ Platform: {', '.join(p.value for p in Platform)}")
            print(f"  ❌ Pillar: {', '.join(p.value for p in Pillar)}")
            return
        engine = RepurposingEngine()
        # Usa VideoType.AZIONE come default
        print(engine.suggest(platform, pillar, VideoType.AZIONE, int(views_str), int(hours_str)))

    elif args.repurpose_rules:
        engine = RepurposingEngine()
        print(engine.display_all_rules())

    elif args.repurpose_check:
        engine = RepurposingEngine()
        checklist = REPURPOSING_CHECKLISTS.get(args.repurpose_check)
        if not checklist:
            print(f"  ❌ Checklist non trovata. Disponibili: {', '.join(REPURPOSING_CHECKLISTS.keys())}")
            return
        print(f"\n  ♻️  CHECKLIST: {checklist['name']}")
        print(f"  Rispondi s/n per ogni punto:\n")
        answers = {}
        for i, (text, reason) in enumerate(checklist["checks"]):
            ans = input(f"  □ {text}? (s/n): ").strip().lower()
            answers[i] = ans in ("s", "si", "sì", "y", "yes")
        print(engine.run_checklist(args.repurpose_check, answers))

    elif args.checklist_display:
        for cat in CRO_CHECKLIST_25:
            print(cat.display())

    elif args.demo:
        print("\n" + "🟩" * 30)
        print("  📱 SOCIAL GROWTH ENGINE — Funnel Demo")
        print("🟩" * 30)

        # 1. CRO Checklist Score
        scorer = ChecklistScorer()
        answers = {i: (i % 3 != 0) for i in range(1, 26)}  # Simula 17/25
        result = scorer.score(answers)
        print(result.display())
        fixes = scorer.generate_priority_fixes(result)
        print(f"\n  🔧 TOP {len(fixes)} FIX:")
        for f in fixes:
            print(f"     {f['priority']}. [{f['impact'].upper()}] #{f['point']}: {f['question'][:45]}...")

        # 2. Lead Magnet
        mgr = LeadMagnetManager()
        print(mgr.list_all())
        primary = mgr.get_primary()
        if primary:
            print(f"\n  🏆 Primario: #{primary.id} — {primary.name}")
            print(f"  📢 CTA: \"{mgr.get_cta_for_content()}\"")
        print(f"  🔄 Serve rotazione (10 sett)? {'Sì' if mgr.should_rotate(10) else 'No'}")
        suggestion = mgr.suggest_rotation()
        if suggestion:
            print(f"  💡 Suggerimento: #{suggestion.id} — {suggestion.name}")

        # Keyword lookup
        for kw in ["AUDIT", "CALCOLA", "CORSO", "CALL", "SITO"]:
            lm = mgr.get_by_keyword(kw)
            status = f"#{lm.id} {lm.name}" if lm else "Non trovato"
            print(f"     \"{kw}\" → {status}")

        # 3. Calendar
        cal = WeeklyCalendar()
        print(cal.display())

        # Assign + update
        cal.assign_content(DayOfWeek.LUNEDI, Platform.TIKTOK, content_id=1, title="Teardown brand X")
        cal.update_slot_status(DayOfWeek.LUNEDI, Platform.TIKTOK, "drafted")
        print(f"\n  ✏️  Dopo assegnazione LUN TikTok:")
        for s in cal.get_day_slots(DayOfWeek.LUNEDI):
            print(s.display_compact())

        # Export JSON (primi 300 chars)
        j = cal.export_json()
        print(f"\n  📤 JSON ({len(j)} bytes): {j[:200]}...")

        # 4. Repurposing
        engine = RepurposingEngine()
        print(engine.display_all_rules())

        print(f"\n  🧪 SIM: TikTok Teardown 2500 views 30h:")
        print(engine.suggest(Platform.TIKTOK, Pillar.TEARDOWN, VideoType.AZIONE, 2500, 30))

        print(f"\n  🧪 SIM: TikTok Quick Win 800 views 50h:")
        print(engine.suggest(Platform.TIKTOK, Pillar.QUICK_WIN, VideoType.EDUCATIVO, 800, 50))

        print(f"\n  🧪 SIM: TikTok 200 views (basse):")
        print(engine.suggest(Platform.TIKTOK, Pillar.TEARDOWN, VideoType.AZIONE, 200, 30))

        # Checklist test
        print(f"\n  📋 Checklist TK→Reel (tutto ok tranne 2):")
        print(engine.run_checklist("tiktok_to_ig_reel",
            {0: True, 1: True, 2: False, 3: True, 4: True, 5: True, 6: False}))

        print(f"\n  📋 Checklist TK→Carosello (tutto ok):")
        print(engine.run_checklist("tiktok_to_carousel", {i: True for i in range(8)}))

    else:
        parser.print_help()


if __name__ == "__main__":
    main()
