Questo file definisce la struttura completa e permanente della Biblioteca
di Marketing University. È il sistema di classificazione che determina
DOVE viene archiviato ogni framework estratto, ogni concetto studiato,
ogni scheda generata.

La Biblioteca è organizzata in 6 AREE tematiche.
Ogni area contiene 4 SOTTOAREE (A, B, C, D).
Ogni sottoarea contiene una lista di ARGOMENTI specifici.

Quando un framework viene estratto (tramite KB_02_EXTRACTION_ENGINE.md),
viene classificato qui con un indirizzo preciso:
AREA [1-6] → SOTTOAREA [A-D] → ARGOMENTO specifico.

Esempio di indirizzo: AREA_1 → 1B → "Hook writing"
Significa: Copywriting & Persuasione → Tecniche Specifiche → Hook writing

## SOTTOAREA 1A: Framework di Copy

Contiene i modelli strutturali completi per scrivere copy.
Ogni framework è una sequenza di passaggi che, seguiti in ordine,
producono un testo persuasivo completo.

### Argomenti:

| # | Argomento | Descrizione | Livello |
|---|-----------|-------------|---------|
| 1A.01 | APP-SOC | Framework primario proprietario: Agree-Promise-Preview + Story-Offer-Close | Avanzato |
| 1A.02 | PAS | Problem-Agitate-Solve: identifica problema, agita dolore, presenta soluzione | Base |
| 1A.03 | AIDA | Attention-Interest-Desire-Action: sequenza classica di conversione | Base |
| 1A.04 | Before-After-Bridge | Mostra situazione attuale, situazione desiderata, ponte (soluzione) | Base |
| 1A.05 | FAB | Feature-Advantage-Benefit: trasforma caratteristiche in benefici | Base |
| 1A.06 | 4P | Picture-Promise-Prove-Push: visualizza, prometti, dimostra, spingi all'azione | Intermedio |
| 1A.07 | Star-Chain-Hook | Stella (attenzione), catena (logica), gancio (azione) | Intermedio |
| 1A.08 | QUEST | Qualify-Understand-Educate-Stimulate-Transition | Intermedio |
| 1A.09 | BAB Esteso | Before-After-Bridge con proof e urgency integrati | Avanzato |
| 1A.10 | Framework Aggiuntivi | Qualsiasi nuovo framework estratto da corsi futuri | Variabile |

### Criteri di classificazione in 1A:
- Il materiale descrive una STRUTTURA COMPLETA per scrivere un pezzo di copy dall'inizio alla fine
- Il framework ha step sequenziali numerabili
- È applicabile a più formati (non specifico per un solo tipo di copy)

1. **Quando ricevi materiale da classificare** (Workflow W1, Step 4):

   - Identifica l'area tematica principale (AREA_1 a AREA_6)
   - Identifica la sottoarea specifica (A, B, C o D)
   - Identifica l'argomento specifico (es. 1B.06)
   - SE l'argomento non esiste nella lista → crea un nuovo codice
     seguendo la numerazione progressiva (es. 1B.13)
   - Assegna l'indirizzo completo alla scheda framework

2. **Quando cerchi un framework** (Workflow W2):
   - L'utente chiede un concetto → identifica l'area/sottoarea
   - Cerca in KB_08_FRAMEWORKS_REGISTRY.md usando l'indirizzo
   - Se non trovato → verifica se l'argomento esiste qui
     → se esiste ma è vuoto = GAP da colmare

3. **Quando fai la review mensile** (Workflow W5):
   - Conta quante schede ci sono per ogni area/sottoarea
   - Identifica aree vuote o con poche schede = GAP
   - Suggerisci quale area prioritizzare per lo studio del mese successivo

## Regole di classificazione:

- **SE** un materiale copre più aree → classifica nella area PRIMARIA
  e segnala le aree secondarie nella scheda framework
- **SE** un materiale è al confine tra due sottoaree → classifica nella
  sottoarea dove ha l'impatto operativo maggiore
- **SE** non sai dove classificare → chiedi all'utente con le opzioni
  possibili e la tua raccomandazione
- **MAI** creare nuove aree (solo 6, permanenti). Puoi creare
  nuovi argomenti dentro le sottoaree esistenti.

## Scenario: L'utente invia un capitolo di un corso di email marketing
## che parla di come scrivere subject line efficaci.

### Processo di classificazione:

1. **Area**: Il materiale parla di email marketing → AREA_2
2. **Sottoarea**: Parla del COPY delle email (non strategia, non sequenze,
   non strategie avanzate) → Sottoarea 2C (Copywriting Email)
3. **Argomento**: Parla specificamente di subject line → 2C.01 (Subject line formulas)
4. **Indirizzo finale**: AREA_2 → 2C → 2C.01

### Considerazione aggiuntiva:
Il materiale potrebbe contenere anche formule di headline applicabili
oltre le email. In quel caso:
- **Classificazione primaria**: AREA_2 → 2C → 2C.01
- **Area secondaria segnalata nella scheda**: AREA_1 → 1B → 1B.01 (Headline writing)

Questo permette di trovare il framework sia cercando in Area 2 che in Area 1.

   La sottoarea D è sempre "Reference / Materiale di Riferimento"
   per permettere di archiviare documenti completi.

   possono esserci 10 schede framework diverse.

   una classificazione primaria e segnalare aree secondarie. Questo è
