## 📋 SCOPO

Questo file contiene il processo decisionale strutturato per tutte le decisioni strategiche di Digital Empire. Trasforma decisioni complesse e cariche di emotività in un processo razionale, ripetibile e basato su dati.

Principio fondante: "Le decisioni si prendono con i DATI della dashboard, non con le sensazioni. Se non hai dati, non hai una decisione — hai un'opinione."

Questo framework si attiva quando:
- È fine trimestre e devi pianificare Q+1
- Un pillar è in crisi (🔴 nella dashboard)
- Emerge una nuova opportunità o idea
- Devi decidere come allocare tempo e risorse
- Senti l'impulso di "fare qualcosa di nuovo"
- Due o più pillar competono per la tua attenzione
- Devi decidere tra due opzioni strategiche

## 📖 CONTENUTO PRINCIPALE

### 1. IL PROCESSO DECISIONALE IN 4 STEP
PANORAMICA DEL PROCESSO
════════════════════════

STEP 1: STATO ATTUALE "Dove sono?"
│ (Dati, non sensazioni)
▼
STEP 2: GAP ANALYSIS "Dove dovrei essere?"
│ (Dove sei vs dove "Qual è la distanza?"
│ dovresti essere) "Perché c'è il gap?"
▼
STEP 3: PRIORITIZZAZIONE "Cosa risolvo PRIMA?"
│ (Formula impatto)
▼
STEP 4: PIANO D'AZIONE "Come lo risolvo?"
(Azioni concrete "In quanto tempo?"
con timeline) "Cosa NON faccio?"

TEMPO TOTALE: 45-90 minuti per decisione complessa
REGOLA: Non saltare mai uno step. La tentazione è
andare direttamente al Step 4 (azione). RESISTI.
Senza i primi 3 step, l'azione è reattiva e spesso
sbagliata.

### 4. STEP 3: PRIORITIZZAZIONE
═══════════════════════════════════════════════════════════
STEP 3 — "COSA RISOLVO PRIMA?" (10-15 minuti)
═══════════════════════════════════════════════════════════

OBIETTIVO: Determinare quale gap ha il maggiore
IMPATTO sul revenue totale se risolto.

FORMULA DI IMPATTO:

IMPATTO = (Dimensione Gap) × (Leva sul Revenue)
× (Velocità di Risoluzione)

Dove:
┌────────────────────┬──────────────────────────────────┐
│ Fattore │ Come valutare (scala 1-5) │
├────────────────────┼──────────────────────────────────┤
│ DIMENSIONE GAP │ 1 = gap piccolo (<20%) │
│ │ 2 = gap moderato (20-40%) │
│ │ 3 = gap significativo (40-60%) │
│ │ 4 = gap grave (60-80%) │
│ │ 5 = gap critico (>80% o zero) │
├────────────────────┼──────────────────────────────────┤
│ LEVA SUL REVENUE │ 1 = impatto minimo sul revenue │
│ │ totale (<5%) │
│ │ 2 = impatto basso (5-10%) │
│ │ 3 = impatto medio (10-20%) │
│ │ 4 = impatto alto (20-40%) │
│ │ 5 = impatto critico (>40% del │
│ │ revenue totale dipende da │
│ │ questo) │
├────────────────────┼──────────────────────────────────┤
│ VELOCITÀ │ 1 = richiede 3+ mesi per vedere │
│ RISOLUZIONE │ risultati │
│ │ 2 = richiede 2-3 mesi │
│ │ 3 = richiede 1-2 mesi │
│ │ 4 = richiede 2-4 settimane │
│ │ 5 = richiede meno di 2 settimane │
└────────────────────┴──────────────────────────────────┘

PROCEDURA:

Per ogni gap identificato nello Step 2, assegna
i 3 punteggi:

┌────────────┬──────────┬───────┬──────┬──────┬────────┐
│ Pillar │ Gap │ Dim. │ Leva │ Vel. │IMPATTO │
│ │ │ Gap │ Rev │ Ris │(D×L×V) │
├────────────┼──────────┼───────┼──────┼──────┼────────┤
│ [Pillar 1] │ [KR/desc]│ [1-5] │ [1-5]│ [1-5]│ [N] │
│ [Pillar 2] │ [KR/desc]│ [1-5] │ [1-5]│ [1-5]│ [N] │
│ [Pillar 3] │ [KR/desc]│ [1-5] │ [1-5]│ [1-5]│ [N] │
│ [Pillar 4] │ [KR/desc]│ [1-5] │ [1-5]│ [1-5]│ [N] │
└────────────┴──────────┴───────┴──────┴──────┴────────┘

Ordina per IMPATTO decrescente

Seleziona il top 1 (o max top 2)

REGOLE DI OVERRIDE (superano la formula):

REGOLA 1: AGENZIA PRIMA
SE il gap dell'agenzia è significativo (>30%):
→ L'agenzia è SEMPRE la priorità #1,
indipendentemente dal punteggio della formula.
→ ECCEZIONE: se l'agenzia è 🟢 stabile e il gap
è in info-biz con un lancio imminente (entro 2
settimane) → il lancio può avere priorità
temporanea (max 2-4 settimane).

REGOLA 2: MAI 3 GAP CONTEMPORANEAMENTE
Non lavorare MAI su 3 gap contemporaneamente.
Scegline 1. AL MASSIMO 2.
Se ne scegli 2: 1 deve essere il focus principale
(70% dello sforzo), l'altro il secondario (30%).

REGOLA 3: ALLARMI PRIMA DEI GAP
SE c'è un allarme 🔴 attivo (da SOGLIE_ALLARME.md):
→ L'allarme ha priorità ASSOLUTA su qualsiasi
gap analysis. Prima risolvi l'allarme, poi
torni alla gap analysis.

ESEMPIO COMPLETO:

┌────────────┬──────────────────┬─────┬──────┬─────┬────────┐
│ Pillar │ Gap │ Dim │ Leva │ Vel │IMPATTO │
├────────────┼──────────────────┼─────┼──────┼─────┼────────┤
│ Agenzia │ Close rate 20% │ 3 │ 5 │ 4 │ 60 ⭐ │
│ │ vs target 35% │ │ │ │ │
├────────────┼──────────────────┼─────┼──────┼─────┼────────┤
│ Info-Biz │ Lista email 50 │ 5 │ 3 │ 3 │ 45 │
│ │ vs target 300 │ │ │ │ │
├────────────┼──────────────────┼─────┼──────┼─────┼────────┤
│ YouTube │ 0 lead generati │ 5 │ 2 │ 4 │ 40 │
│ │ vs target 10/mese│ │ │ │ │
├────────────┼──────────────────┼─────┼──────┼─────┼────────┤
│ Cross-Poll │ 0 azioni in │ 4 │ 2 │ 5 │ 40 │
│ │ 30 giorni │ │ │ │ │
└────────────┴──────────────────┴─────┴──────┴─────┴────────┘

DECISIONE: Focus su Close Rate Agenzia (IMPATTO 60).
Secondario: Lista email Info-Biz (IMPATTO 45).
NOT TO DO: YouTube lead gen e cross-pollination
vengono DOPO.

OUTPUT DELLO STEP 3:
1 (o max 2) gap prioritari su cui concentrarsi,
ordinati per impatto, con motivazione.

### 8. PROCESSO PER DECISIONI DI FINE TRIMESTRE
═══════════════════════════════════════════════════════════
PLANNING Q+1 — PROCESSO COMPLETO
═══════════════════════════════════════════════════════════

Questo processo si esegue l'ultimo venerdì del
trimestre, come parte della review trimestrale
(vedi WORKFLOW_CADENZE.md).

FASE 1: RETROSPETTIVA (1.5 ore)
─────────────────────────────────
Usa il template da RETROSPETTIVA_ENGINE.md

FASE 2: CLOSE-OUT OKR Q CORRENTE (45 min)
──────────────────────────────────────────
Usa il template close-out da OKR_SYSTEM.md

FASE 3: DECISIONI STRATEGICHE Q+1 (1 ora)
──────────────────────────────────────────

Rispondi a queste 7 domande (in ordine):

L'AGENZIA È SOLIDA?
"Il revenue dell'agenzia è stabile o in crescita?
La pipeline è piena per i prossimi 30 giorni?"
├── SÌ → Puoi allocare tempo ad altri pillar
└── NO → Il Q+1 è principalmente "SALVA L'AGENZIA"

QUALE PILLAR HA IL POTENZIALE MAGGIORE?
"Se potessi investire 100 ore extra in UN pillar,
quale genererebbe il ROI più alto?"
└── Questo diventa la priorità #1 del trimestre
(se l'agenzia è stabile)

QUALE CROSS-POLLINATION NON SFRUTTO?
"Quale sinergia tra pillar sto ignorando che
potrebbe moltiplicare i risultati?"
└── Revisiona la mappa in CROSS_POLLINATION_ENGINE.md

COSA DEVO SMETTERE DI FARE?
"Cosa mi sta rubando tempo senza generare
risultati proporzionali?"
└── Questo va nella Not To Do list di Q+1

QUALE COMPETENZA MI MANCA?
"Per raggiungere gli OKR di Q+1, ho tutte le
competenze necessarie?"
└── Se NO → includi formazione nello sprint
(Marketing University P6)

QUALE RISCHIO MI PREOCCUPA?
"Cosa potrebbe andare storto nel Q+1?"
└── Prepara un piano B per gli scenari peggiori

SE POTESSI OTTENERE UNA SOLA COSA IN Q+1,
QUALE SAREBBE?
"_______________________________________________"
└── Questa è la TUA priorità emotiva. Confrontala
con la priorità razionale (#2). Se coincidono
→ perfetto. Se no → segui la razionale, ma
dedica un 10% alla emotiva per mantenere
motivazione.

FASE 4: DEFINIZIONE OKR Q+1 (1 ora)
──────────────────────────────────────
Usa il template OKR Trimestrale da OKR_SYSTEM.md.
Compila: Objective + KR per ogni pillar + 3 priorità

Not To Do.
FASE 5: RESOURCE ALLOCATION Q+1 (30 min)
──────────────────────────────────────────
Definisci la distribuzione tempo per Q+1:

│ Pillar │ % Q+1 │ Motivazione │
├─────────────────┼──────────┼──────────────────────┤
│ Agenzia CRO │ [N]% │ [perché questa %] │
│ Info-Business │ [N]% │ [perché questa %] │
│ YouTube │ [N]% │ [perché questa %] │
│ Satellite │ [N]% │ [perché questa %] │
│ Formazione │ [N]% │ [se prevista] │
└─────────────────┴──────────┴──────────────────────┘

## 🔧 COME UTILIZZARE QUESTO FILE

**Quando consultarlo:**
- Quando l'utente deve prendere una decisione strategica (qualsiasi tipo)
- Quando l'utente dice "non so cosa fare" o "ho troppe cose da fare"
- Quando un pillar è 🔴 e serve decidere come intervenire
- Quando l'utente deve scegliere tra due opzioni (Sezione 6)
- Quando l'utente deve allocare tempo/risorse (Sezione 7)
- A fine trimestre per il planning Q+1 (Sezione 8)
- Quando l'utente chiede gap analysis o prioritizzazione

**Come integrare nella risposta:**
1. Guida l'utente attraverso i 4 STEP in ordine — non saltare
2. Chiedi i dati necessari per lo Step 1 se non li ha forniti
3. Usa le tabelle e i template esattamente come sono nel file
4. Applica SEMPRE le regole di override (Sezione 4, Step 3)
5. Includi SEMPRE la Not To Do nel piano d'azione (Step 4)
6. Registra la decisione nel Decision Log (Sezione 9)
7. Se l'utente vuole saltare allo Step 4 → fermalo: "Prima servono i dati (Step 1), il gap (Step 2) e la priorità (Step 3). Iniziamo dall'inizio."

## ⚠️ NOTE E AVVERTENZE

1. **Il processo decisionale NON è un esercizio intellettuale.** Deve produrre AZIONI concrete con timeline. Se alla fine del processo non hai almeno 3 azioni per questa settimana → il processo non è completato.

2. **La tentazione più grande è saltare allo Step 4** (azione) senza fare gli Step 1-3. RESISTI. Le azioni senza diagnosi sono spesso le azioni sbagliate. "Un problema ben definito è un problema mezzo risolto."

3. **Le regole di override (Sezione 4) esistono per un motivo.** La formula dell'impatto è uno strumento, non una legge. Se la formula dice che YouTube è prioritario ma l'agenzia è in crisi → l'agenzia vince. Sempre.

4. **Il Decision Log (Sezione 9) è il tuo asset più sottovalutato.** Tra 6 mesi, rileggere le decisioni passate con i risultati ti darà pattern incredibilmente utili su come ragioni e dove sbagli.

5. **"NOT TO DO" è la sezione più importante del Piano d'Azione.** Decidere cosa fare è facile. Decidere cosa NON fare è dove si vince la partita. Se il piano d'azione non ha una Not To Do list → è incompleto.

6. **Non usare questo framework per micro-decisioni** ("quale titolo per il video?"). È progettato per DECISIONI STRATEGICHE che impattano l'allocazione di tempo, risorse e focus tra i pillar. Per le micro-decisioni, usa l'intuizione + i framework dei singoli progetti (P1-P8).
