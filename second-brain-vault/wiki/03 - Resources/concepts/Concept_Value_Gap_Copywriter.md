# Concept: Value Gap del Copywriter (Dipendente vs Freelance)

## Overview
Il Value Gap è il divario tra il valore economico generato da un copywriter per il suo cliente/datore e la compensazione che il copywriter riceve. Nei contratti a tempo (dipendente o per ora/parola), il gap è massimo. In modelli a prezzo fisso o % profitto, il gap si riduce.

## Il Gap Visualizzato

Grafico Andrei Pascu (qOK4WP82Bvo#0:11:32, frame-347):
- **Valore generato:** €50k/mese (barra verde alta)
- **Stipendio ricevuto:** €1.2k/mese (barra grigia bassa con fondo rosso)

Il divario ≈ 40x. Il surplus va all'azienda.

## Meccanismo

Il Value Gap nasce da una pricing trap: quando il copywriter accetta di essere pagato per **input** (tempo, parole) invece che per **output** (conversioni, revenue), cede il surplus di valore al committente.

Equazione del gap:
```
Value Gap = Valore generato - Compenso ricevuto
```

Massimo quando: payment = per ora / per parola
Minimo quando: payment = % revenue generata

## 4 Posizioni sul Gap

| Metodo | Gap | Note |
|--------|-----|------|
| Per parola | Massimo | Prezza il mezzo, non il fine |
| Per ora | Massimo | Replica la logica del dipendente |
| Prezzo fisso | Medio | Beginners: tu fissi il prezzo proporzionale al valore |
| % profitto | Minimo | Senior: 10% revenue, richiede dati fatturato |

## Implicazione Pratica

Per ridurre il Value Gap:
1. Smettere di prezzare input (tempo, parole)
2. Prezzare output (copy consegnato, con valore stimato)
3. A lungo termine: spostarsi su modelli a performance (% profitto)
