## Il Metodo in 4 Passi

### Passo 1 — Il Design System (claude.ai/design)
- Sezioni: Slides template, Type (3 livelli), Colors (8 cat.), Spacing, Components (4 tipi), Brand (logo+wordmark)
- Setup via "Quick questions": materiali esistenti + cosa fa il prodotto + quali superfici
- Problema frequente: "Missing brand fonts" → upload manuale

### Passo 2 — I Template (Design Files)
- Template riusabili cross-progetto, brand-aligned di default
- "Start with context" sidebar: Design System / screenshot / codebase / Figma file
- Libreria Avanguardia: 50+ YouTube Templates, Slides YouTube, LinkedIn DS, Funnels LinkedIn

### Passo 3 — Le Skills (Claude Code)
- `skill-creator` (anthropics/skills GitHub): converte workflow ripetuti in SKILL.md
- `featuresheet:cheat-skill`: genera cheat sheet 1080×1350 PNG+PDF branded in un singolo prompt
- Self-check pattern: Claude genera PNG → lo rilegge natively → corregge errori → ri-esporta (zero intervento umano)
- Social Media Manager reference: 25+ skill coprendo YouTube, email, LinkedIn, Skool, research, prompt engineering

### Passo 4 — Lead Magnet Automatizzato
- Keyword = regalo (es. "FUNNEL" per funnel, "Claude" per guida Claude)
- CTA: "Commenta '[keyword]' e te lo mando personalmente" + scarcity XX/100
- Claude Code produce sia l'asset (PDF/PNG) sia il LinkedIn post con CTA nella stessa sessione
