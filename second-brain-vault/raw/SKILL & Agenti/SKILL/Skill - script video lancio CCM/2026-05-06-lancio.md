## 02. FASI DEL LANCIO
═══════════════════════════════════════════════════════════════

Il lancio è diviso in 5 fasi.
Ogni fase ha il suo obiettivo, la sua CTA,
il suo tono, e i suoi contenuti prioritari.

---

### FASE 0 — PRE-LANCIO (settimane prima di G0)
OBIETTIVO: Costruire audience e credibilità. Zero vendita.
DURATA: Variabile (2-6 settimane)

CTA ATTIVA: Follow + engagement
COSA NON FARE: Non menzionare nessun prodotto
TONO: Educativo puro. Massimo valore.

CONTENUTI PRIORITARI:
- Tutorial pratici su Claude Code (Formato 1)
- Discovery di tool e funzioni (Formato 3)
- Liste di risorse (Formato 4)
- Confronti e livelli (Formato 5)

OBIETTIVO NUMERICO:
- Crescita follower sulle 3 pagine
- Engagement rate >5%
- Primissimi contatti caldi (commenti interessati)

SEGNALE DI PASSAGGIO ALLA FASE 1:
Quando una o più pagine raggiungono momentum
(>20 follower reali, commenti di engagement genuino)
oppure dopo N settimane stabilite.

---

### FASE 1 — WARM-UP (G-7 a G0)
OBIETTIVO: Creare anticipazione senza rivelare il prodotto.
DURATA: 7 giorni prima dell'apertura funnel

CTA ATTIVA: Engagement ("seguimi per non perdertelo")
COSA NON FARE: Non rivelare il nome del prodotto.
               Non dare il link ancora.
TONO: Misterioso ma credibile. Curioso ma specifico.

CONTENUTI PRIORITARI:
- Teaser sul "qualcosa che sta arrivando"
- Contenuti di valore ancora più densi del solito
- Behind the scenes (mostrare che si sta costruendo qualcosa)
- Domande al pubblico per coinvolgerlo

LINGUAGGIO WARM-UP:
"Sto preparando qualcosa su Claude Code
che non esiste ancora in Italia."
"Se stai usando Claude Code ogni giorno,
questo ti interesserà molto."
"Tra qualche giorno apro qualcosa.
Se vuoi saperlo subito, seguimi."

COSA EVITARE:
- Non dire "corso" o "ebook" ancora
- Non dare prezzi
- Non dare link
- Non creare urgenza artificiale

SEGNALE DI PASSAGGIO ALLA FASE 2:
G0 = giorno stabilito di apertura funnel.

---

### FASE 2 — LANCIO ATTIVO / LEAD CAPTURE (G0 a GW-1)
OBIETTIVO: Massimizzare gli opt-in per l'ebook gratuito.
DURATA: Dal giorno di apertura funnel al giorno prima della call/webinar

CTA ATTIVA: Ebook gratuito "Claude Code Mastery" → link in bio
COSA NON FARE: Non spingere corso, masterclass, o call negli script
TONO: Educativo con CTA naturale verso l'ebook

CONTENUTI PRIORITARI:
- Tutorial pratici con CTA → ebook
- Demo che mostrano quello che c'è nell'ebook
- Lista di concetti dall'ebook come anticipazione
- Discovery di funzioni trattate nell'ebook

LINGUAGGIO CTA FASE 2:
"Ho scritto 206 pagine su questa roba. Gratis. Link in bio."
"Ebook gratuito: Claude Code Mastery. 206 pagine. Link in bio."
"Se vuoi la guida completa, l'ho messa in un ebook.
È gratis. Si chiama Claude Code Mastery. Link in bio."

OBIETTIVO NUMERICO:
- [INSERIRE target opt-in totali per questa fase]
- Tasso di conversione landing page target: >30%

SEGNALE DI PASSAGGIO ALLA FASE 3:
Giorno stabilito per il webinar/call oppure
raggiungimento del target di opt-in.

---

### FASE 3 — PUSH CALL / CONVERSIONE
OBIETTIVO: Convertire i lead caldi in prenotazioni call.
DURATA: Ultima settimana prima della call

CTA ATTIVA: Call gratuita 1:1 → link pagina call
COSA NON FARE: Non tornare a spingere l'ebook.
               Non spingere corso direttamente.
TONO: Più personale. Più diretto. Trasparenza totale.

CONTENUTI PRIORITARI:
- Script sulla call (cos'è, come funziona, perché è gratis)
- Contenuti che mostrano cosa si impara nella call
- Dietro le quinte delle call già fatte
- Risposta alle domande frequenti sulla call

LINGUAGGIO CTA FASE 3:
"Faccio call gratuite di 45 minuti su Claude Code.
1 a 1. Sul tuo caso specifico.
8 posti a settimana. Link in bio."

"90% formazione. 10% pitch. Carte scoperte.
Link in bio per prenotare il tuo slot."

URGENZA REALE COMUNICABILE:
"Faccio 8 call a settimana. Non di più.
Quando i posti finiscono, finiscono."
(Solo se i posti sono davvero limitati a 8)

OBIETTIVO NUMERICO:
- [INSERIRE target call prenotate]
- [INSERIRE target call effettuate]

---

### FASE 4 — POST-LANCIO / EVERGREEN
OBIETTIVO: Mantenere il funnel attivo in modo automatico.
DURATA: Indefinita

CTA ATTIVA: Alterna settimanalmente tra ebook e call
TONO: Ritorna educativo con CTA naturali integrate

CONTENUTI:
- Serie YouTube (tutorial lunghi 20-40 min)
- Short-form continuativi con CTA ebook o call
- Case study delle call effettuate (anonimizzati)
- Aggiornamenti su Claude Code (discovery, news)
