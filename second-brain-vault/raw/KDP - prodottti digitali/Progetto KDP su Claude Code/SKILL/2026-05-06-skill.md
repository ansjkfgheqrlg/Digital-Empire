## 4. PRINCIPIO FONDAMENTALE

> "Un buon libro non si scrive. Si riscrive. L'editing non è decorazione — è ingegneria strutturale del testo."

L'editing professionale segue una gerarchia precisa. Non puoi lucidare le frasi se la struttura è rotta. Non puoi sistemare la struttura se il contenuto è sbagliato.

```

GERARCHIA DELL'EDITING (dall'alto = priorità massima):
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

LIVELLO 4: STRATEGIA (il libro mantiene le promesse?)
    ↓ solo dopo aver risolto questo
LIVELLO 3: STRUTTURA (l'ordine è logico? ci sono buchi?)
    ↓ solo dopo aver risolto questo
LIVELLO 2: CONTENUTO (ogni sezione è forte, specifica, utile?)
    ↓ solo dopo aver risolto questo
LIVELLO 1: SUPERFICIE (grammatica, ritmo, formattazione)

ERRORE CLASSICO: Iniziare dal Livello 1 (lucidare le frasi)
quando il Livello 4 è rotto (il libro non mantiene 
ciò che promette).
```


### 3 leggi dell'ottimizzazione libro:


```

LEGGE 1: COMPLETEZZA > PERFEZIONE PARZIALE
→ Un libro ottimizzato al 100% ma con capitoli mancanti 
  è INUTILE. Mai perdere contenuto durante l'editing.

LEGGE 2: MIGLIORA LA VOCE, NON SOSTITUIRLA
→ Il tuo lavoro è rendere la voce dell'autore più 
  efficace, non imporre la tua. Se il libro è 
  colloquiale, rendilo un colloquiale MIGLIORE.

LEGGE 3: OGNI MODIFICA DEVE AVERE UNA RAGIONE
→ "Suona meglio" non è una ragione. 
  "La frase attiva aumenta l'engagement del lettore 
  e riduce la lunghezza del 30%" è una ragione.
```

#### 0A. Protocollo di Ricezione

```python

# ═══════════════════════════════════════════════════════
# INTAKE VALIDATOR — Esegui PRIMA di qualsiasi analisi
# ═══════════════════════════════════════════════════════

def validate_intake(book_text, strategy=None):
    """
    Valida che tutti i prerequisiti siano soddisfatti
    prima di iniziare l'audit.
    
    Returns: dict con status e issues trovate
    """
    
    issues = []
    warnings = []
    metadata = {}
    
    # ── CHECK 1: Il testo è presente e non vuoto ──
    if not book_text or len(book_text.strip()) < 500:
        issues.append(
            "BLOCCANTE: Il testo ricevuto è troppo corto "
            "o vuoto. Servono almeno 500 caratteri. "
            "Hai incollato/caricato tutto il libro?"
        )
    
    # ── CHECK 2: Rilevamento lingua ──
    # Analizza le prime 200 parole per determinare la lingua
    first_words = book_text.split()[:200]
    italian_markers = [
        'il', 'la', 'di', 'che', 'un', 'una', 'per', 
        'con', 'sono', 'come', 'questo', 'quella', 
        'nella', 'delle', 'degli', 'anche', 'suo', 
        'alla', 'dal', 'nel'
    ]
    english_markers = [
        'the', 'a', 'an', 'is', 'are', 'was', 'were',
        'of', 'in', 'to', 'for', 'with', 'that', 
        'this', 'from', 'have', 'has', 'been'
    ]
    
    it_count = sum(
        1 for w in first_words 
        if w.lower() in italian_markers
    )
    en_count = sum(
        1 for w in first_words 
        if w.lower() in english_markers
    )
    
    if it_count > en_count:
        metadata['lingua'] = 'italiano'
    elif en_count > it_count:
        metadata['lingua'] = 'english'
    else:
        metadata['lingua'] = 'da_confermare'
        warnings.append(
            "Non riesco a determinare la lingua con "
            "certezza. Conferma: il libro è in italiano "
            "o in inglese?"
        )
    
    # ── CHECK 3: Struttura capitoli ──
    chapter_markers = [
        'capitolo', 'chapter', 'cap.', 'cap ', 
        'parte ', 'part ', 'sezione', 'section'
    ]
    
    chapters_found = []
    lines = book_text.split('\n')
    for i, line in enumerate(lines):
        line_lower = line.lower().strip()
        for marker in chapter_markers:
            if marker in line_lower and len(line.strip()) < 100:
                chapters_found.append({
                    'line_num': i + 1,
                    'title': line.strip(),
                    'position_pct': round(
                        (i / max(len(lines), 1)) * 100, 1
                    )
                })
    
    metadata['chapters_found'] = len(chapters_found)
    metadata['chapter_list'] = chapters_found
    
    if len(chapters_found) == 0:
        warnings.append(
            "Nessun marcatore di capitolo trovato "
            "(es. 'Capitolo 1', 'Parte 1', 'Sezione'). "
            "Il libro ha capitoli/sezioni? "
            "Se sì, come sono indicati?"
        )
    
    # ── CHECK 4: Completezza (intro + corpo + conclusione) ──
    text_lower = book_text.lower()
    has_intro = any(
        kw in text_lower 
        for kw in [
            'introduzione', 'prefazione', 'premessa',
            'introduction', 'preface', 'foreword'
        ]
    )
    has_conclusion = any(
        kw in text_lower 
        for kw in [
            'conclusione', 'conclusioni', 'epilogo',
            'conclusion', 'final thoughts', 'afterword',
            'considerazioni finali', 'in chiusura'
        ]
    )
    
    if not has_intro:
        warnings.append(
            "Non trovo un'introduzione/prefazione. "
            "Il libro ne ha una? È stata inclusa?"
        )
    if not has_conclusion:
        warnings.append(
            "Non trovo una conclusione/epilogo. "
            "Il libro ne ha una? È stata inclusa? "
            "O il libro finisce con l'ultimo capitolo?"
        )
    
    # ── CHECK 5: Statistiche base del testo ──
    words = book_text.split()
    sentences = [
        s.strip() for s in 
        book_text.replace('!', '.').replace('?', '.').split('.') 
        if len(s.strip()) > 3
    ]
    paragraphs = [
        p.strip() for p in book_text.split('\n\n') 
        if len(p.strip()) > 20
    ]
    
    metadata['stats'] = {
        'total_words': len(words),
        'total_sentences': len(sentences),
        'total_paragraphs': len(paragraphs),
        'total_lines': len(lines),
        'avg_sentence_length': round(
            len(words) / max(len(sentences), 1), 1
        ),
        'avg_paragraph_length_sentences': round(
            len(sentences) / max(len(paragraphs), 1), 1
        ),
        'estimated_pages': round(len(words) / 250, 0),
        'estimated_reading_time_min': round(
            len(words) / 200, 0
        )
    }
    
    # ── CHECK 6: Strategia presente? ──
    metadata['has_strategy'] = strategy is not None
    if not strategy:
        warnings.append(
            "Nessuna strategia/brief fornita. "
            "Posso audire il testo, ma non posso "
            "verificare l'allineamento strategico "
            "(target, positioning, promessa). "
            "Hai il brief? Se sì, caricalo."
        )
    
    # ── CHECK 7: Libro troppo lungo per un singolo pass? ──
    if len(words) > 25000:
        metadata['requires_chunking'] = True
        estimated_chunks = (len(words) // 15000) + 1
        warnings.append(
            f"Il libro è lungo ({len(words):,} parole). "
            f"Potrebbe essere necessario processarlo "
            f"in {estimated_chunks} blocchi. "
            f"Procederò comunque e segnalerò se serve "
            f"dividere."
        )
    else:
        metadata['requires_chunking'] = False
    
    # ── RISULTATO ──
    return {
        'status': 'BLOCKED' if issues else 'READY',
        'issues': issues,       # Bloccanti
        'warnings': warnings,   # Non bloccanti ma da comunicare
        'metadata': metadata
    }
```

```python
                        1: 'Filler sistematici che gonfiano il testo '
                           'senza aggiungere valore'
                    }
                }
            ]
        }
    }
    
    @staticmethod
    def calculate_dimension_score(scores_dict):
        """
        Calcola il punteggio di una dimensione
        scores_dict: {'check_id': score, ...}
        Returns: punteggio 0-100
        """
        if not scores_dict:
            return 0
        avg = sum(scores_dict.values()) / len(scores_dict)
        return round((avg / 5) * 100, 0)
    
    @staticmethod
    def calculate_total_score(dimension_scores):
        """
        Calcola il punteggio totale pesato.
        dimension_scores: {'D1_STRATEGY': 80, ...}
        Returns: punteggio 0-100
        """
        weights = {
            'D1_STRATEGY': 0.25,
            'D2_STRUCTURE': 0.20,
            'D3_CONTENT': 0.25,
            'D4_VOICE': 0.10,
            'D5_FLOW': 0.10,
            'D6_SURFACE': 0.10
        }
        total = sum(
            dimension_scores.get(dim, 0) * w 
            for dim, w in weights.items()
        )
        return round(total, 0)
    
    @staticmethod
    def score_to_verdict(score):
        """Converte il punteggio in verdetto."""
        if score >= 85:
            return '🟢 ECCELLENTE — Piccoli ritocchi, pronto per pubblicazione'
        elif score >= 70:
            return '🟡 BUONO — Miglioramenti mirati necessari'
        elif score >= 50:
            return '🟠 SUFFICIENTE — Revisione significativa necessaria'
        elif score >= 30:
            return '🔴 INSUFFICIENTE — Riscrittura sostanziale necessaria'
        else:
            return '⛔ CRITICO — Considerare riscrittura completa'
```

```python
# ═══════════════════════════════════════════════════════
# TEXT METRICS ANALYZER — Analisi Quantitativa Automatica
# ═══════════════════════════════════════════════════════

def analyze_text_metrics(text):
    """
    Analisi quantitativa completa del testo.
    Genera metriche oggettive su leggibilità, 
    struttura e stile.
    """
    import re
    from collections import Counter
    
    # ── Tokenizzazione ──
    words = text.split()
    sentences = [
        s.strip() for s in 
        re.split(r'[.!?]+', text) 
        if len(s.strip().split()) >= 3
    ]
    paragraphs = [
        p.strip() for p in text.split('\n\n') 
        if len(p.strip()) > 20
    ]
    
    # ── 1. Distribuzione lunghezza frasi ──
    sentence_lengths = [len(s.split()) for s in sentences]
    
    short_sentences = sum(1 for l in sentence_lengths if l <= 8)
    medium_sentences = sum(1 for l in sentence_lengths if 9 <= l <= 20)
    long_sentences = sum(1 for l in sentence_lengths if 21 <= l <= 35)
    very_long_sentences = sum(1 for l in sentence_lengths if l > 35)
    
    sentence_distribution = {
        'corte (≤8 parole)': {
            'count': short_sentences,
            'pct': round(short_sentences / max(len(sentences), 1) * 100, 1),
            'target': '20-30%',
            'note': 'Creano impatto e ritmo'
        },
        'medie (9-20 parole)': {
            'count': medium_sentences,
            'pct': round(medium_sentences / max(len(sentences), 1) * 100, 1),
            'target': '50-60%',
            'note': 'Il "pane" della prosa'
        },
        'lunghe (21-35 parole)': {
            'count': long_sentences,
            'pct': round(long_sentences / max(len(sentences), 1) * 100, 1),
            'target': '15-25%',
            'note': 'Costruiscono complessità'
        },
        'troppo lunghe (>35 parole)': {
            'count': very_long_sentences,
            'pct': round(very_long_sentences / max(len(sentences), 1) * 100, 1),
            'target': '<5%',
            'note': '⚠️ Da spezzare quasi sempre'
        }
    }
    
    # ── 2. Distribuzione lunghezza paragrafi ──
    para_lengths = [len(p.split('.')) for p in paragraphs]
    
    short_paras = sum(1 for l in para_lengths if l <= 2)
    medium_paras = sum(1 for l in para_lengths if 3 <= l <= 5)
    long_paras = sum(1 for l in para_lengths if 6 <= l <= 8)
    very_long_paras = sum(1 for l in para_lengths if l > 8)
    
    paragraph_distribution = {
        'corti (1-2 frasi)': {
            'count': short_paras,
            'pct': round(short_paras / max(len(paragraphs), 1) * 100, 1),
            'target': '20-30%',
            'note': 'Creano respiro e impatto'
        },
        'medi (3-5 frasi)': {
            'count': medium_paras,
            'pct': round(medium_paras / max(len(paragraphs), 1) * 100, 1),
            'target': '50-60%',
            'note': 'La lunghezza ideale'
        },
        'lunghi (6-8 frasi)': {
            'count': long_paras,
            'pct': round(long_paras / max(len(paragraphs), 1) * 100, 1),
            'target': '10-20%',
            'note': 'Accettabili per approfondimenti'
        },
        'troppo lunghi (>8 frasi)': {
            'count': very_long_paras,
            'pct': round(very_long_paras / max(len(paragraphs), 1) * 100, 1),
            'target': '<5%',
            'note': '⚠️ Muro di testo, da spezzare'
        }
    }
    
    # ── 3. Leggibilità (Gulpease Index per italiano) ──
    # Formula Gulpease: 89 + (300 × frasi - 10 × lettere) / parole
    total_chars = sum(len(w) for w in words)
    gulpease = round(
        89 + (300 * len(sentences) - 10 * total_chars) 
        / max(len(words), 1), 
        0
    )
    
    if gulpease >= 80:
        readability_verdict = '🟢 Molto facile (livello elementare)'
    elif gulpease >= 60:
        readability_verdict = '🟢 Facile (livello medio)'
    elif gulpease >= 40:
        readability_verdict = '🟡 Medio (livello superiore)'
    elif gulpease >= 20:
        readability_verdict = '🟠 Difficile (livello universitario)'
    else:
        readability_verdict = '🔴 Molto difficile'
    
    # ── 4. Rilevamento Pattern Problematici ──
    
    # 4a. Filler words (italiano)
    filler_patterns_it = [
        r'\bfondamentalmente\b',
        r'\bin definitiva\b',
        r'\bcome abbiamo già detto\b',
        r'\bè importante notare che\b',
        r'\bè bene ricordare che\b',
        r'\bcome sappiamo\b',
        r'\bovviamente\b',
        r'\bnaturalmente\b',
        r'\bsenza ombra di dubbio\b',
        r'\bè opportuno sottolineare\b',
        r'\bin buona sostanza\b',
        r'\ba dire il vero\b',
        r'\bper così dire\b',
        r'\bin un certo senso\b',
        r'\bper certi versi\b',
        r'\bè doveroso precisare\b',
        r'\bva da sé che\b',
        r'\bnon è un segreto che\b',
        r'\bcome si suol dire\b',
        r'\binutile dire che\b'
    ]
    
    # 4b. Filler words (inglese)
    filler_patterns_en = [
        r'\bbasically\b',
        r'\bactually\b',
        r'\bin order to\b',
        r'\bit is important to note\b',
        r'\bas we all know\b',
        r'\bneedless to say\b',
        r'\bit goes without saying\b',
        r'\bat the end of the day\b',
        r'\bin terms of\b',
        r'\bthe fact that\b',
        r'\bin and of itself\b',
        r'\bvery unique\b',
        r'\bcompletely destroyed\b',
        r'\babsolutely essential\b'
    ]
    
    filler_count = 0
    filler_instances = []
    all_fillers = filler_patterns_it + filler_patterns_en
    text_lower = text.lower()
    
    for pattern in all_fillers:
        matches = re.findall(pattern, text_lower)
        if matches:
            filler_count += len(matches)
            filler_instances.append({
                'pattern': pattern.replace(r'\b', '').strip(),
                'count': len(matches)
            })
    
    # 4c. Costruzioni passive (italiano)
    passive_patterns = [
        r'\bè stato\b', r'\bè stata\b',
        r'\bsono stati\b', r'\bsono state\b',
        r'\bviene\b.*\bto\b', r'\bvengono\b',
        r'\bfurono\b', r'\bfu\b.*\bto\b'
    ]
    passive_count = sum(
        len(re.findall(p, text_lower)) 
        for p in passive_patterns
    )
    passive_ratio = round(
        passive_count / max(len(sentences), 1) * 100, 1
    )
    
    # 4d. Inizi di frase ripetuti
    sentence_starts = [
        ' '.join(s.strip().split()[:3]).lower() 
        for s in sentences 
        if len(s.strip().split()) >= 3
    ]
    start_counter = Counter(sentence_starts)
    repeated_starts = {
        k: v for k, v in start_counter.items() 
        if v >= 3
    }
    
    # ── 5. Analisi per capitolo ──
    # (Richiede che i capitoli siano già stati identificati)
    
    # ── RISULTATO ──
    return {
        'sentence_distribution': sentence_distribution,
        'paragraph_distribution': paragraph_distribution,
        'readability': {
            'gulpease_index': gulpease,
            'verdict': readability_verdict,
            'avg_sentence_length': round(
                sum(sentence_lengths) / max(len(sentence_lengths), 1), 1
            ),
            'max_sentence_length': max(sentence_lengths) if sentence_lengths else 0,
            'min_sentence_length': min(sentence_lengths) if sentence_lengths else 0
        },
        'problems': {
            'filler_total': filler_count,
            'filler_detail': sorted(
                filler_instances, 
                key=lambda x: x['count'], 
                reverse=True
            )[:10],  # Top 10 filler
            'passive_count': passive_count,
            'passive_ratio_pct': passive_ratio,
            'passive_verdict': (
                '🟢 OK' if passive_ratio < 10 
                else '🟡 Attenzione' if passive_ratio < 20 
                else '🔴 Troppe passive'
            ),
            'repeated_starts': repeated_starts
        }
    }
```

```python
class RevisionEngine:
    """
    Applica il backlog al testo in modo sistematico.
    Garantisce completezza e tracciabilità.
    """
    
    # ── ORDINE DI APPLICAZIONE ──
    # Le modifiche vanno applicate in quest'ordine 
    # per evitare conflitti:
    APPLICATION_ORDER = [
        # 1. Prima le modifiche strutturali (macro)
        'STRUTTURA',   # Riordino capitoli, merge, split
        
        # 2. Poi le modifiche di contenuto
        'STRATEGIA',   # Allineamento promessa
        'CONTENUTO',   # Specificità, azionabilità
        
        # 3. Poi le modifiche di voce
        'VOCE',        # Tono, persona, engagement
        
        # 4. Poi le modifiche di ritmo
        'RITMO',       # Transizioni, variazione
        
        # 5. Infine le modifiche di superficie
        'SUPERFICIE',  # Grammatica, filler, formato
        
        # 6. Per ultimi i pattern (cross-capitolo)
        'PATTERN'      # Problemi ricorrenti
    ]
    
    @staticmethod
    def apply_revision(backlog_items, original_text):
        """
        Per ogni item del backlog, in ordine di priorità:
        
        1. Localizza il testo target nel libro
        2. Applica la modifica proposta
        3. Verifica che la modifica non rompa il contesto
        4. Registra nel changelog
        5. Se l'item ha dipendenze, 
           verifica le dipendenze DOPO
        """
        
        changelog = []
        skipped = []
        
        # Ordina: P0 prima, poi P1, poi P2
        # Dentro la stessa priorità, segui APPLICATION_ORDER
        sorted_items = sorted(
            backlog_items,
            key=lambda x: (
                {'P0': 0, 'P1': 1, 'P2': 2}[x['priority']],
                RevisionEngine.APPLICATION_ORDER.index(
                    x['type']
                ) if x['type'] in RevisionEngine.APPLICATION_ORDER 
                else 99
            )
        )
        
        for item in sorted_items:
            try:
                # Applica la modifica
                # ... (logica di sostituzione)
                
                changelog.append({
                    'id': item['id'],
                    'status': 'DONE',
                    'note': f"Applicato: {item['proposed_fix'][:80]}..."
                })
                
            except Exception as e:
                # Se non applicabile, registra perché
                skipped.append({
                    'id': item['id'],
                    'status': 'SKIP',
                    'reason': str(e)
                })
        
        return changelog, skipped
    
    @staticmethod
    def completeness_verification(
        original_chapters, 
        revised_chapters
    ):
        """
        Verifica che NESSUN contenuto sia stato perso 
        durante la revisione.
        
        REGOLA ASSOLUTA: 
        Il numero di capitoli DEVE essere uguale.
        Ogni capitolo DEVE essere presente.
        La lunghezza totale NON DEVE diminuire >20% 
        (a meno che filler rimossi intenzionalmente).
        """
        
        checks = {
            'chapter_count_match': (
                len(original_chapters) == len(revised_chapters)
            ),
            'original_chapters': len(original_chapters),
            'revised_chapters': len(revised_chapters),
            'missing_chapters': [
                ch for ch in original_chapters 
                if ch not in revised_chapters
            ],
            'word_count_original': sum(
                len(ch.split()) for ch in original_chapters.values()
            ),
            'word_count_revised': sum(
                len(ch.split()) for ch in revised_chapters.values()
            ),
        }
        
        checks['word_count_change_pct'] = round(
            (checks['word_count_revised'] - checks['word_count_original']) 
            / max(checks['word_count_original'], 1) * 100, 
            1
        )
        
        if checks['word_count_change_pct'] < -20:
            checks['warning'] = (
                f"⚠️ ATTENZIONE: Il testo è diminuito del "
                f"{abs(checks['word_count_change_pct'])}%. "
                f"Verificare che non sia stato perso contenuto."
            )
        
        return checks
```

#### Pattern più comuni (da cercare attivamente):


| Pattern | Come si manifesta | Fix tipico |
| --- | --- | --- |
| Aperture deboli ripetute | 4+ capitoli iniziano con "In questo capitolo..." o definizioni | Sostituire ogni apertura con hook specifico per quel capitolo |
| Filler sistematici | "Fondamentalmente", "È importante notare" ripetuti 10+ volte | Eliminare ogni occorrenza. Se la frase funziona senza, il filler non serviva |
| Passive sistematiche | "È stato dimostrato", "Viene spesso detto" in ogni capitolo | Riscrivere in attivo: "I dati dimostrano", "Gli esperti dicono" |
| Persona grammaticale instabile | Passa da "tu" a "voi" a "noi" tra sezioni | Standardizzare su una persona e applicare a tutto il libro |
| Mancanza di prove | Affermazioni senza dati/esempi ripetute in tutto il libro | Aggiungere dato, esempio, o caso studio per ogni claim significativo |
| Chiusure morte | Capitoli che finiscono con l'ultimo concetto senza wrap-up | Aggiungere takeaway + bridge al capitolo successivo |
