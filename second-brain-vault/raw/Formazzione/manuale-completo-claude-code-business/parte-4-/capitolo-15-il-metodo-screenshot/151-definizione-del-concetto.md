# 15.1 — Definizione del Concetto

Il metodo Screenshot Loop è l'implementazione pratica del ciclo Task-Do-Verify applicato alla costruzione di siti web e 
interfacce grafiche. Claude Code costruisce una versione del sito, fa uno screenshot, lo confronta con un'immagine di 
riferimento, identifica le differenze e le corregge, ripetendo il ciclo fino a raggiungere un livello di fedeltà accettabile.
