# 15.5 — Errori Comuni

Errore 1: Screenshot singoli anziché full-page​
Fare screenshot sezione per sezione e poi assemblarli è enormemente meno efficiente. Il metodo Command + Shift + P 
→ full size screenshot cattura tutto in un'unica operazione. 
Errore 2: Immagini troppo pesanti​
Mai inserire immagini superiori a 5-6 MB nel contesto. Ridimensionare sempre al 50%. L'autore ha specificato che 
l'immagine originale di 12.5 MB avrebbe fatto "esplodere tutto". 
Errore 3: Non copiare gli stili CSS​
Dare solo l'immagine è insufficiente. Gli stili CSS danno a Claude Code le "coordinate esatte" del design: colori, font, 
spaziature. Senza di essi, Claude deve indovinare — e indovinare significa errare. 
Errore 4: Aspettarsi le stesse immagini del sito originale​
Claude Code non ha accesso alle immagini del sito originale. Può solo replicare la struttura e inserire placeholder. Le 
immagini devono essere sostituite manualmente o tramite un prompt successivo che indica dove trovare gli asset.
