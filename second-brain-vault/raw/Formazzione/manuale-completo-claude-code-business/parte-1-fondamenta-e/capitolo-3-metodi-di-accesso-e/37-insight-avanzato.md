# 3.7 — Insight Avanzato

Shortcut di accesso rapido a Claude Code: 
●​
In Antigravity (Mac): Command + Shift + ESC → Apre direttamente Claude Code 
●​
Icona stella: Sia in VS Code che in Antigravity, Claude Code è accessibile tramite un'icona a forma di stella 
nella barra laterale 
Il concetto di file "in contesto":​
Quando Claude Code è aperto in un IDE, nella parte superiore della chat viene mostrato quale file è attualmente 
"guardato" dal sistema. Questo è un indicatore visivo cruciale perché: 
●​
Se chiedete di modificare "questo file", Claude modifica il file attualmente visualizzato 
●​
Se siete nel file sbagliato, Claude potrebbe modificare il file errato 
●​
È buona pratica assicurarsi di essere nel file corretto prima di dare istruzioni 
L'autore spiega: "Assicuriamoci di essere anche magari nel file giusto, di modo tale che non ci siano probabilità che lei 
sbagli."
