# 17.1 — Definizione del Concetto

Le modalità di permesso (permission modes) sono i livelli di autonomia che l'utente concede a Claude Code durante il 
lavoro. Determinano quanto controllo l'utente mantiene sulle azioni di Claude Code — dalla supervisione totale di ogni 
singola modifica, fino alla completa autonomia operativa. La scelta della modalità corretta in ogni fase del lavoro è una 
decisione strategica che impatta direttamente su velocità, sicurezza e qualità del risultato.
