### 4. SCRIPT COMPLETO

Vuoi usare le potenzialità di Claude Code, ma hai paura dei costi delle API o non vuoi inviare i dati sensibili dei tuoi clienti ai server di Anthropic? 

C'è una soluzione che quasi nessuno usa: l'ambiente ibrido locale con Ollama.

Funziona così. Invece di far processare tutto a Claude, installi Ollama sul tuo computer, e fai girare un modello open source come Llama 3 o Mistral in locale. 

A quel punto, configuri Claude Code nel tuo terminale per far dialogare i due sistemi. Come si fa? Vai nel file `.claude.json` e imposti un "custom endpoint" che punta a `localhost`.

Il risultato? Usi Claude 3.5 Sonnet solo per l'architettura complessa, e devii tutti i micro-task di lettura e pulizia del codice al tuo modello locale gratuito. 

Così facendo, il codice dei tuoi clienti non esce mai dal tuo PC, la privacy è garantita al 100%, e la tua fattura delle API crolla di botto del 70%.

Questa configurazione ibrida richiede alcuni passaggi delicati per evitare conflitti di porta ed errori di connessione. Nel capitolo 4 del nostro Manuale di Claude Code trovi la guida passo-passo testata e il file di configurazione già pronto da incollare. Link in bio.
