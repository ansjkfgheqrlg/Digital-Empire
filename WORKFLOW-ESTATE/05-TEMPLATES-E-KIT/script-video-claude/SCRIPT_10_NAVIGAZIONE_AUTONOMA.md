# SCRIPT 10: ORGANIZZAZIONE CARTELLE PER NAVIGAZIONE
**Argomento Tecnico:** Come organizzare le cartelle perché Claude navighi da solo
**Angolo:** Funzione sconosciuta (navigazione autonoma)
**Leva Emotiva:** "aspetta, non sapevo che si potesse fare così"

## SCRIPT VOCALE
Qualcuno ha appena capito come far navigare l'intelligenza artificiale nel proprio computer da sola, senza caricargli nessun file a mano.
Se usi Claude Code dal terminale, lui può leggere letteralmente tutte le tue cartelle.
Ma per non farlo impazzire, devi usare i file indice.
Prima cosa crea una cartella chiamata `Clienti`.
Al suo interno non mettere mille file a caso. Crea un singolo file e rinominalo `INDEX.md`.
Dentro l'indice fai un elenco puntato con i link alle sotto-cartelle.
A questo punto, quando scrivi a Claude "analizza il cliente X",
lui aprirà l'indice, troverà il percorso esatto, entrerà nella sotto-cartella e leggerà solo i file giusti.
Hai appena creato un agente autonomo che si cerca i dati da solo.
